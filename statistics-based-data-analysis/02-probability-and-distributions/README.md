## 강의 내용 정리

### 1. 기술통계학 (Descriptive Statistics)
- 수집한 데이터를 정리·요약해 데이터의 분포와 특성을 초기에 파악하는, 모든 분석의 출발점이 되는 분야.
- R의 `mean()`, `var()`, `sd()`, `summary()` 등을 이용한 평균·분산·표준편차·요약 통계량 계산 예시 (R 내장 데이터 `EuStockMarkets` 활용).
- "평균의 함정": 평균(mean), 중앙값(median), 최빈값(mode)이 서로 다른 의미를 가지며, 소득 불균형처럼 분포가 한쪽으로 치우친 경우 평균만으로는 실상을 오해할 수 있음을 짚는다.

### 2. 확률(Probability)의 정의
- **고전적 확률(수학적 확률)**: 표본공간의 전체 경우의 수(O) 중 사건 A에 해당하는 경우의 수(n)의 비율, 즉 `n/O`. (예: 주사위에서 홀수가 나올 확률 = 3/6 = 1/2)
- **통계적 확률**: 동일한 실험을 아주 많이(N번) 반복했을 때, 사건 A의 상대도수(`n/N`)가 일정한 값 P(A)로 수렴해가는 성질을 이용한 확률 정의. (주사위를 12번, 1,200번, 1,200만 번 굴렸을 때 각 눈이 나올 빈도가 점점 균등해지는 예시로 설명)
- **확률 공리(공리적 확률)**: ① 0 ≤ P(A) ≤ 1, ② 표본공간 전체의 확률 P(Ω) = 1, ③ 서로 배반인 사건들의 합집합 확률은 각 확률의 합과 같다는 세 가지 공리로 확률을 수학적으로 정의.

### 3. 확률분포
- 확률변수가 취할 수 있는 값과 그 값이 나타날 확률을 대응시킨 관계. 누적분포함수 `F(x) = P(X ≤ x)`로 정의.
- 확률변수가 이산형이면 확률질량함수, 연속형이면 확률밀도함수라 부른다.

### 4. 베르누이 시행과 이항분포
- **베르누이 시행**: 성공(확률 p) 또는 실패(확률 1-p)의 두 가지 결과만 나오는 확률실험. (예: 주사위에서 3의 배수가 나오면 성공)
- **이항분포 B(n, p)**: 성공 확률 p가 동일한 베르누이 시행을 n번 독립적으로 반복했을 때, 성공 횟수가 따르는 분포. 모수는 시행 횟수 n과 성공 확률 p.

### 5. 정규분포
- 이항분포의 시행 횟수 n이 아주 커지면(특히 p=0.5 부근) 좌우 대칭인 종 모양 분포로 근사됨을 드무아브르(1667~1754)가 발견했고, 이후 라플라스와 가우스에 의해 확장·정립되었다.
- 정규분포의 특징: ① 종 모양, 좌우 끝이 x축에 닿지 않고 무한히 이어짐 ② 평균 중심 좌우대칭 ③ 평균 근처에 밀집, 양 끝으로 갈수록 감소 ④ 평균 μ와 표준편차 σ(분산 σ²)로 모양이 결정되며 `N(μ, σ²)`로 표기.
- **표준정규분포**: 평균 0, 표준편차 1인 정규분포 `N(0, 1²)`. 대문자 Z로 표기하며, 모든 정규분포는 표준화 변환(`z = (x-μ)/σ`)을 통해 표준정규분포로 변환할 수 있다.
- 예제: 남학생 키의 평균 170cm, 표준편차 6cm일 때 182cm 이상일 확률은 z=2로 표준화한 뒤 표준정규분포표를 참조하여 약 0.023(2.3%)으로 계산.

### 복습 팁 (강의 노트 기준)
100명 학생의 수학 평균 70점, 표준편차 9일 때 내 점수 80점의 등수를 `pnorm()` 함수로 계산하는 예제가 다뤄졌으며, 결과적으로 상위 13~14등 수준으로 확인되었다.
