## 1면 — 서술형 (중요한 순서)

**1. 🔥 Vanishing Gradient** (5회)
- 정의: 역전파 때 gradient가 아래층으로 갈수록 0에 가까워져서 **아래층 weight가 학습되지 않음**
- 원인: sigmoid 미분값이 **최대 0.25** → 층마다 곱해져 0.25ⁿ → 0 (10층이면 약 10⁻⁶). 입력이 아주 크거나 작으면(포화) 미분값 ≈ 0
- 해결: **ReLU** (x > 0이면 미분값 1 → 그대로 전달), Xavier/He 초기화, Batch Normalization

**2. 🔥 Overfitting과 Train/Validation** (5회)
- 문제: 학습 데이터는 잘 맞히는데 **새 데이터는 못 맞힘** (일반화 실패)
- 원인: 파라미터 수에 비해 **학습 데이터가 적음** (고차원, 너무 오래 학습)
- 해결: 데이터 늘리기(augmentation), Regularization(L2, Dropout, BN), Early stopping, Transfer learning
- **Train 높고 Val 낮음** → overfitting → (모델·데이터 그대로) λ 키우기, Dropout, Early stopping
- **Train·Val 차이 없음** → 학습 부족(underfitting) → λ 줄이기, 더 오래 학습, learning rate 조정
- **멈출 때**: Train은 계속 오르는데 **Val이 더 안 오르거나 떨어질 때** → Val 최고 시점 선택

**3. 🔥 차원의 저주** (4회, 주어진 4단어 꼭 넣기)
- **고차원**일수록 필요한 **학습 데이터 양**이 지수적으로 증가 (한 축 k칸 → kᵈ개)
- 데이터가 모자라 공간에 듬성듬성 → **overfitting** → **분류 정확도** 하락
- 해결: 차원 축소, 핵심 특징만 뽑은 latent vector, 사전학습 모델로 저차원 변환

**4. ⭐ Transfer Learning이 잘 되는 이유** (3회, 2026.04엔 2번)
- ImageNet(1000 class)으로 학습한 모델은 이미 **이미지 특징을 뽑는 법**을 배움
- 아래층의 특징(선·색·질감)은 **어떤 이미지에도 통하는 일반적인 특징**
- → 윗부분(분류층)만 **적은 데이터로 학습** → 학습할 파라미터가 적어 overfitting 없이 높은 성능, 시간도 짧음
- 데이터 적으면 마지막 층만, 많으면 위쪽 여러 층 fine-tune (LR은 원래의 1/10)

**5. ⭐ 고차원 → 저차원으로 줄여도 정보가 유지되는 이유** (3회)
- 실제 데이터는 고차원 공간에 고르게 퍼져 있지 않고 **저차원 구조에 모여 있음**
- 이웃 픽셀끼리 값이 비슷함(상관관계·중복) → **핵심 특징은 적은 차원으로 표현 가능** (latent vector)
- t-SNE 2D 그림: 2차원으로 줄여도 **비슷한 이미지끼리 모여 있음** → 2D로도 분류 가능

**6. ⭐ Perceptron** (3회, 그림 필수)
- 그림: `x1 … xn → (× w1 … wn) → Σ + b → f(활성화) → y`,  y = f(Σwx + b)
- 동작: 입력 × 가중치 합 → 비선형 함수 f 통과 → 출력. **좋은 w를 찾는 것 = 학습**
- f가 없으면 층을 쌓아도 W₂W₁x = W'x (선형 하나와 같음) → 비선형 함수 필수

**7. ⭐ 일반 프로그램 vs 기계학습** (3회)
- 일반: 사람이 규칙 작성 → 입력 + 프로그램 = 출력 (규칙이 쉽게 깨지고 확장 안 됨)
- 기계학습: 입력 + 정답 → **기계가 프로그램(W)을 자동으로 만듦** (데이터 기반)

**8. ⭐ Validation vs Test** (2회)
- 학습마다 W가 다른 이유: 초기값·데이터 순서 random + hyperparameter 다름 → **다른 골짜기(local minimum) 도착**
- 최종 모델: **Validation 성능 최고**인 것
- Test 필요: Val은 모델 고르는 데 써서 점수가 부풀려짐 → **한 번도 안 쓴 Test**로 1번만 측정

**9. ⭐ λ (Regularization 강도)** (2025.10, 10점)
- λ 작게: train 오차↓ val 오차↑ (overfit) / λ 크게: train 오차↑ val 오차↓ / 너무 크면 둘 다↑
- L(W) = (1) 데이터 loss: W를 학습 데이터에 맞춤 + (2) 정규화: W를 **작고 고르게** → 새 데이터에도 맞게
- L2: 작은 값이 고르게 ([.25 .25 .25 .25]가 [1 0 0 0]보다 좋음) / L1: 0이 많게

**10. ⭐ Linear Classifier · K-NN**
- Linear 뜻: 점수가 입력의 **1차 함수** → 직선 경계 → XOR·도넛 모양은 못 나눔
- W의 각 행 = class별 **대표 이미지(template)** / 말 머리 2개 = 왼쪽·오른쪽 말을 모두 맞히려다 합쳐짐
- K-NN: 가까운 k개로 투표, 흰 영역 = 동점 / 안 쓰는 이유: 예측이 느림(O(N)), 픽셀 거리가 의미 없음, 차원의 저주

**11. 용어 나머지** (2023·2024)
- Association: 정답 없이 **함께 사는 상품 규칙** (빵 → 우유) → 진열·묶음·추천
- 분류 vs 회귀: 정해진 class (덥다/춥다, 정확도) vs 연속 숫자 (기온, RMSE). 둘 다 지도학습
- 차원 축소 이유: 차원의 저주 해결, overfitting 방지, 계산량 감소, 시각화

## 2면 — SSL · 계산 · 6주차 (중요한 순서)

**1. 🔥 Self-Supervised Learning** (7주차, 반드시 나옴)
- 정의: 정답 없는 데이터에서 **정답을 자동으로 만들어(pretext task)** 학습 → 좋은 특징 추출기 → 적은 정답 데이터로 실제 문제(downstream) 학습
- 평가: pretext 성능이 아니라 **downstream 성능**으로
- **Rotation**: (가) 이미지를 직접 0/90/180/270도로 돌리고 **돌린 각도가 정답** / (나) **사람이 붙인 소량의 정답**
  - 뉴런 수: 640×480×3 입력 = **921,600**, 출력 = **4**
- **Inpainting** (10×10 박스): 출력 = 10×10×3 = **300**, 가린 부분의 **원본 픽셀이 정답**, MSE로 loss → 학습된 특징을 분류 등에 재사용
- **Contrastive**: 원 = 이미지를 encoder에 넣어 얻은 **특징 벡터**
  - Positive = 같은 이미지의 변형(crop·회전·색 변경), Negative = 다른 이미지
  - Loss = **max(0, (가) − (나) + α)** → Positive 거리(가)는 줄이고 Negative 거리(나)는 키움
- 텍스트: **GPT = 다음 단어 맞히기**, **BERT = 빈칸 단어 맞히기** + 다음 문장인지
- Representation vs Generative: 핵심 특징만 학습(기억으로 그린 지폐) → 다른 문제에 사용 / 데이터 분포 자체 학습(정밀한 지폐) → 새 데이터 생성

**2. ⭐ Loss 계산**
- SVM: `Li = Σ max(0, 오답점수 − 정답점수 + 1)` (정답 class는 빼고 더함)
- Softmax: `Li = −ln(정답 확률)`, 정답 확률 = e^정답점수 / Σ e^점수
- 자주 나온 답: −ln 0.5 = **0.693** / SVM 2.9, 0, 12.9 → 평균 **5.27** / cat Softmax 24.5 / 188.7 = 0.13 → **2.04**
- W가 아주 작을 때: SVM = **C − 1** (10 class → 9) / Softmax = **ln C** (→ 2.3). 유도: e⁰/(C·e⁰) = 1/C → −ln(1/C)
- 최소 0 예: <0,0,0,500> / 최대 ∞ 예: <500,500,500,0> (정답 4번)

**3. ⭐ 크기 · 횟수 계산**
- 이미지: 32×32×3 = 3,072 / 640×480×3 = 921,600 / 가능한 이미지 수 = 256^3072
- K-NN 학습 결과: 학습 데이터 전부 (50,000 × 32×32×3) / Linear: W (10 × 3,072) + b (10)
- 1 epoch update (5,000개, batch 50): SGD **5,000** / Mini-batch **100** / Batch **1**
- loss 공간 차원 = weight 개수 + 1

**4. ⭐ Backprop 그래프** (2023)
- 규칙: 아래로 보낼 값 = **위에서 온 값 × 내 미분값** / 더하기: 그대로 전달 / 곱하기: 상대편 값을 곱함
- 답: (가) **−0.53** / (나) **0.20** / (다) **−0.20** / (라) **0.40** → (다)는 w 수정에, (라)는 아래층 전달에 사용
- sigmoid 위에서 0.5가 오면: 최대 0.125 (x = 0), 최소 ≈ 0 (x가 아주 크거나 작을 때)

**5. ⭐ ReLU의 속도 문제 · 초기화**
- 출력이 **항상 0 이상** → 모든 w가 같이 커지거나 같이 작아짐 → 지그재그로 느림 / 음수면 gradient 0 → 죽은 뉴런
- 해결: Leaky ReLU, ELU, Batch Normalization, 입력 평균을 0으로
- Xavier: w가 너무 작으면 신호가 0으로 사라지고, 너무 크면 포화 → **√(입력 수)로 나눠** 층마다 크기 유지 (ReLU는 He 초기화)

**6. 🎯 6주차 — Optimizer**
- SGD 문제: 지그재그, local minimum·saddle point에서 멈춤, mini-batch라 gradient가 흔들림
- Momentum: **관성** → 골짜기 탈출, 지그재그 감소 (단점: 지나침) / Nesterov: **먼저 가본 곳**의 기울기로 결정
- AdaGrad: 방향별로 update 크기를 맞춤, 오래 하면 0이 됨 → RMSProp: 최근 값 위주로 해결
- **Adam = Momentum + RMSProp** → 기본 선택

**7. 🎯 6주차 — Dropout · Regularization**
- Dropout: 학습 때 뉴런을 **무작위로 0** → 특정 특징에 의존 안 함 + 여러 모델의 앙상블 효과 / test 때는 끄고 **p를 곱함**
- Regularization 공통 패턴: **학습 때 무작위성 추가, test 때 평균**
  - BN: mini-batch 구성이 매번 random / Data Augmentation: 변형(뒤집기·자르기·색) 방법이 random
- Ensemble vs Regularization: 여러 모델을 평균 vs 한 모델 안에서 해결

**8. 🎯 5주차 — Batch Normalization**
- 층을 지날 때마다 값의 분포가 틀어짐 → 중간중간 **평균 0, 분산 1로 정규화** (+ γ, β로 조정)
- 효과: 학습이 빠르고 안정적, 큰 learning rate 가능, 초기화 영향 감소
