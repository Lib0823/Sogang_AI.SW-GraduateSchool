# AI Data System and Infrastructure

<br/>

서강대학교 AI·SW 대학원 **AI 데이터 시스템 및 인프라(GITF345)** 강의 내용을 정리한 저장소입니다.
담당 교수는 김영재(`youkim@sogang.ac.kr`)이며, 스토리지 하드웨어에서 시작해
파일 시스템 → 데이터베이스 → 클라우드·분산 스토리지 → VectorDB/RAG →
LLM/KV Cache → Cloud AI Infrastructure로 이어지는 데이터 시스템의 전체 계층을
한 학기에 훑는 과목입니다. 각 주차 노트는 `NN-주제.md` 형태의 단일 마크다운 파일로
정리합니다.

<br/>

> *이 저장소의 자료는 학습 및 개인 복습 목적으로 정리한 것이며, 실제 강의
> 내용과 표현상 차이가 있을 수 있습니다.*
