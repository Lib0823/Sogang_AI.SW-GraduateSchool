## 강의 내용 정리

### 1. 회귀분석(Regression)의 역사
- "회귀(regress)"의 원뜻은 "옛날 상태로 돌아간다"는 의미이다.
- 영국의 유전학자 프랜시스 골턴(Francis Galton, 1886)은 부모와 자녀의 키를 연구하며, 자녀의 키가 부모보다 극단적으로 크거나 작아지기보다 전체 평균으로 돌아가려는 경향(회귀)이 있다는 가설을 세우고 이를 "회귀분석"이라 명명했다.
- 이후 칼 피어슨(Karl Pearson, 1903)이 아버지와 아들의 키 데이터를 바탕으로 함수 관계를 도출해 회귀분석 이론을 수학적으로 정립했다.

### 2. 회귀분석의 목적과 인과관계의 함정
- 독립변수와 종속변수를 구별하고 그 사이의 인과관계를 파악하는 것이 목적이다.
- 인과관계는 데이터에 대한 깊은 통찰과 경험 없이는 잘못 해석되기 쉽다. 강의에서 제시된 예시:
  - 미세먼지 농도와 교통사고 발생 건수가 반비례하는 것처럼 보이는 그래프 — 실제로는 미세먼지가 사고를 줄이는 것이 아니라 제3의 요인(계절 등)이 함께 작용할 수 있음.
  - 아이스크림 판매량과 익사사고 증가 (제3의 요인: 계절/기온)
  - 불을 켜고 자는 아이의 근시 발생률 (제3의 요인: 부모의 유전적 근시가 조명 습관에도 영향)
  - 국가부채 비율과 성장률의 관계 (인과관계의 방향이 뒤바뀌었을 가능성)
  - 사과 수입량과 이혼율의 관계 (인과관계를 알 수 없는 단순 상관)
- **종속변수**: 다른 변수의 영향을 받아 값이 결정되는 변수. **독립변수**: 영향을 미치는 변수.

### 3. 단순회귀분석(Simple Regression Analysis)
- 독립변수 1개, 종속변수 1개로 원인과 결과를 통계적으로 검정.
- 통계적으로 유의할 때, 독립변수(원인)가 종속변수(결과)에 영향을 준다고 해석하며 회귀계수가 양수(+)면 긍정적, 음수(-)면 부정적 영향을 의미한다.
- 회귀식 `Y = a + bX`에서 Y절편(a), 기울기(b, 영향력의 크기), 결정계수 R²(설명력/정확도)를 구하는 것이 핵심이며, 엑셀의 최소제곱법 수식과 산점도·추세선을 이용해 직접 계산하는 실습이 포함되어 있다.
- 엑셀 데이터 분석 도구를 통한 회귀분석 결과 해석:
  - **F 검정**: 회귀식 전체의 유의성 검정 (p < 0.05면 유의함 — "모든 회귀계수가 0"이라는 귀무가설을 기각).
  - **T 검정**: 각 독립변수가 개별적으로 유의한지 검정 (p < 0.05, 95% 신뢰수준의 양측검정).

### 4. 다중회귀분석(Multiple Regression)
- 독립변수가 2개 이상인 경우로, 회귀식은 `Y = a + b1X1 + b2X2 + ... + bnXn` 형태를 가진다.
- 실습 예시: 종업원의 연봉(Y)을 근속연수(X)만으로 설명하는 단순회귀(결정계수 0.82)보다, 근속연수와 학력(대졸/고졸 이진변수)을 함께 사용하는 다중회귀(결정계수 0.97)가 훨씬 높은 설명력을 보였다.
- R 실습: R 내장 데이터 `mtcars`를 이용해 연비(mpg)를 배기량(disp)·마력(hp)·무게(wt)로 설명하는 다중회귀모형을 `lm()` 함수로 적합하고, 각 계수를 회귀식에 대입해 예측값을 구하는 과정을 다룬다.
