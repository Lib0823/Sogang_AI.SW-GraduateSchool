## 강의 내용 정리

### 1. 상관분석(Correlation Analysis)의 정의
- 확률론과 통계학에서 두 변수 간에 어떤 선형적 또는 비선형적 관계를 갖고 있는지를 분석하는 방법이다.
- 두 변수 간 관계의 강도를 **상관관계(Correlation)**라 하며, 모상관계수는 그리스 문자 ρ, 표본상관계수는 r로 표기한다.

### 2. 실습: 통계 기법을 이용한 상관관계 분석
- 예능 프로그램 속 인물 간 호감도를 설문 데이터로 수집해 상관계수를 구하는 예시("덕선이 남편 찾기")를 통해, 실제로 손으로 데이터를 수집·저장한 뒤 분석하는 과정을 체험한다.
- R 실습: `cor()` 함수로 상관계수를 계산하고, `corrplot` 패키지를 이용해 상관계수 행렬을 다양한 형태(number, circle, square, pie, ellipse 등)로 시각화한다. R 내장 데이터 `EuStockMarkets`(유럽 4대 증시 지수)를 이용해 지수 간 상관관계를 계산하고 히트맵으로 표현하는 예시가 제시된다 (DAX-SMI 등 지수 간 0.9 이상의 매우 높은 상관관계 확인).

### 3. 상관분석 실전 활용 예시 (논문 사례)
- "서울시 소상공인 지원정책 효과성 연구" 논문을 인용하여, 컨설팅·자금지원·교육·서비스유용성·서비스용이성·서비스만족 변수들 간의 상관관계 분석 결과표를 제시한다.
- 컨설팅과 서비스만족 간 상관계수 0.532, 자금지원과 서비스만족 간 0.578 등으로 비교적 높은 상관관계가 확인되었으며, 모든 변수 간 상관관계가 유의수준 0.01에서 유의한 것으로 나타났다.
- 다중공선성 검증(VIF < 10, 공차한계값 > 0.1)을 통해 변수 간 심각한 다중공선성 문제가 없음을 함께 확인하는 절차도 다룬다.

> 참고: 상관계수는 두 변수 간 연관의 **정도**를 나타낼 뿐, 인과관계를 의미하지는 않는다는 점이 04주차(회귀분석) 강의와 이어지는 핵심 주의사항이다.
