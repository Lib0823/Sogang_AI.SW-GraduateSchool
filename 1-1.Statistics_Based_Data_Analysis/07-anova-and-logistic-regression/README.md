## 강의 내용 정리

### 1. 분산분석(ANOVA) — 모집단이 세 개 이상인 경우
- 집단이 세 개 이상일 때, 두 집단씩 짝지어 반복 비교하는 대신 분산분석을 통해 한 번에 검정한다.
- **일원배치 분산분석(One-way ANOVA)**: 집단을 구분하는 요인(독립변수)이 하나인 경우로, 자료의 총 변동을 요인에 의한 집단 간 변동과 집단 내 변동으로 분해하여 요인에 의한 변동이 통계적으로 의미 있는 크기인지(p < 0.05) 검정한다.
- **가설 수립**
  - 귀무가설(H₀): 모든 집단(처리)의 평균이 같다 (`μ1 = μ2 = ... = μk`), 즉 각 처리의 효과는 없다.
  - 대안가설(H₁): 적어도 한 집단의 평균은 다르다.
- R 실습: R 내장 데이터 `PlantGrowth`(식물 처리 그룹별 생장 무게)를 이용해 `lm()`과 `anova()`로 분산분석표를 산출하고, `shapiro.test()`로 잔차의 정규성을, `dunnett`/`Tukey` 다중비교(`multcomp` 패키지의 `glht()`)로 어느 집단 간에 차이가 있는지 사후검정을 수행하는 과정을 다룬다.
- 실제 논문 사례(대학 유형별·전공계열별 취업준비비용 차이 분석)를 통해 t검정과 분산분석(F/p, scheffe 사후검정)이 실무 연구에서 어떻게 활용되는지 함께 살펴본다.

### 2. 로지스틱 회귀분석(Logistic Regression)
- 1958년 D. R. Cox가 제안한 확률 모델로, 독립변수의 선형결합을 이용해 사건의 발생 가능성을 예측하는 통계 기법이다.
- 일반적인 선형회귀와 달리 **종속변수가 범주형(이항형 등)**일 때 사용하며, 예측 대상은 종속변수 Y의 값 자체가 아니라 Y가 특정 범주가 될 확률 P(Y=i)이다.
- 로지스틱 함수: `P(Y)/(1-P(Y)) = exp(β0 + β1X)` 형태로 오즈(odds)의 로그값을 선형식으로 모델링한다.
- **장점**: 정교한 모수 추정, 범주 확률값 추정 가능, 계수 해석을 통한 변수별 유의성·영향력 파악 용이.
- **단점**: 데이터 차원이 매우 클 때 다른 머신러닝 기법 대비 추정 정확도가 떨어질 수 있고, 극단적인 x값에서 확률이 0/1에 가까워져 반복 계산 시 과적합이 발생하기 쉬우며, 복잡한 비선형 분류에는 약하다.
- **활용 분야**: 의료(질병 발생 여부 예측), 마케팅(구매 여부 예측), 금융권 신용평가모형·이탈예측모형 등에 전통적으로 널리 활용된다.
- 실제 논문 사례를 통해, 재학 중 근로/인턴 경험 유무가 졸업 후 정규직 취업 여부에 미치는 영향을 이분형 로지스틱 회귀분석으로 검증한 사례(관련 전공 일 경험이 있으면 정규직 취업 확률이 1.22배 높아짐, p=0.023으로 유의)를 다룬다.

### 3. R 실습: mtcars 데이터를 이용한 로지스틱 회귀
- R 내장 데이터 `mtcars`에서 엔진 형태(vs: 0=V형, 1=직렬형)를 종속변수로, 변속기(am)·연비(mpg) 등을 독립변수로 하여 `glm(..., family="binomial")`로 로지스틱 회귀모형을 적합하고 `summary()`로 계수의 유의성(p-value)을 확인하는 과정을 다룬다.
