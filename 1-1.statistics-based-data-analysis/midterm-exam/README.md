## 리포트 구성 (6개 섹션)
리포트는 [01-introduction](../01-introduction)부터 [07-anova-and-logistic-regression](../07-anova-and-logistic-regression)까지 다룬 이론들을 아우르며, 아래 6개 섹션으로 정리되어 있다.

### Section 1. 가설 설정하기
가설의 개념, 귀무·대립가설, 양측·단측검정, 가설검정 4단계, 제1·2종 오류, 검정력, 유의수준·신뢰수준, 검정 통계량(Z/t/χ²/F)과 p-값을 정리하고, `diet.csv` 데이터로 **쌍체 t검정**을 실행했다 (평균 차이 1.238kg, t=3.4868, p=0.0069 → 귀무가설 기각, 다이어트 프로그램의 체중 감소 효과가 통계적으로 유의함을 확인).

### Section 2. 통계 기반 분석모델
기술통계·상관분석(피어슨/카이제곱/스피어만)·회귀분석(변수선택법: 후진제거법/전진선택법/단계별선택법)·분산분석(ANOVA)·주성분분석(PCA)·판별분석의 개념을 정리하고, `iris` 데이터로 다음 코드를 실행했다:
- **기술통계**: Sepal Length의 평균 5.843, 중앙값 5.800, 왜도 0.315, 첨도 -0.552로 분포가 정규분포에 가까움을 확인.
- **상관분석**: Sepal Length-Petal Length 간 r=0.872로 강한 양의 상관관계 확인 (Pearson/Chi²/Spearman 모두 유의).
- **PCA**: 4개 변수를 2개 주성분으로 축소해도 분산의 97.8%를 설명 (PC1 92.46% + PC2 5.31%).
- **로지스틱 회귀**: `mtcars` 데이터로 연비(mpg)에 따른 엔진 타입(vs) 분류 모델을 적합, 두 계수 모두 p<0.01로 유의함을 확인.

### Section 3. 데이터 마이닝 분석 기법
분류(로지스틱 회귀, 의사결정트리 CART, SVM, 인공신경망)·예측(회귀분석, 시계열/ARIMA)·군집화(K-평균)·연관규칙(지지도/신뢰도/향상도)의 개념을 정리하고:
- **ARIMA 시계열 예측**: `AirPassengers` 데이터(1949~1960년 월별 항공 승객 수)에 ARIMA(1,0,1)(0,1,1,12) 모델을 적합해 향후 10년을 예측.
- **K-평균 군집화**: `iris` 데이터에서 실루엣값 기준으로는 K=2가 최적(0.681)이나, 실제 품종이 3종임을 고려해 K=3(between/total 88.4%)도 함께 분석.

### Section 4. 앙상블·파생변수·시각화
파생변수 생성(단위 변환, 표현형식 변환, 요약통계량, 변수 결합), 배깅·부스팅·랜덤포레스트를 정리하고:
- 고객 연령 데이터를 연령대별 이진 더미변수(20대/30대/40대/50대)로 변환.
- `iris` 데이터로 배깅(정확도 90.67%), 부스팅/AdaBoost(정확도 89.33%), 랜덤포레스트(OOB 정확도 93.33%, 테스트 정확도 97.78%)를 각각 적용해 비교.

### Section 5. 빅데이터 모델 평가 및 검증
훈련/평가/검증 데이터셋 분할, 과적합(overfitting), 교차검증(K-fold CV)을 정리하고, 예측·분류·군집 모델별 성능평가 지표(MAE/MSE/RMS/MAPE, 혼동행렬·민감도·특이도, ROC/AUC, 던 지수·CH 지수·랜드 지수)를 실습했다:
- ARIMA 예측 모델: MAE 0.146, RMS 0.195, MAPE 1.69%.
- 5-fold 교차검증(Random Forest 회귀): 평균 MAE 0.274, MAPE 4.75%.
- 이진 분류(setosa vs. others): AUC 1.0000 (완벽 분류).
- K-평균 군집(K=3): Rand Index 0.822로 실제 품종 라벨과 82% 일치.

### Section 6. 빅데이터 모델 운영방안
빅데이터 모델 개발·운영 6단계 프로세스(분석 목적 정의 → 가설 검토 → 데이터 준비 → 모델링 → 성능평가 → 운영), 운영시스템 통합 방식(직접 호출/파일 전달/DBMS 경유), 추적 신호(Tracking Signal)를 이용한 모델 성능 모니터링, 모델 개선 방안(재학습 vs. 모델 교체)을 정리했다.
