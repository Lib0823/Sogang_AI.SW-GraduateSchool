## 강의 내용 정리

### 1. 데이터 분석의 정의
데이터 분석은 4차 산업 시대 생존을 위한 필수 기술로 소개되며, 다음 7단계 흐름으로 설명된다: **데이터 → 분석(통계) → 정보 → 예측/분류/군집/시각화 → 의사결정 → 경쟁우위 → 생존**. 단순한 정보(일련의 자료)와 데이터(분석된 정보)를 구분하는 관점이 강조된다.

### 2. 데이터 분석의 역사적 사례
- 조선시대의 측우기(1442년, 전국 350곳에 측우 관측소 운영)는 서양보다 약 200년 앞선 과학적 데이터 수집 도구로 소개된다.
- 크림전쟁 당시 플로렌스 나이팅게일은 전투 자체보다 열악한 병원 환경으로 인한 사망자가 더 많았음을 데이터로 밝혀내고, **장미 도표(Rose Diagram)**로 시각화하여 위생 개선을 이끌어낸 통계학의 대표 사례로 다뤄진다.

### 3. 기업경영과 데이터 분석
- **ERP(전사적 자원관리)**: 인사·생산·마케팅·재무 등 기업 내부 자원을 통합 관리.
- **CRM(고객관계관리)**: 고객 데이터를 분석해 영업·마케팅·서비스 개선.
- 밸류체인(Value Chain) 관점에서 각 활동(HRM, 조달, 물류, 마케팅, A/S 등)에 데이터 분석이 어떻게 적용되는지 소개.

### 4. 빅데이터 전문 분야와 활용 분야
- 빅데이터 관련 직무를 기술(하둡, 분산처리), 분석(회귀·분산·요인분석 등), 기획, 제조, 의료, 금융, 유통, 공공/선거 등 분야별로 소개.
- 마케팅 분야(CRM, 맞춤형 광고), 통신, 스마트그리드, 자산관리, 공공 정책 등 실제 빅데이터 활용 사례 제시.
- 데이터 마이닝의 세부 기법: 데이터 마이닝, 텍스트 마이닝, 오피니언 마이닝, 웹 마이닝, 소셜 마이닝, 현실 마이닝, 군집분석 등.

### 5. 통계학·인공지능·머신러닝·딥러닝의 관계
- 통계학, 인공지능, 머신러닝, 딥러닝은 서로 겹치는 영역을 가진 별개의 학문으로, 벤 다이어그램을 통해 그 포함 관계(통계학 ⊃ 패턴인식 ⊃ 머신러닝 ⊃ 딥러닝 등)를 설명.
- AI 발전 단계를 세탁기(1단계) → 전문가 시스템(2단계) → 머신러닝(3단계) → 딥러닝(4단계)으로 구분.

### 6. 통계학의 정의
- 위키피디아 정의: "수량적 비교를 기초로 많은 사실을 통계적으로 관찰하고 처리하는 방법을 연구하는 학문."
- R. A. Fisher의 정의: "관찰 자료에 수학적 원리를 적용하는 응용수학의 한 분야."
- 통계학의 연구 대상: 모집단, 변동량, 자료축약방법.
- 척도의 종류: 명목척도(성별 등), 서열척도(학력 등), 등간척도·비율척도(사칙연산 가능, 온도의 절대영점 여부 등 예시로 설명).

### 7. R과 R Studio
- **R**: 1995년 뉴질랜드 오클랜드 대학의 로스 이하카(Ross Ihaka)와 로버트 젠틀맨(Robert Gentleman)이 공개한 통계 계산·그래프 작성용 프로그래밍 언어. GPL로 배포되어 무료로 사용 가능.
- **R Studio**: R을 위한 통합개발환경(IDE)으로, 콘솔·편집기·그래프·디버깅·작업공간 관리 기능을 제공. 오픈소스이며 기업용 유료 버전도 존재.
