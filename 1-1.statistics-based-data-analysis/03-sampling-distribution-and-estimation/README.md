## 강의 내용 정리

### 1. 표본분포 (Sampling Distribution)
- 표본분포란 표본들로부터 모집단의 특성을 유추하는 것으로, 선거 여론조사가 대표적인 예시로 다뤄진다 (중앙선거여론조사심의위원회의 선거여론조사 기준 등).
- **모수(parameter)**: 모집단의 특성을 나타내는 값 (예: 특정 후보에 대한 전체 유권자의 지지율 P).
- **통계량(statistic)**: 표본으로부터 관찰되는 특성 값 (예: 표본평균, 표본표준편차, 중앙값).
- **비복원추출 / 복원추출**: 한 번 추출한 표본을 다시 추출 대상에 포함하지 않는지(비복원) 포함하는지(복원)의 차이. 여론조사에서 무작위로 전화번호를 생성해 연결하는 RDD(Random Digit Dialing) 방식이 예시로 제시된다.

### 2. 추정 (Estimation)
- **신뢰수준과 표본오차**: "신뢰수준 95%에서 표본오차 ±3.1%포인트"라는 여론조사 문구의 의미는, 동일한 방식의 조사를 100번 반복했을 때 그중 95번은 실제 지지율이 해당 범위(예: 40%→36.9~43.1%) 안에 들어온다는 뜻이다.
- **추측통계학**: 표본의 특성으로부터 모집단의 특성을 유추하는 통계학의 한 분야로, 크게 추정과 가설검정 두 갈래로 나뉜다.
  - **점추정**: 모수를 하나의 값으로 추정.
  - **구간추정**: 모수의 참값이 포함될 것으로 기대되는 구간을 추정. 표본평균 분포를 표준정규분포로 변환한 `100(1-α)%` 신뢰구간 공식과, 이를 R로 시각화(신뢰구간의 상·하한 및 p-value 개념 도식)하는 예시가 제시된다.

### 3. 가설 (Hypothesis)의 기본 개념
- **가설검정의 4단계**: ① 가설 수립 → ② 표본으로부터 검정 통계량 계산 → ③ 가설 선택 기준(유의수준) 수립 → ④ 판정.
- **영가설(귀무가설, H₀)**: 기존과 차이가 없음을 나타내는 가설, 검정의 출발점.
- **대안가설(대립가설, H₁)**: 연구자가 표본을 통해 입증하고자 하는 가설(연구가설).

### 4. 가설검정의 오류
- **제1종 오류(α)**: 실제 H₀이 참인데 잘못 기각하는 오류 — "있는데 없다"고 판단.
- **제2종 오류(β)**: 실제 H₀이 거짓인데 채택하는 오류 — "없는데 있다"고 판단.
- 사법 판단에 비유: 실제 유죄인데 무죄로 판결(1종 오류), 실제 무죄인데 유죄로 판결(2종 오류)하는 상황으로 설명.

### 5. 민감도, 특이도, 정확도 (의료 검사 사례)
- **민감도(Sensitivity)**: 특정 질환이 있는 사람 중 검사 결과가 양성으로 나오는 비율.
- **특이도(Specificity)**: 특정 질환이 없는 사람 중 검사 결과가 음성으로 나오는 비율.
- **정확도(Accuracy)**: 전체 검사 중 맞게 판정한 비율.
- 신형 스왑 검사와 기존 스왑 검사(Baseline)의 성능을 비교한 실제 사례 데이터를 통해, 민감도 91.8%→100%, 특이도 99.2%→99.2%, 정확도 94.1%→99.7%로 개선된 사례가 제시된다.
