## 0. 이 수업이 왜 필요한가

머신러닝을 "확률 모형"으로 바라보는 관점입니다. 흐름을 한 줄로 요약하면:

> **측정값을 확률 분포로 모델링한다 → 그 분포가 가진 파라미터를 데이터로부터 추정한다.**

예를 들어 정규분포(Normal Distribution)를 쓰기로 했다면, 그 분포가 가진 파라미터는 크게 두 개입니다.

| 기호 | 이름 | 한글 |
|---|---|---|
| μ (mu) | mean | 평균 |
| σ (sigma) | standard deviation | 표준편차 |

확률밀도함수(PDF)를 세워두고 μ와 σ의 **추정치**를 계산하는 것 — 이게 머신러닝이 하는 일의 본질입니다.
딥러닝은 파라미터가 수백만 개로 늘어나서 손으로 못 푸니까 **역전파(backpropagation)** 로 푸는 것뿐, 하는 일 자체는 같습니다.

**자주 쓰이는 분포들**
- Normal / Gaussian Distribution (정규분포) — 연속형
- Bernoulli Distribution (베르누이) — 0/1 두 가지 결과
- Categorical / Multinomial Distribution — 여러 개 카테고리

> 💡 선수 지식은 정규분포 정도면 충분합니다. 겁먹을 필요 없음.

## 1. 확률 변수와 결합 분포

### 용어부터
- **P** = Probability (확률)
- **X, Y** = Random Variable (확률 변수)
- **P(X, Y)** = Joint Probability / Joint Distribution (**결합 확률 / 결합 분포**)
  → "X와 Y가 동시에 특정 값을 가질 확률"

### Bivariate Distribution (이변량 분포)
변수가 두 개인 확률 분포 P(X, Y)를 말합니다.

수업 예시에서는
- X는 x₁ ~ x₅ 까지 **5가지 사건(event)** 을 가질 수 있고
- Y는 y₁ ~ y₃ 까지 **3가지 사건**을 가질 수 있습니다.

즉 5 × 3 = 15칸짜리 표가 하나 생기고, **그 15칸을 전부 더하면 1**이 됩니다.

### Discrete vs Continuous

| | Discrete (이산) | Continuous (연속) |
|---|---|---|
| 예 | 주사위 눈, 카테고리 | 키, 몸무게, 온도 |
| 다 더할 때 | **Σ (시그마, 합)** | **∫ (적분)** |

> ⚠️ 수업 중 "디스크립트"로 들린 건 **discrete(이산)** 입니다.
> 이산 변수는 카테고리에 대한 것이라 크기(순서)가 있을 수도, 없을 수도 있습니다.
> (예: '상/중/하'는 순서가 있고, '사과/배/감'은 순서가 없음)

## 2. Sum Rule (합의 법칙)

$$P(X) = \sum_{y} P(X, Y=y)$$

연속형이면 $P(X) = \int P(X, Y)\,dy$

### 무슨 뜻이냐면
표에서 **한 축을 따라 전부 더해버리면 그 변수는 사라진다**는 뜻입니다.
Y에 대해 다 더해버리면 Y는 쓸모없어지고 X만 남습니다.

이렇게 얻은 P(X)를 **Marginal Probability / Marginal Distribution (주변 확률 / 주변 분포)** 이라고 부릅니다.
표의 가장자리(margin)에 합계가 적히기 때문에 붙은 이름입니다.

### 예시 — P(Y) 구하기
X와 관계없이 Y만 보고 싶다 → X축을 따라 전부 더한다.

| | 값 |
|---|---|
| P(y₁) | 0.26 |
| P(y₂) | 0.47 |
| P(y₃) | 0.27 |
| **합계** | **1.00** ✅ |

> ✅ **검산 습관**: marginal을 구했으면 항상 합이 1인지 확인. 안 맞으면 어딘가 틀린 겁니다.

## 3. Conditional Probability (조건부 확률)

### 기호 읽는 법
$$P(Y \mid X = x_3)$$

세로 막대 `|` 를 기준으로 **오른쪽에 있는 것은 "조건으로 주어졌다"** 는 뜻입니다.
"조건으로 주어졌다"는 건 **딱 그 케이스만 생각하겠다**는 의미입니다.

즉 위 식은 "X가 x₃인 경우만 놓고 볼 때, Y의 확률 분포"입니다.
Y는 3가지가 있으니 **3개 값을 전부 구해야** 하나의 '분포'가 완성됩니다.

### 계산 (조건: X = x₃)
x₃ 행의 값이 각각 0.03, 0.05, 0.03 이라고 하면 → P(x₃) = **0.11**

$$P(Y=y_1 \mid X=x_3) = \frac{0.03}{0.03+0.05+0.03} = \frac{3}{11}$$
$$P(Y=y_2 \mid X=x_3) = \frac{0.05}{0.03+0.05+0.03} = \frac{5}{11}$$
$$P(Y=y_3 \mid X=x_3) = \frac{0.03}{0.03+0.05+0.03} = \frac{3}{11}$$

> ⚠️ **분모는 항상 P(x₃) 하나로 고정**입니다. (필기에 y₂ 분모를 다르게 적어둔 부분 수정함)
> 검산: 3/11 + 5/11 + 3/11 = 11/11 = **1** ✅

### 일반형으로 정리하면
$$P(y_1 \mid x_3) = \frac{P(x_3, y_1)}{P(x_3, y_1)+P(x_3, y_2)+P(x_3, y_3)} = \frac{P(x_3, y_1)}{P(x_3)}$$

**한 줄 요약: 조건부 확률 = 결합 확률 ÷ 주변 확률**
"전체(x₃가 일어난 모든 경우) 중에서 그 칸이 차지하는 비율"

---

## 4. Product Rule (곱의 법칙)

$$P(X, Y) = P(X)\,P(Y \mid X) = P(Y)\,P(X \mid Y)$$

3번의 조건부 확률 식을 이항한 것뿐입니다. 같은 곱셈을 여러 형태로 쓸 수 있습니다.

- $P(A, B) = P(A)P(B \mid A) = P(B)P(A \mid B)$
- 결합 분포는 "하나의 확률 × 그것을 조건으로 둔 나머지의 확률"로 쪼갤 수 있다.

---

## 5. Bayes' Theorem (베이즈 정리)

Product Rule의 두 표현이 같다는 데서 바로 나옵니다.

$$P(X)P(Y \mid X) = P(Y)P(X \mid Y)$$

양변을 P(Y)로 나누면:

$$\boxed{P(X \mid Y) = \frac{P(X)\,P(Y \mid X)}{P(Y)}}$$

### 각 항의 이름과 뜻 ⭐ (제일 중요)

관측값이 Y = y₃ 인 상황을 예로 들면:

$$P(X \mid Y=y_3) = \frac{P(X)\,P(Y=y_3 \mid X)}{P(Y=y_3)}$$

| 항 | 영어 | 한글 | 의미 | 역할 |
|---|---|---|---|---|
| $P(X \mid Y{=}y_3)$ | **Posterior** | 사후 확률 | 관측을 하고 **난 뒤**, 가설 X가 맞을 확률 | 우리가 최종적으로 구하려는 값 |
| $P(X)$ | **Prior** | 사전 확률 | 관측 **전에** 가설 X에 대해 갖고 있던 믿음 | 배경 지식 / 출발점 |
| $Y = y_3$ | **Observation** | 관측값 / 데이터 | 실제로 측정되거나 눈으로 확인한 결과 | 믿음을 갱신시키는 새 정보 |
| $P(Y{=}y_3 \mid X)$ | **Likelihood** | 우도 / 가능도 | 가설 X가 사실이라면 이 관측값이 나올 확률 | 이 가설이 데이터를 얼마나 잘 설명하나 |
| $P(Y{=}y_3)$ | **Evidence** | 증거 / 주변 가능도 | 가설과 무관하게 그 관측값이 나올 전체 확률 | 합이 1이 되게 맞추는 **정규화 상수** |

### 직관적으로
> **사후 = 사전 × 우도 ÷ 증거**
> 기존의 믿음(prior)을 새로 들어온 데이터(likelihood)로 **업데이트**해서 갱신된 믿음(posterior)을 얻는 절차.

### 왜 "역확률(inverse probability)"이라 부르나
우리가 쉽게 아는 건 보통 P(결과 | 원인) 입니다. (원인을 알면 결과 확률은 계산 가능)
그런데 실제로 궁금한 건 P(원인 | 결과) 입니다. (결과를 보고 원인을 역추적)
**확률의 방향을 뒤집는 느낌**이라 inverse probability라는 표현도 씁니다.

### Latent Variable (잠재 변수)
Y는 관측했지만 X는 직접 볼 수 없는 경우, X를 **latent variable(잠재 변수)** 이라고 합니다.
"y₃을 관측했다. 그렇다면 보이지 않는 X의 분포는 어떻게 되는가?" — 이걸 구하는 게 베이즈 추론입니다.
머신러닝 논문의 상당수가 이 구조입니다.

### 계산 순서 (실전)
1. Prior P(X)를 정한다
2. 각 X에 대한 Likelihood P(y₃ | X)를 구한다
3. **Evidence P(y₃) = Σ P(X)P(y₃|X)** 를 계산한다 ← 분모(정규화 상수)
4. 나눠서 Posterior를 얻는다
5. **검산: posterior 전부 더해서 1인지 확인**

## 6. 예제 — 바닐라 쿠키 문제

### 문제 상황
- **보울 1 (B₁)**: 바닐라 30개, 초코 10개 (총 40개)
- **보울 2 (B₂)**: 바닐라 20개, 초코 20개 (총 40개)
- 보울을 랜덤으로 하나 고르고, 거기서 쿠키를 하나 뽑았더니 **바닐라(V)** 였다.
- **질문: 그 쿠키가 보울 1에서 나왔을 확률 P(B₁ | V)는?**

### 베이즈 용어로 번역
- 가설(Hypothesis) **X** = 내가 고른 보울은 무엇인가? (B₁ 또는 B₂)
- 관측(Observation) **Y** = 바닐라를 뽑았다 (V)
- 구할 것 = **Posterior** P(X = B₁ | Y = V)

### ① Prior (사전 확률)
쿠키를 보기 전, 보울을 랜덤하게 고를 확률
- P(B₁) = 0.5
- P(B₂) = 0.5

### ② Likelihood (우도)
각 보울에서 **바닐라가 나올** 확률 — 방향에 주의!
- P(V | B₁) = 30/40 = **0.75**
- P(V | B₂) = 20/40 = **0.5**

### ③ Evidence (증거) — 분모
보울 구분 없이 전체에서 바닐라가 뽑힐 확률 (= 모든 경우를 다 더함)

$$P(V) = P(V|B_1)P(B_1) + P(V|B_2)P(B_2)$$
$$= (0.75 \times 0.5) + (0.5 \times 0.5) = 0.375 + 0.25 = \mathbf{0.625}$$

### ④ Posterior (사후 확률) — 정답

$$P(B_1 \mid V) = \frac{P(B_1)P(V \mid B_1)}{P(V)} = \frac{0.5 \times 0.75}{0.625} = \frac{0.375}{0.625} = \mathbf{0.6}$$

$$P(B_2 \mid V) = \frac{P(B_2)P(V \mid B_2)}{P(V)} = \frac{0.5 \times 0.5}{0.625} = \frac{0.25}{0.625} = \mathbf{0.4}$$

> 검산: 0.6 + 0.4 = **1** ✅

### 이 결과를 어떻게 해석하나

| | 보울 1 | 보울 2 |
|---|---|---|
| 관측 전 (Prior) | 0.5 | 0.5 |
| 관측 후 (Posterior) | **0.6** | **0.4** |

문제는 "B₁일 확률을 구하라"고만 했지만, 사실은 **분포 전체(B₁, B₂ 둘 다)를 구하는 게 자연스럽습니다.**
그래야 합이 1인지 검산도 되고, 분모 P(V)가 왜 정규화 상수인지도 눈에 보입니다.

**바닐라를 봤다는 관측 하나로, 50:50이던 믿음이 60:40으로 갱신되었습니다.**
바닐라 비율이 더 높은 보울 1 쪽으로 확률이 쏠린 것 — 이게 베이즈 정리가 하는 일 전부입니다.

## 8. 핵심 공식 요약 (시험/과제용)

```
[Sum Rule]        P(X) = Σ_y P(X, Y=y)
[Product Rule]    P(X, Y) = P(X)P(Y|X) = P(Y)P(X|Y)
[Conditional]     P(Y|X) = P(X, Y) / P(X)
[Bayes]           P(X|Y) = P(X)P(Y|X) / P(Y)
[Evidence]        P(Y) = Σ_x P(X=x)P(Y|X=x)
```

**항상 체크할 것**
1. 조건부 확률의 분모는 **조건으로 준 쪽의 주변 확률**
2. 구한 분포는 **다 더해서 1**인지 검산
3. Likelihood P(Y|X)와 Posterior P(X|Y)의 **방향을 헷갈리지 말 것** ← 초반 최대 함정
