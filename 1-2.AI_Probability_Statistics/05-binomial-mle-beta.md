## 0. 이번 주 큰 그림 (수식 없이)

**상황**: 앞면이 잘 나오는지 모르는 동전이 하나 있음. 100번 던졌더니 앞면이 20번 나왔음.
**질문**: 이 동전의 "앞면 나올 확률"은 얼마일까? 그리고 다음에 100번 던지면 앞면이 몇 번 나올까?

이번 주 수업은 이 질문에 답하는 방법 두 가지를 배운 것임.

| 방법 | 답하는 방식 | 비유 |
|---|---|---|
| **MLE** | "20/100 = 0.2다" — 숫자 하나로 딱 답함 | 시험 한 번 보고 "얘 실력은 80점"이라고 단정 |
| **Bayesian** | "0.2 근처일 가능성이 제일 높고, 0.15~0.3 사이일 가능성이 크다" — 가능성의 분포로 답함 | 원래 알던 정보(prior) + 이번 시험 결과(데이터)를 합쳐서 "아마 75~85점 사이" |

전체 흐름:

```
① 데이터: 100번 중 앞면 20번          ← Binomial 분포로 표현
② MLE:    θ = 20/100 = 0.2            ← 숫자 하나
③ Prior:  원래 알던 정보 = Beta(5, 4)  ← 데이터 보기 전 생각
④ Posterior: Beta(25, 84)             ← 데이터 보고 업데이트한 생각
⑤ 예측:   posterior에서 θ를 5000번 뽑고, 각 θ로 100번 던지기를 흉내냄
```

이번 주 핵심 결론 3개만 먼저 외우면 됨:

1. **MLE = 성공 횟수 / 전체 횟수** (동전이면 그냥 앞면 비율)
2. **Beta(a, b)에서 성공 k번, 실패 m번 보면 → Beta(a + k, b + m)** (그냥 더하기임)
3. **데이터가 많아질수록 불확실성이 줄고, 결국 데이터가 결과를 결정함**

## 1. 먼저 알아둘 수학 기호 읽는 법

수업에서 나온 기호를 "읽는 법"과 "뜻"으로 정리함. 막히면 여기로 돌아오면 됨.

| 기호 | 읽는 법 | 뜻 (쉽게) |
|---|---|---|
| $\theta$ | 세타 | 우리가 모르는 값. 이번 주는 **동전 앞면이 나올 확률** |
| $\hat\theta$ | 세타 햇 | θ를 **추정한 값** (모자 = 추정치) |
| $p(A \mid B)$ | B일 때 A의 확률 | 세로줄 `\|` 오른쪽은 "이미 정해진 조건" |
| $Y \sim \text{Binomial}(\dots)$ | Y는 Binomial을 따른다 | 물결 `~` = "~분포를 따르는 랜덤 값" |
| $\binom{N}{k}$ | N 콤비네이션 k (nCk) | N개 중 k개 고르는 경우의 수 |
| $\sum$ | 시그마 | 전부 **더하기** |
| $\int_0^1 \dots d\theta$ | 0부터 1까지 적분 | 0~1 구간 그래프 아래 **넓이**. 칸이 무한히 잘게 쪼개진 "더하기"라고 보면 됨 |
| $\frac{d}{d\theta}$ | θ로 미분 | 그래프의 **기울기**. 기울기 = 0이면 꼭대기(또는 바닥) |
| $\arg\max_\theta f(\theta)$ | 아그맥스 | f를 **가장 크게 만드는 θ 값** (최댓값 자체가 아니라 그때의 θ) |
| $\propto$ | 비례한다 | 상수배 차이는 무시하고 **모양만 같다** |

> 핵심 감각: **∑(더하기)와 ∫(적분)는 같은 역할**임. 값이 띄엄띄엄(0, 1, 2…)이면 ∑, 연속(0~1 사이 모든 실수)이면 ∫를 씀.

## 2. Binomial Distribution (이항분포)

### 2-1. 한 줄 요약

> **"성공 확률이 θ인 걸 N번 했을 때, 성공이 딱 k번 나올 확률"** 을 계산하는 공식

### 2-2. 공식

$$
\Pr[Y=k \mid N,\theta] = \binom{N}{k}\,\theta^{k}(1-\theta)^{N-k}
$$

고등학교 때 본 $P(X=k)=\binom{n}{k}p^k(1-p)^{n-k}$ 와 **완전히 같은 식**이고 p를 θ로 바꿔 쓴 것뿐임.

### 2-3. 공식이 왜 이렇게 생겼나 (작은 예시)

동전 3번 던져서 앞면이 2번 나올 확률 (θ = 앞면 확률):

- 앞앞뒤 → $\theta \times \theta \times (1-\theta)$
- 앞뒤앞 → $\theta \times (1-\theta) \times \theta$
- 뒤앞앞 → $(1-\theta) \times \theta \times \theta$

세 경우 모두 확률이 $\theta^2(1-\theta)^1$ 로 같고, 경우의 수가 $\binom{3}{2}=3$ 가지임. 그래서

$$
\Pr[Y=2] = 3 \times \theta^2(1-\theta)^1 = \binom{3}{2}\theta^2(1-\theta)^{3-2}
$$

정리하면 공식의 각 부분은:

| 부분 | 뜻 |
|---|---|
| $\binom{N}{k}$ | 성공 k번이 **어느 자리에서** 나올지 경우의 수 |
| $\theta^k$ | 성공이 k번 나올 확률 |
| $(1-\theta)^{N-k}$ | 실패가 나머지 N−k번 나올 확률 |

- N = 1이면 **Bernoulli** 분포 (한 번 던지기)
- Binomial = Bernoulli를 N번 반복했을 때 성공 횟수

### 2-4. θ에 따라 그래프 모양이 바뀜

θ를 고정하고 k = 0, 1, 2, …, N 을 하나씩 넣으면 각각 확률이 나옴 → 막대그래프

- θ = 0.5 → 가운데(N/2 근처)에 막대가 몰린 대칭 모양
- θ = 0.1 → 앞면이 잘 안 나오니까 k가 작은 왼쪽에 몰림 (1의 개수는 줄고 0의 개수가 늘어남)
- 막대는 정수 k에서만 존재함 (앞면 2.5번 같은 건 없음) → **이산 분포**
- 막대를 다 더하면 1
- 평균 = $N\theta$ (예: 100번 × 0.2 = 20번), 분산 = $N\theta(1-\theta)$

## 3. Likelihood (우도) — 같은 식을 거꾸로 보기

### 3-1. 한 줄 요약

> 데이터는 이미 봤으니 고정하고, **"θ가 이 값이라면 지금 데이터가 나올 확률이 얼마냐"** 를 θ마다 계산한 것

### 3-2. 무엇이 달라지나

Binomial 식은 하나인데, **무엇을 고정하냐**에 따라 이름이 바뀜.

| 보는 방식 | 고정 | 바꿔보는 것 | 이름 |
|---|---|---|---|
| "θ = 0.2인 동전이면 앞면 몇 번 나올까?" | θ | k | 확률분포 (Binomial) |
| "앞면 20번 나왔는데 θ가 뭘까?" | k = 20 | θ | **Likelihood** $L(\theta)$ |

우리 상황(N = 100, k = 20)을 넣으면:

$$
L(\theta) = \binom{100}{20}\theta^{20}(1-\theta)^{80}
$$

이제 θ에 여러 값을 넣어볼 수 있음:

- θ = 0.2 넣으면 → 값이 큼 (앞면 20%짜리 동전이면 100번 중 20번은 아주 자연스러움)
- θ = 0.8 넣으면 → 값이 거의 0 (앞면 80%짜리 동전인데 20번만 나오는 건 말이 안 됨)

→ **likelihood가 크다 = 그 θ가 지금 데이터를 잘 설명한다** 는 뜻임

### 3-3. 주의: likelihood는 "θ의 확률"이 아님

- θ에 대해 넓이(적분)를 구하면 1이 아님. 이 예시는 $\int_0^1 L(\theta)\,d\theta = \frac{1}{101}$
- 그래서 likelihood를 그대로 "θ가 0.2일 확률"이라고 하면 안 됨
- 확률로 만들려면 나중에 **전체 합이 1이 되도록 나눠줘야 함** (5장의 Z)

## 4. MLE (Maximum Likelihood Estimate, 최대우도추정)

### 4-1. 한 줄 요약

> **likelihood가 가장 큰 θ를 정답으로 고르는 방법**. "지금 데이터를 가장 잘 설명하는 θ"

### 4-2. 왜 이런 기준이 필요한가

- "가장 좋은 θ"를 고르려면 **무엇이 좋은 건지 기준**부터 정해야 함
- MLE는 기준을 "**데이터가 나올 확률이 최대**"로 정한 것임

$$
\hat\theta_{\text{MLE}} = \arg\max_\theta L(\theta)
\quad \text{(L을 가장 크게 만드는 θ를 고른다)}
$$

### 4-3. 꼭대기 찾기 = 기울기가 0인 곳

L(θ) 그래프는 0~1 사이에서 언덕 모양이고 꼭대기는 θ = 0.2 근처임.
언덕 꼭대기에서는 그래프가 평평함 → **기울기(미분) = 0**. 그래서 미분해서 0이 되는 θ를 찾음.

### 4-4. 미분 과정 (한 단계씩)

**준비 — 미분 규칙 2개만 쓰면 됨**

| 규칙 | 식 | 예시 |
|---|---|---|
| ① 곱의 미분 | $(f \cdot g)' = f' \cdot g + f \cdot g'$ | 앞만 미분 × 뒤 그대로 + 앞 그대로 × 뒤만 미분 |
| ② 거듭제곱 미분 | $(\theta^n)' = n\,\theta^{n-1}$ | $(\theta^{20})' = 20\,\theta^{19}$ |
| ②-1 괄호 안이 1−θ일 때 | $((1-\theta)^n)' = n(1-\theta)^{n-1} \times (-1)$ | 괄호 안 $(1-\theta)$를 미분한 −1이 추가로 곱해짐 |

**Step 1. 상수는 무시해도 됨**

$\binom{100}{20}$ 은 그냥 큰 숫자(상수)임. 숫자를 곱해도 꼭대기 **위치**는 안 바뀌므로 신경 안 써도 됨.
그래서 $\theta^{20}(1-\theta)^{80}$ 만 미분하면 됨.

**Step 2. 곱의 미분 적용**

$f = \theta^{20}$, $g = (1-\theta)^{80}$ 로 두면

- $f' = 20\,\theta^{19}$
- $g' = 80(1-\theta)^{79} \times (-1)$

$$
\frac{dL}{d\theta} \propto 20\,\theta^{19}(1-\theta)^{80} \;-\; 80\,\theta^{20}(1-\theta)^{79} = 0
$$

**Step 3. 공통으로 들어있는 걸 앞으로 빼기 (인수분해)**

두 항 모두 $\theta^{19}$ 와 $(1-\theta)^{79}$ 를 갖고 있음:

- 첫째 항: $\theta^{19}(1-\theta)^{79} \times 20(1-\theta)$
- 둘째 항: $\theta^{19}(1-\theta)^{79} \times 80\,\theta$

$$
\theta^{19}(1-\theta)^{79}\,\Big[\,20(1-\theta) - 80\theta\,\Big] = 0
$$

**Step 4. 대괄호 안이 0이어야 함**

앞부분 $\theta^{19}(1-\theta)^{79}$ 은 θ가 0이나 1일 때만 0인데, 그건 꼭대기가 아님. 그러니 대괄호 안이 0:

$$
20 - 20\theta - 80\theta = 0 \;\Rightarrow\; 20 = 100\,\theta \;\Rightarrow\; \hat\theta_{\text{MLE}} = \frac{20}{100} = 0.2
$$

**결론: 복잡하게 미분했지만 답은 그냥 "앞면 비율"임.** 일반적으로

$$
\hat\theta_{\text{MLE}} = \frac{k}{N} = \frac{\text{성공 횟수}}{\text{전체 횟수}}
$$

### 4-5. (참고) log 써서 더 쉽게 미분하기

곱하기가 많으면 미분이 귀찮음. log를 씌우면 **곱하기 → 더하기**, **거듭제곱 → 앞으로 곱하기**로 바뀌어서 쉬워짐.
log는 값이 클수록 커지는 함수라서 log를 씌워도 꼭대기 위치는 그대로임.

$$
\log L(\theta) = \text{상수} + 20\log\theta + 80\log(1-\theta)
$$

$$
\frac{d}{d\theta}\log L = \frac{20}{\theta} - \frac{80}{1-\theta} = 0 \;\Rightarrow\; 20(1-\theta) = 80\theta \;\Rightarrow\; \theta = 0.2
$$

- 여기에 마이너스를 붙인 $-\log L$ 이 **NLL (Negative Log-Likelihood)** 임
- 딥러닝에서 쓰는 **cross-entropy loss**가 바로 이것이라, "loss를 줄인다 = likelihood를 키운다"와 같은 말임 (계획서상 11주차에 다시 나옴)

### 4-6. MLE의 약점

- **숫자 하나만** 줌 → "얼마나 확실한지"를 말해주지 못함
- **데이터가 적으면 극단적**임. 예) 3번 던져서 3번 다 앞면 → $\hat\theta = 3/3 = 1$ → "이 동전은 절대 뒷면이 안 나온다"는 이상한 결론
- **원래 알던 정보를 넣을 방법이 없음** (예: "보통 동전은 0.5 근처다")
- 이 약점들을 해결하는 게 Bayesian 방법임

## 5. Bayesian 방법 — 먼저 작은 예시로 감 잡기

연속 분포(Beta)로 바로 가면 어려우니, **θ 후보가 3개뿐인** 장난감 예시로 먼저 해봄.

### 5-1. 설정

- θ 후보: 0.2, 0.5, 0.8 셋 중 하나라고 가정
- 데이터: 5번 던져서 앞면 1번

### 5-2. 계산 표 (Prior를 똑같이 줬을 때)

| θ 후보 | ① Prior (데이터 보기 전 믿음) | ② Likelihood $\binom{5}{1}\theta(1-\theta)^4$ | ③ = ① × ② | ④ Posterior = ③ ÷ 합계 |
|---|---|---|---|---|
| 0.2 | 1/3 | 0.4096 | 0.1365 | **0.716** |
| 0.5 | 1/3 | 0.1563 | 0.0521 | 0.273 |
| 0.8 | 1/3 | 0.0064 | 0.0021 | 0.011 |
| **합계** | 1 | | **0.1908 (= Z)** | 1 |

이 표가 베이즈 정리의 전부임:

1. **Prior**: 데이터 보기 전에 각 후보를 얼마나 믿는지
2. **Likelihood**: 각 후보가 데이터를 얼마나 잘 설명하는지
3. **곱하기**: 원래 믿음에 "설명력"을 가중치로 곱함 = **reweighting**
4. **합계(Z)로 나누기**: ③의 합이 1이 아니라서, 합이 1이 되도록 맞춰줌 → 이게 확률이 됨

결과: 데이터(5번 중 1번 앞면)를 보고 나니 θ = 0.2를 71.6%로 믿게 됨.

### 5-3. Prior를 바꾸면? (사전 정보의 힘)

"회사 데이터를 보니 대부분 동전은 공정하더라" → θ = 0.5에 prior를 0.8 줌

| θ 후보 | Prior | Likelihood | Prior × Likelihood | Posterior |
|---|---|---|---|---|
| 0.2 | 0.1 | 0.4096 | 0.0410 | 0.246 |
| 0.5 | **0.8** | 0.1563 | 0.1250 | **0.750** |
| 0.8 | 0.1 | 0.0064 | 0.0006 | 0.004 |
| 합계 | 1 | | 0.1666 (= Z) | 1 |

- 같은 데이터인데 prior가 강하니 이번엔 0.5를 75%로 믿음
- 데이터가 겨우 5개라 prior를 뒤집기엔 부족한 것임. 데이터가 많아지면 결국 데이터 쪽으로 넘어감 (9장)

### 5-4. 이걸 식으로 쓰면 = 베이즈 정리

$$
\underbrace{p(\theta \mid Y)}_{\text{④ posterior}} = \frac{\overbrace{p(Y \mid \theta)}^{\text{② likelihood}} \times \overbrace{p(\theta)}^{\text{① prior}}}{\underbrace{Z}_{\text{③의 합계 = evidence}}}
$$

- θ 후보가 띄엄띄엄이면 Z = ③을 **다 더한 것** (∑)
- θ가 0~1 사이 아무 값이나 될 수 있으면(연속) Z = ③을 **적분한 것** (∫). 표의 칸이 무한히 많아진 것뿐이고 원리는 똑같음

$$
Z = \int_0^1 p(Y \mid \theta)\,p(\theta)\,d\theta
$$

- Z로 나누는 이유: posterior는 확률이라 **전부 더하면(적분하면) 1**이어야 하기 때문임. Z를 **normalization constant(정규화 상수)** 라고도 부름

## 6. 연속 버전 ① — Prior가 Uniform일 때

### 6-1. Uniform prior

사전 정보가 전혀 없으면 "θ는 0~1 중 아무거나 똑같이 가능하다"로 둠:

$$
p(\theta) = U_{[0,1]}(\theta) = 1 \quad (0 \le \theta \le 1)
$$

그래프: 0~1 구간에서 높이 1인 납작한 직사각형 (넓이 = 1 × 1 = 1)

### 6-2. Posterior 계산

$$
p(\theta \mid Y) = \frac{\binom{100}{20}\theta^{20}(1-\theta)^{80} \times 1}{\int_0^1 \binom{100}{20}\theta^{20}(1-\theta)^{80}\,d\theta}
$$

- $\binom{100}{20}$ 는 위아래 똑같이 있는 숫자라 **약분**됨
- prior가 1이라 곱해도 그대로임

$$
p(\theta \mid Y) = \frac{\theta^{20}(1-\theta)^{80}}{\int_0^1 \theta^{20}(1-\theta)^{80}\,d\theta}
$$

- 분자 $f(\theta) = \theta^{20}(1-\theta)^{80}$ : θ에 따라 바뀌는 부분 → **모양**을 결정
- 분모: 그걸 0~1까지 적분한 값 → θ가 없는 **그냥 숫자**. 넓이를 1로 맞추는 역할

문제는 이 분모 적분을 직접 하기가 너무 어렵다는 것임. 그런데 $\theta^{\square}(1-\theta)^{\square}$ 꼴의 적분은 수학자들이 이미 이름을 붙여놨음 → **Beta 함수 $B(a,b)$**. 그래서 Beta 분포를 배우는 것임.

## 7. Beta Distribution (베타분포)

### 7-1. 한 줄 요약

> **"확률값 θ 자체가 얼마일지"에 대한 분포.** 확률에 대한 확률임

- Binomial: θ를 알 때 → 앞면이 **몇 번** 나올지
- Beta: θ를 모를 때 → **θ가 얼마쯤일지**

비유: 야구 선수 타율(θ)을 모름. "이 선수 타율은 0.25~0.30 사이일 가능성이 크다"를 그래프로 그린 게 Beta 분포임.

### 7-2. 공식

$$
\text{Beta}(\theta \mid a, b) = \frac{\theta^{a-1}(1-\theta)^{b-1}}{B(a,b)}, \qquad 0 \le \theta \le 1
$$

| 부분 | 역할 |
|---|---|
| 분자 $\theta^{a-1}(1-\theta)^{b-1}$ | **모양**을 결정 (θ에 따라 바뀜) |
| 분모 $B(a,b)$ | 넓이를 1로 맞추는 **숫자** (θ와 무관) |

$$
B(a,b) = \int_0^1 \theta^{a-1}(1-\theta)^{b-1}\,d\theta
$$

- 즉 $B(a,b)$ = 분자를 0~1까지 적분한 넓이 → 분자를 이걸로 나누면 넓이가 정확히 1이 됨
- a, b가 정수면 $B(a,b) = \dfrac{(a-1)!\,(b-1)!}{(a+b-1)!}$ 로 바로 계산 가능

### 7-3. 직접 계산해보는 예시

**Beta(1, 1)**

$$
\frac{\theta^{1-1}(1-\theta)^{1-1}}{B(1,1)} = \frac{\theta^0 (1-\theta)^0}{1} = \frac{1 \times 1}{1} = 1
$$

- 아무 숫자의 0제곱 = 1 이라서 분자가 1이 됨
- 0~1에서 높이 1인 평평한 선 → **Uniform과 똑같음**. 6장의 uniform prior = Beta(1, 1) 이었음

**Beta(2, 2)**

$$
\frac{\theta^{2-1}(1-\theta)^{2-1}}{B(2,2)} = \frac{\theta(1-\theta)}{B(2,2)}, \qquad B(2,2) = \frac{1! \times 1!}{3!} = \frac{1}{6}
$$

$$
\Rightarrow \text{Beta}(\theta \mid 2,2) = 6\,\theta(1-\theta)
$$

- 2차 함수 → 가운데(θ = 0.5)가 볼록한 포물선. θ = 0, 1에서 0이고, θ = 0.5에서 높이 6 × 0.5 × 0.5 = 1.5
- 참고: $\theta(1-\theta)$ 꼴은 logistic regression에서 sigmoid 미분 $\sigma(1-\sigma)$ 로도 자주 보이는 모양임

**6장의 uniform posterior도 Beta였음**

$$
\theta^{20}(1-\theta)^{80} = \theta^{21-1}(1-\theta)^{81-1} \;\Rightarrow\; p(\theta \mid Y) = \text{Beta}(\theta \mid 21, 81)
$$

- 지수에 1을 더하면 a, b가 됨 (a − 1 = 20 → a = 21)
- 이 분포의 꼭대기는 θ = 0.2 → **사전 정보가 없으면(uniform) posterior 꼭대기 = MLE**

### 7-4. a, b를 바꾸면 모양이 어떻게 되나

**외우는 법: a = 성공 쪽 힘, b = 실패 쪽 힘**

| a, b | 모양 | 뜻 |
|---|---|---|
| a = b = 1 | 평평함 | 아무 정보 없음 |
| a = b > 1 (예: 2, 2) | 0.5 중심 볼록 | "공정한 동전 같다" |
| a > b (예: 10, 2) | 1 쪽으로 쏠림 (꼭대기 0.9) | "앞면이 잘 나오는 동전 같다" |
| a < b (예: 2, 10) | 0 쪽으로 쏠림 | "뒷면이 잘 나오는 동전 같다" |
| a + b가 커질수록 | 뾰족해짐 | 확신이 커짐 |
| a, b < 1 | 양 끝이 높은 U자 | 0이나 1 근처로 극단적일 것 같다 |

### 7-5. a, b = "미리 본 횟수"라고 생각하면 쉬움

- a − 1 = 미리 본 **성공** 횟수, b − 1 = 미리 본 **실패** 횟수
- Beta(1, 1): 미리 본 게 0번 → 정보 없음
- Beta(5, 4): 앞면 4번, 뒷면 3번을 이미 본 것 같은 상태 → "0.5 조금 넘는 것 같은데 확신은 약함"

### 7-6. 요약 통계 (참고)

| | 식 | Beta(5,4) | Beta(25,84) |
|---|---|---|---|
| 평균 | $\dfrac{a}{a+b}$ | 0.556 | 0.229 |
| 꼭대기(mode) | $\dfrac{a-1}{a+b-2}$ | 0.571 | 0.224 |
| 표준편차 (퍼진 정도) | $\sqrt{\dfrac{ab}{(a+b)^2(a+b+1)}}$ | 0.157 | 0.040 |

## 8. 연속 버전 ② — Beta Prior + Binomial → Beta Posterior

### 8-1. 설정

- Prior: θ ~ Beta(5, 4) → $\dfrac{\theta^{5-1}(1-\theta)^{4-1}}{B(5,4)}$ ("0.5 조금 넘을 것 같다"는 사전 생각)
- 데이터: 100번 중 앞면 20번 → Likelihood $\binom{100}{20}\theta^{20}(1-\theta)^{80}$

### 8-2. 계산 (5장 표와 똑같이: 곱하고 → 나누기)

$$
p(\theta \mid Y) = \frac{1}{Z} \times \binom{100}{20}\theta^{20}(1-\theta)^{80} \times \frac{\theta^{5-1}(1-\theta)^{4-1}}{B(5,4)}
$$

**Step 1. θ 없는 숫자들은 앞으로 한 덩어리로 모음**

$$
= \underbrace{\frac{\binom{100}{20}}{Z \cdot B(5,4)}}_{\text{그냥 숫자}} \times \theta^{20}\,\theta^{5-1} \times (1-\theta)^{80}(1-\theta)^{4-1}
$$

**Step 2. 밑이 같으면 지수끼리 더함** ($x^m \times x^n = x^{m+n}$)

- θ 쪽: 20 + (5 − 1) = 24 = 25 − 1
- (1−θ) 쪽: 80 + (4 − 1) = 83 = 84 − 1

$$
= \text{숫자} \times \theta^{25-1}(1-\theta)^{84-1}
$$

**Step 3. 모양이 Beta(25, 84)와 똑같음 → 답은 Beta(25, 84)**

- 모양(분자)이 Beta(25, 84)랑 똑같음
- posterior는 넓이가 1이어야 하는데, 이 모양의 넓이를 1로 만드는 숫자는 딱 하나($\frac{1}{B(25,84)}$)뿐임
- 그래서 앞의 "숫자" 덩어리는 계산 안 해도 자동으로 $\frac{1}{B(25,84)}$ 가 됨 → **어려운 Z 적분을 안 해도 됨**

$$
p(\theta \mid Y) = \frac{\theta^{25-1}(1-\theta)^{84-1}}{B(25,84)} = \text{Beta}(\theta \mid 25, 84)
$$

### 8-3. 결국 그냥 더하기임 (가장 중요)

$$
\text{Beta}(a,\ b) \;\xrightarrow{\text{성공 } k\text{번},\ \text{실패 } m\text{번}}\; \text{Beta}(a + k,\ b + m)
$$

이번 예: Beta(5, 4) + 앞면 20번, 뒷면 80번 → **Beta(5 + 20, 4 + 80) = Beta(25, 84)**

해석:

- 데이터 보기 전 생각: 평균 0.556 ("0.5 조금 넘겠지")
- 데이터: 0.2 (100번 중 20번)
- 데이터 본 후 생각: 평균 0.229, 대략 0.16 ~ 0.31 사이일 가능성 95%
- 데이터 100개가 prior(미리 본 7번 정도)보다 훨씬 많아서 데이터 쪽(0.2)으로 크게 끌려감

### 8-4. Conjugate Prior (켤레 사전분포)

> prior와 posterior가 **같은 종류의 분포**로 나오게 해주는 prior

- Beta를 prior로 쓰고 likelihood가 Binomial이면 → posterior도 Beta
- 그래서 업데이트가 "a, b에 숫자 더하기"로 끝남. 적분 지옥을 피하게 해주는 조합임

| Prior | Likelihood | Posterior |
|---|---|---|
| **Beta** | **Binomial** (Bernoulli) | **Beta** |
| Dirichlet | Multinomial (Categorical) | Dirichlet |

- Beta prior → **θ가 어떤 값일 확률**
- Binomial likelihood → **θ일 때 어떤 결과가 몇 번 나올 확률**
- 둘 다 $\theta^{\square}(1-\theta)^{\square}$ 모양이라 곱하면 지수만 더해져서 다시 Beta가 됨

### 8-5. Prior는 어디서 가져오나

- 내 사전 지식, 전문가 의견, **회사에 쌓여 있는 과거 데이터**
- 새로 측정한 데이터로 likelihood를 계산 → prior에 곱해서 **reweighting** → posterior
- 아무 정보가 없으면 uniform(Beta(1, 1))을 씀. 이때 결과 꼭대기 = MLE

## 9. 데이터가 많아지면 + 계속 업데이트하기

### 9-1. 데이터가 많을수록 확실해짐

같은 20% 비율로 데이터를 10배 늘리면 (prior는 Beta(5, 4) 그대로):

| 데이터 | Posterior | 평균 | 퍼진 정도(표준편차) |
|---|---|---|---|
| 100번 중 20번 | Beta(25, 84) | 0.229 | 0.040 |
| 1000번 중 200번 | Beta(205, 804) | 0.203 | 0.013 |

- 데이터가 많아지면 그래프가 **뾰족**해짐 → 정밀도(precision)가 높아짐
- prior 영향은 점점 사라지고 MLE(0.2)에 가까워짐
- 결국 **데이터의 양이 결과를 결정**함. prior는 데이터가 적을 때 특히 중요함

### 9-2. 업데이트는 반복 가능함

- 오늘의 posterior를 내일의 prior로 쓰면 됨. 데이터가 들어올 때마다 a, b에 계속 더하면 끝

$$
\text{Beta}(5,4) \xrightarrow{\text{앞 20, 뒤 80}} \text{Beta}(25,84) \xrightarrow{\text{앞 30, 뒤 70}} \text{Beta}(55,154)
$$

- 한 번에 넣든(batch) 나눠서 넣든(sequential) 결과가 같음. 더하기는 순서를 바꿔도 같기 때문임 → **4주차 과제(Sequential = Batch)** 를 Beta-Binomial로 보면 이렇게 간단히 확인됨

## 10. Posterior로 예측하기 — Sampling

### 10-1. 한 줄 요약

> posterior에서 θ를 **여러 번 랜덤으로 뽑고**, 뽑은 θ마다 **동전 던지기를 흉내** 내서, 앞으로 나올 결과의 분포를 얻는 것

### 10-2. 두 단계

**① Parameter prediction — θ 뽑기**

$$
\theta^{1}, \theta^{2}, \dots, \theta^{5000} \;\sim\; \text{Beta}(25, 84)
$$

- posterior 그래프가 높은 곳(0.2 근처)에서 많이 뽑히고, 낮은 곳에서는 드물게 뽑힘
- θ는 동전 안에 숨어 있어서 **직접 볼 수 없는 값** → **hidden variable (latent variable)** 이라고 부름

**② Observation prediction — 뽑은 θ로 100번 던지기 흉내**

$$
Y^{1} \sim \text{Binomial}(100,\ \theta^{1}),\quad Y^{2} \sim \text{Binomial}(100,\ \theta^{2}),\quad \dots,\quad Y^{5000}
$$

- θ¹ = 0.23이 뽑혔으면 "앞면 확률 0.23인 동전 100번 던지기"를 시뮬레이션 → 예: 25번
- θ² = 0.18이면 → 예: 17번
- 이걸 5000번 하면 "다음에 100번 던지면 앞면이 몇 번 나올지"의 **분포**가 생김
- 이 분포를 **posterior predictive distribution** 이라고 함
- 앞으로 **관측될** 값을 예측하는 거라 data prediction이 아니라 **observation prediction** 이라고 부름

### 10-3. 왜 MLE로 예측하는 것보다 좋나

| | MLE: θ = 0.2로 고정해서 예측 | Bayesian: θ를 뽑아서 예측 |
|---|---|---|
| 앞면 평균 | 20번 | 약 22.9번 |
| 퍼진 정도(표준편차) | 4.0 | 약 5.8 |

- Bayesian 쪽이 더 넓게 퍼짐 → "**θ가 정확히 0.2인지도 확실하지 않다**"는 불확실성까지 예측에 반영했기 때문임
- MLE는 θ를 확정된 값처럼 취급해서 실제보다 **자신감 과잉** 예측을 하게 됨

### 10-4. 코드로 보면 (Python)

수식보다 코드가 편하면 이렇게 보면 됨. 하는 일은 위 ①, ② 두 줄이 전부임.

```python
import numpy as np

rng = np.random.default_rng(0)
a, b = 5 + 20, 4 + 80                    # posterior = Beta(25, 84)  (그냥 더하기)

thetas = rng.beta(a, b, size=5000)       # ① θ를 5000개 뽑기
ys = rng.binomial(n=100, p=thetas)       # ② 각 θ로 100번 던지기 흉내

print(thetas.mean())   # ≈ 0.229  (θ 평균)
print(ys.mean())       # ≈ 22.9   (앞면 평균 횟수)
print(ys.std())        # ≈ 5.8    (퍼진 정도)
```

## 11. 확장 — Multinomial / Categorical, 그리고 LLM

### 11-1. 동전 → 주사위로 확장

| 결과 개수 | 1번 던지기 | N번 던지기 |
|---|---|---|
| 2개 (동전) | Bernoulli | Binomial |
| K개 (주사위) | **Categorical** | **Multinomial** |

- 주사위는 면이 6개라 θ도 6개 필요함 ($\theta_1 \sim \theta_6$, 다 더하면 1)
- Categorical = Multinomial에서 N = 1 (한 번 던지기)

$$
\text{Multinomial}(n_1,\dots,n_K \mid N, \theta_1,\dots,\theta_K) = \frac{N!}{n_1! \cdots n_K!}\,\theta_1^{n_1}\cdots\theta_K^{n_K}
$$

- Binomial 공식에서 "성공/실패 2종류"가 "K종류"로 늘어난 것뿐임
- 짝꿍 prior는 Beta를 K개로 확장한 **Dirichlet** → 토픽 모델 **LDA (Latent Dirichlet Allocation)** 가 이 조합을 씀

### 11-2. LLM이 글을 쓰는 방식 = 면이 10만 개인 주사위 던지기

- 단어가 10만 개면 → **면이 10만 개인 주사위**
- 과정
  1. 지금까지의 문장을 neural network에 넣음
  2. 마지막 softmax 층이 10만 개 단어 각각의 확률을 출력 → Categorical 분포
  3. 그 확률대로 주사위 한 번 던짐(sampling) → 다음 단어 하나 결정
  4. 그 단어를 문장 뒤에 붙여서 다시 1번으로 (auto-regressive)
  5. **EOS (End Of Sequence)** 가 나올 때까지 반복
- 확률이 제일 높은 단어만 고르는 게 아니라 확률대로 랜덤하게 뽑으니까, 같은 질문에도 매번 답이 조금씩 다름

## 12. 최종 정리 — MLE vs Bayesian

| | MLE | Bayesian |
|---|---|---|
| 답의 형태 | 숫자 하나 (0.2) | 분포 (Beta(25, 84)) |
| 계산 | 미분해서 0 → 결국 k/N | prior × likelihood ÷ Z → Beta면 그냥 더하기 |
| 사전 정보 | 못 넣음 | prior로 넣음 |
| 불확실성 | 표현 못함 | 분포 폭으로 표현 |
| 데이터 적을 때 | 극단값 (3/3 → 1) | prior가 완충 |
| 데이터 많을 때 | 정확해짐 | MLE와 거의 같아짐 |

## 자가 점검 체크리스트

- [ ] 동전 3번 중 앞면 2번 예시로 Binomial 공식이 왜 그렇게 생겼는지 설명할 수 있다
- [ ] 같은 식이 "k를 바꿀 때"는 확률분포, "θ를 바꿀 때"는 likelihood인 이유를 말할 수 있다
- [ ] MLE의 기준("데이터가 나올 확률이 최대인 θ")을 말할 수 있다
- [ ] 곱의 미분 → 인수분해 → θ = 0.2 과정을 손으로 따라 쓸 수 있다
- [ ] MLE의 약점 3가지를 말할 수 있다
- [ ] θ 후보 3개짜리 표(prior × likelihood ÷ 합계)를 직접 채울 수 있다
- [ ] Z로 나누는 이유를 설명할 수 있다 (합/넓이가 1이 되게)
- [ ] Beta(1,1) = 1, Beta(2,2) = 6θ(1−θ) 를 직접 계산할 수 있다
- [ ] a, b를 바꾸면 Beta 모양이 어떻게 바뀌는지 그릴 수 있다
- [ ] Beta(5,4) + 앞면 20, 뒷면 80 → Beta(25,84) 를 지수 더하기로 유도할 수 있다
- [ ] Z를 직접 적분하지 않아도 되는 이유를 설명할 수 있다
- [ ] conjugate prior가 무엇이고 왜 편한지 말할 수 있다
- [ ] 데이터가 늘면 posterior가 어떻게 변하는지, sequential = batch인 이유를 말할 수 있다
- [ ] parameter prediction → observation prediction 두 단계를 설명할 수 있다
- [ ] Bayesian 예측이 MLE 예측보다 넓게 퍼지는 이유를 말할 수 있다
- [ ] LLM 다음 단어 생성을 Categorical sampling으로 설명할 수 있다
