## 0. 이번 주 큰 그림

이번 주 내용은 사실 **하나의 레시피**를 여러 문제에 반복 적용한 것이다.

```
① 문제를 읽고 "모르는 것"을 X로 정의한다          (가설, hypothesis)
② X의 각 값에 대해 Prior P(X)를 정한다            (데이터 보기 전 믿음)
③ 관측 데이터의 Likelihood P(data | X)를 구한다    (X가 이거라면 이 데이터가 나올 확률)
④ Prior × Likelihood 를 곱한다                     (unnormalized posterior)
⑤ 전부 더한 값 Z로 나눠 합이 1이 되게 한다          (normalization)
⑥ 결과가 Posterior P(X | data)
⑦ 새 데이터가 오면 Posterior를 Prior 자리에 넣고 ③부터 반복  (Bayesian Update)
```

쿠키 문제, 주사위 문제, 동전(Euro) 문제 모두 이 표 하나로 풀린다. 문제마다 바뀌는 건 **X를 뭐로 잡느냐**, **Prior를 어떻게 주느냐**, **Likelihood를 어떻게 계산하느냐** 세 가지뿐이다.

```
                Prior        Likelihood
P(X | data) = ────────── × ─────────────   →  사실상  Posterior ∝ Prior × Likelihood
                  P(X)      P(data | X)
              ─────────────────────────
                     P(data) = Z   (정규화 상수, 모든 X에 대해 같은 값)
```

`∝`(비례)만 기억하면 된다. 분모 Z는 X와 상관없는 상수라서 마지막에 "합이 1이 되게 나누기"만 하면 자동으로 해결된다.

## 1. 확률의 합이 1이라는 말의 정확한 의미

**같은 조건(condition) 아래에서, 가능한 사건(event)을 전부 더하면 1**이다.

조건 C가 c₀, c₁ 두 종류, 사건 A가 a₁, a₂, a₃ 세 종류라고 하면:

```
P(a₁ | c₀) + P(a₂ | c₀) + P(a₃ | c₀) = 1     ✅  (| 뒤는 고정, 앞을 다 더함)
P(a₁ | c₀) + P(a₁ | c₁)              ≠ 1     ❌  (조건 쪽을 더하는 건 의미 없음)
```

이게 중요한 이유 → **Likelihood는 X에 대한 확률분포가 아니다.**

101 Bowls 문제에서 Likelihood 열 P(V | X)를 X 방향으로 다 더하면

```
0 + 0.01 + 0.02 + ... + 1.00 = 50.5   (≠ 1)
```

이 된다. Likelihood는 "X를 고정했을 때 데이터 쪽" 확률이라 X 방향으로 더하면 1이 될 이유가 없다. 그래서 Prior와 곱한 뒤 **반드시 정규화**를 해야 Posterior가 X에 대한 제대로 된 분포가 된다.

## 2. 분포(Distribution)와 PMF / PDF / CDF

### 2-1. Distribution
**가능한 결과들 + 각 결과의 확률**을 묶어놓은 것이다.
- 동전: {앞: 0.5, 뒤: 0.5}
- 6면 주사위: {1~6 각각 1/6}

### 2-2. PMF (Probability Mass Function) — 이산(Discrete)
결과 하나를 넣으면 그 확률을 돌려주는 함수이다. Think Bayes에서는 `Pmf` 객체(pandas Series 상속)로 표현한다.

```
PMF:  x  →  P(X = x)
조건: Σᵢ P(X = xᵢ) = 1
```

결과 개수가 n개이고 다 공평하면 각각 1/n이다 (예: bowl 101개 → 각 1/101).

### 2-3. 연속(Continuous)이면 왜 달라지나
쿠키 속 바닐라 비율 θ는 사실 0~1 사이의 **아무 실수**나 될 수 있다. 그런데 점이 무한히 많으므로

```
P(θ = 0.18732222...) = 0
```

특정 한 점의 확률은 0이다. 그래서 연속 변수는 **구간**으로 확률을 정의한다.

```
P(0.187 < θ ≤ 0.1873)
P(0.187 < θ ≤ 0.187 + Δ)
```

이 구간 확률을 구간 폭 Δ로 나누고 Δ → 0으로 보내면(= 미분) 그 점의 **밀도(Density)** 가 된다.

```
          P(θ₀ < θ ≤ θ₀ + Δ)
f(θ₀) = lim ─────────────────────     ← PDF (Probability Density Function)
        Δ→0          Δ
```

- f(θ)는 **확률이 아니라 밀도**이다 → 1보다 커도 된다.
- 확률은 밀도를 구간에서 **적분**해야 나온다: P(a < θ ≤ b) = ∫ₐᵇ f(θ) dθ

### 2-4. 이산 ↔ 연속 대응표

| | 이산 (Discrete) | 연속 (Continuous) |
|---|---|---|
| 함수 | PMF: P(X = xᵢ) | PDF: f(x) |
| 한 점의 확률 | P(X = xᵢ) > 0 가능 | 항상 0 |
| 전체 합 = 1 | Σᵢ P(X = xᵢ) = 1 | ∫₋∞^∞ f(x) dx = 1 |
| 구간 확률 | 해당 값들 더하기 | 구간 적분 |

### 2-5. CDF (Cumulative Distribution Function)

```
F(x) = P(X ≤ x) = ∫₋∞ˣ f(t) dt
```

- "x **이하**일 확률"이다 (= 가 아니라 ≤).
- 적분 기호 안의 변수 t는 이름만 빌려 쓰는 변수(dummy variable)라 무슨 문자를 써도 상관없다. 적분 범위 끝의 x와 헷갈리지 않게 t로 쓴 것이다.
- **PDF를 적분하면 CDF, CDF를 미분하면 PDF**: f(x) = dF(x)/dx

### 2-6. 이산화(Discretization)
연속인 θ를 그대로 다루기 어려우니 0, 0.01, 0.02, ..., 1.00 처럼 **101개 점으로 쪼개서** 이산 문제로 바꿔 푸는 것이다. 101 Bowls 문제가 바로 이 방식이다 → 3장.

## 3. 101 Bowls 문제 (Cookie Problem 확장)

### 3-1. 문제
- Bowl 0 = 바닐라 0%, Bowl 1 = 바닐라 1%, ..., Bowl 100 = 바닐라 100%
- 나머지는 전부 초콜릿
- bowl 하나를 랜덤으로 고르고 쿠키를 뽑았더니 바닐라 → **각 bowl일 확률은?**

### 3-2. 레시피 적용

| X (bowl) | 바닐라 비율 | Prior P(X) | Likelihood P(V \| X) |
|---|---|---|---|
| X₀ = B0 | 0% | 1/101 | 0 |
| X₁ = B1 | 1% | 1/101 | 0.01 |
| ⋮ | ⋮ | ⋮ | ⋮ |
| X₁₀₀ = B100 | 100% | 1/101 | 1 |
| **합** | | **1** | **50.5 (분포 아님)** |

- Prior: "랜덤으로 골랐다" → 전부 공평하게 1/101 → **Uniform prior**
- Likelihood: bowl x에서 바닐라가 나올 확률 = x/100

### 3-3. 바닐라 1개 관측 후

```
Posterior ∝ (1/101) × (x/100)
Z = Σ (1/101)(x/100) = 50.5 / 101 = 0.5      ← P(V), 바닐라가 나올 전체 확률
P(Bx | V) = x / 5050
```

- B0 → 0 (바닐라가 아예 없으니 불가능)
- B100 → 100/5050 ≈ 0.0198 (가장 높음)
- 그래프 모양은 **직선** (Likelihood가 x에 비례하니까)

### 3-4. 바닐라, 바닐라, 초콜릿 (VVC) 관측

같은 bowl에서 3번 뽑았을 때 데이터 전체의 Likelihood는

```
P(VVC | X) = P(V | X) × P(V | X) × P(C | X)

예) X = B1 :  P(VVC | B1) = 0.01 × 0.01 × 0.99
```

**이렇게 그냥 곱해도 되는 조건 2가지**

1. **복원추출(Sampling with replacement)** — 뽑은 쿠키를 다시 넣는다(refill). 그래야 bowl의 바닐라 비율이 매번 그대로 유지된다.
2. **각 시행이 서로 관계없음(Independent experiment)** — 첫 번째에 뭐가 나왔는지가 두 번째 결과에 영향을 주지 않는다.

결과:
- B100은 초콜릿이 없으므로 P(C | B100) = 0 → Posterior 0으로 **탈락**
- B0도 바닐라가 없으므로 탈락
- Posterior ∝ x²(1−x) 모양, **최댓값은 B67**

### 3-5. MAP (Maximum A Posteriori)
**Posterior가 가장 큰 X 값**이다. VVC면 MAP = 67이고, 이는 관측 데이터의 바닐라 비율 2/3 ≈ 0.67과 일치한다.

### 3-6. 이 문제의 진짜 의미
사실 bowl 고르기 문제가 아니라 **비율 추정(Estimating proportions)** 문제이다.
"bowl 하나가 있는데 바닐라 비율 θ를 모른다. 0~1 중 뭐든 똑같이 가능하다고 보자. 3개 뽑아서 2개가 바닐라면 θ는 얼마쯤일까?" → 이 질문의 답이 위의 Posterior이다.

이건 **동전 던지기와 완전히 같은 구조**이다 (바닐라 = 앞면, 초콜릿 = 뒷면, θ = 앞면 나올 확률). → 7장 Euro 문제로 이어진다.

## 4. 독립(Independence)

**독립 사건**: 한 사건이 다른 사건에 아무 영향을 주지 않는다. 두 사건 사이에 아무 관계가 없다.

```
A, B 독립  ⟺  P(A, B) = P(A) × P(B)
          ⟺  P(A | B) = P(A)          (B를 알아도 A의 확률이 안 바뀜)
```

쿠키 문제에서 정확히는 **bowl X가 정해졌다는 조건 아래에서** 독립이다 (조건부 독립, Conditional independence).

```
P(V₁, V₂, C₃ | X) = P(V₁ | X) × P(V₂ | X) × P(C₃ | X)
```

- X를 **알면**: 앞에서 뭐가 나왔든 다음 쿠키 확률은 x/100 그대로 → 독립
- X를 **모르면**: 바닐라를 보면 "바닐라 많은 bowl인가 보다" 하고 믿음이 바뀌고, 그러면 다음 쿠키 예측도 바뀜 → 독립 아님

그래서 Likelihood를 곱할 때는 항상 `| X` 가 붙은 상태에서 곱하는 것이다.

## 5. Bayesian Update — Sequential vs Batch

### 5-1. Posterior가 다음 Prior가 된다

| P(X) | P(V₁ \| X) | P(X \| V₁) | P(V₂ \| X) | P(X \| V₁,V₂) | P(C \| X) | P(X \| V₁,V₂,C) |
|---|---|---|---|---|---|---|
| Prior | 1번째 데이터 | Posterior ① | 2번째 데이터 | Posterior ② | 3번째 데이터 | Posterior ③ |
| | | → 다음 Prior | | → 다음 Prior | | 최종 |

데이터가 하나 올 때마다 **직전 Posterior × 새 Likelihood → 정규화** 를 반복한다.

### 5-2. 두 가지 방식

| | Sequential update | Batch update |
|---|---|---|
| 방법 | 데이터 1개씩 순서대로 업데이트 | 데이터를 모아서 한 번에 업데이트 |
| 계산 | Prior × L₁ → 정규화 → × L₂ → 정규화 → ... | Prior × (L₁ × L₂ × L₃) → 정규화 1번 |
| 결과 | **동일** | **동일** |

### 5-3. 과제: Sequential = Batch 증명

데이터 D₁, D₂가 X가 주어졌을 때 조건부 독립이라고 하자: P(D₁, D₂ | X) = P(D₁ | X) P(D₂ | X)

**Batch** (한 번에):
```
              P(D₁ | X) P(D₂ | X) P(X)
P(X | D₁,D₂) = ─────────────────────────
                     P(D₁, D₂)
```

**Sequential** (하나씩):
```
1단계:  P(X | D₁) = P(D₁ | X) P(X) / P(D₁)

2단계:  P(X | D₁)을 Prior로 사용
                    P(D₂ | X) · P(X | D₁)
        P(X | D₁,D₂) = ───────────────────────
                        P(D₂ | D₁)

                    P(D₂ | X) · P(D₁ | X) P(X)
                  = ─────────────────────────────
                        P(D₁) · P(D₂ | D₁)
```

분모의 P(D₁) · P(D₂ | D₁) = P(D₁, D₂) (Product rule) 이므로

```
Sequential 결과 = P(D₁ | X) P(D₂ | X) P(X) / P(D₁, D₂) = Batch 결과   ∎
```

(2단계에서 P(D₂ | X, D₁) = P(D₂ | X) 로 바꿀 수 있는 게 바로 조건부 독립 가정 덕분이다.)

**핵심 이유를 한 줄로**: 곱셈은 순서를 바꿔도 결과가 같고(교환법칙), 정규화는 모든 X에 똑같은 상수를 나누는 것일 뿐이라 결과 비율을 바꾸지 않는다.

### 5-4. 중간 정규화는 안 해도 된다
위 이유 때문에 Sequential로 하더라도 **중간 단계에서는 정규화를 생략하고 맨 마지막에 한 번만** 해도 최종 결과가 같다. 중간 값들은 합이 1이 아니지만 비율은 올바르게 유지된다.

단, 실제 코드에서 아주 작은 확률을 수백 번 곱하면 부동소수점 underflow(0으로 뭉개짐)가 생길 수 있다. 데이터가 많으면 중간중간 정규화하거나 log를 취해서 덧셈으로 계산하는 방식을 쓴다.

### 5-5. 숫자로 확인 (주사위 문제, 1과 7이 나옴)

**Sequential**
```
Prior             :  6면 1/3,  8면 1/3,  12면 1/3
× P(1|X)          :  1/6,  1/8,  1/12
→ 정규화 (Z₁=1/8) :  4/9,  3/9,  2/9
× P(7|X)          :  0,  1/8,  1/12   →  0,  1/24,  1/54
→ 정규화          :  0,  9/13,  4/13
```

**Batch**
```
Prior × P(1|X) × P(7|X) = (1/3)×{ (1/6)(0),  (1/8)(1/8),  (1/12)(1/12) }
                         ∝ 0,  1/64,  1/144
→ 정규화 :  0,  9/13,  4/13         (1/64 : 1/144 = 144 : 64 = 9 : 4)
```

똑같이 **8면 ≈ 0.692, 12면 ≈ 0.308**이 나온다.

### 5-6. 코드로 확인 (101 Bowls, VVC)

```python
import numpy as np

x = np.arange(101) / 100            # 가설: 바닐라 비율 0.00 ~ 1.00
prior = np.ones(101) / 101          # Uniform prior
lik = {'V': x, 'C': 1 - x}          # Likelihood

# Sequential: 하나씩 곱하고 매번 정규화
seq = prior.copy()
for d in 'VVC':
    seq = seq * lik[d]
    seq = seq / seq.sum()

# Sequential: 중간 정규화 생략, 마지막에 1번만
seq2 = prior.copy()
for d in 'VVC':
    seq2 = seq2 * lik[d]
seq2 = seq2 / seq2.sum()

# Batch: Likelihood를 먼저 전부 곱해서 한 번에
batch = prior * (lik['V'] * lik['V'] * lik['C'])
batch = batch / batch.sum()

print(np.allclose(seq, batch), np.allclose(seq2, batch))   # True True
print(seq.argmax())                                         # 67 (MAP)
```

### 5-7. 왜 Sequential이 실무에서 중요한가 — 자율주행 예시
Sequential 방식은 **현재 Posterior 하나만 들고 있으면 된다.** 예전 데이터나 예전 중간 결과를 저장할 필요가 없다.

자율주행 자동차는 매초 센서 데이터가 들어올 때마다 "지금 내 위치에 대한 Posterior"를 업데이트한다. 과거 센서 데이터를 전부 쌓아두고 매번 처음부터 다시 계산하는 게 아니라, 현재 Posterior에 새 데이터만 반영해서 계속 갱신한다. 이런 방식을 Recursive Bayesian estimation(Bayes filter)이라 부르고, Kalman filter와 Particle filter가 대표적인 구현이다. (실제 자동차는 움직이니까 "이동 예측" 단계가 추가로 들어가지만, 관측으로 업데이트하는 부분은 오늘 배운 Bayesian update 그대로이다.)

## 6. 주사위 문제 3종

### 6-1. 문제 1 — 1이 나왔을 때 6면체일 확률은?
상자에 6면, 8면, 12면 주사위가 하나씩 있다. 하나 골라서 굴렸더니 1이 나왔다.

| X | P(X) | P(Y=1 \| X) | Prior × Lik | P(X \| Y=1) |
|---|---|---|---|---|
| 6면 | 1/3 | 1/6 | 1/18 | **4/9 ≈ 0.444** |
| 8면 | 1/3 | 1/8 | 1/24 | 3/9 ≈ 0.333 |
| 12면 | 1/3 | 1/12 | 1/36 | 2/9 ≈ 0.222 |

```
Z₁ = (1/3)(1/6 + 1/8 + 1/12) = (1/3)(9/24) = 1/8
```

면이 적을수록 "1이 나올 확률"이 커서 Posterior가 높다.

**이어서 같은 주사위로 7이 나오면** (Y₂ = 7)

| X | P(X \| Y₁=1) | P(Y₂=7 \| X) | 곱하기 | P(X \| Y₁, Y₂) |
|---|---|---|---|---|
| 6면 | 4/9 | **0** (7은 불가능) | 0 | 0 |
| 8면 | 3/9 | 1/8 | (1/3)(1/8)² / Z₁ | (1/8)² / [(1/8)² + (1/12)²] = **9/13 ≈ 0.692** |
| 12면 | 2/9 | 1/12 | (1/3)(1/12)² / Z₁ | (1/12)² / [(1/8)² + (1/12)²] = 4/13 ≈ 0.308 |

앞에 붙어있던 1/3과 1/Z₁은 모든 행에 공통이라 정규화할 때 약분돼서 사라진다.

**Likelihood가 0이면 그 가설은 영구히 탈락**한다. 이후 무엇을 곱해도 0이다.

### 6-2. 문제 2 — 4번 굴려서 1, 3, 5, 7이 나옴 → 8면체일 확률은?

| X | P(X) | P(1,3,5,7 \| X) | P(X \| 1,3,5,7) |
|---|---|---|---|
| D6 | 1/3 | (1/6)(1/6)(1/6)(**0**) = 0 | 0 |
| D8 | 1/3 | (1/8)⁴ | (1/8)⁴ / [(1/8)⁴ + (1/12)⁴] = **81/97 ≈ 0.835** |
| D12 | 1/3 | (1/12)⁴ | 16/97 ≈ 0.165 |

```
(1/8)⁴ : (1/12)⁴ = 12⁴ : 8⁴ = (3/2)⁴ = 81 : 16
```

데이터가 쌓일수록 "7이 가능한 주사위 중 면이 가장 적은 것(D8)"으로 확신이 몰린다.

### 6-3. 문제 3 — Prior가 공평하지 않은 경우
상자에 D4 1개, D6 2개, D8 3개, D12 4개, D20 5개 (총 15개). 하나 골라 굴렸더니 7이 나옴 → 8면체일 확률은?

| 개수 | X | P(X) | P(7 \| X) | Prior × Lik | P(X \| 7) |
|---|---|---|---|---|---|
| 1 | D4 | 1/15 | 0 | 0 | 0 |
| 2 | D6 | 2/15 | 0 | 0 | 0 |
| 3 | D8 | 3/15 | 1/8 | 1/40 | **9/23 ≈ 0.391** |
| 4 | D12 | 4/15 | 1/12 | 1/45 | 8/23 ≈ 0.348 |
| 5 | D20 | 5/15 | 1/20 | 1/60 | 6/23 ≈ 0.261 |

```
Z = 1/40 + 1/45 + 1/60 = (9 + 8 + 6) / 360 = 23/360
```

- Prior는 **개수 / 전체 개수(15)** 로 정한다.
- D20은 Prior가 제일 크지만 Likelihood가 작아서 결국 D8이 가장 높다. Prior와 Likelihood가 서로 줄다리기하는 구조이다.
- 팁: Prior를 1, 2, 3, 4, 5처럼 정규화 안 된 상태로 넣어도 된다. 어차피 마지막 정규화에서 해결된다.

## 7. Prior를 정하는 것이 제일 중요하다

문제를 풀 때 실제로 어려운 부분은 계산이 아니라 **텍스트로 된 문제를 읽고 X를 정의하고 그에 맞는 Prior를 정하는 것**이다.

- "랜덤으로 고른다" → Uniform prior (전부 1/n)
- "D4 1개, D6 2개 ..." → 개수에 비례
- **사전 정보(prior information)** 가 있으면 반영한다. 예: "이 상황에서 온도는 20~30도 사이여야 한다"는 조건을 알고 있으면, 그 범위 밖 온도의 Prior를 0으로 두고 범위 안에만 확률을 준다. 이런 조건을 전체 수식(formulation)에 넣고 싶을 때 확률적 모델링(probabilistic modeling)을 쓰는 것이다.

Prior를 0으로 준 값은 데이터가 아무리 들어와도 Posterior가 0이다. 그래서 "절대 불가능"이 확실한 게 아니면 Prior를 0으로 두지 않는 게 안전하다.

## 8. Random Variable, Bernoulli, Binomial, Multinomial

### 8-1. Random Variable (확률변수)
이름은 "변수"지만 실제로는 **함수**이다. 실제 세계에서 일어난 결과(앞면/뒷면, 쿠키 색 등)를 **숫자 공간으로 매핑하는 함수**를 확률변수라 한다.

```
Y : {앞면, 뒷면} → {1, 0}
    Y(앞면) = 1,  Y(뒷면) = 0
```

결과를 숫자로 바꿔야 더하기, 평균, 확률 계산을 할 수 있다.

### 8-2. Bernoulli distribution — 동전 1번
```
Y ~ Bernoulli(θ),      Y ∈ {0, 1}   (0 = 뒷면, 1 = 앞면)

P(Y = 1 | θ) = θ
P(Y = 0 | θ) = 1 − θ
```

θ는 **1(앞면)이 나올 확률**이다. Binomial에서 N = 1인 특수한 경우이다: Bin(θ, N=1) = Bernoulli(θ)

**데이터 {1, 1, 1, 0}의 Likelihood**
```
P(Data | θ) = P(1|θ) · P(1|θ) · P(1|θ) · P(0|θ)
            = θ · θ · θ · (1 − θ)
            = θ³(1 − θ)          ← Likelihood (θ에 대한 함수)
```

앞면 개수만큼 θ, 뒷면 개수만큼 (1−θ)를 곱하면 된다. Uniform prior면 Posterior ∝ θ³(1−θ)이고, 이를 θ로 미분해서 0이 되는 점을 찾으면

```
d/dθ [θ³(1−θ)] = 3θ² − 4θ³ = θ²(3 − 4θ) = 0   →  θ = 3/4
```

MAP = 0.75 = 관측된 앞면 비율(3/4)이다. (101 Bowls에서 MAP=67이 2/3이었던 것과 같은 원리)

### 8-3. Binomial distribution — 동전 N번 던져서 앞면이 몇 번?
```
Y ~ Bin(θ, N)
  θ : 1(앞면)이 나올 확률
  N : 던지는 횟수 (동전 개수)
  Y : 앞면이 나온 총 횟수 → 가능한 값 0, 1, ..., N
```

**N = 2 일 때** (Y ∈ {0, 1, 2})
```
P(Y = 0 | θ, N=2) = (1 − θ)²          ← 뒤뒤
P(Y = 1 | θ, N=2) = 2θ(1 − θ)         ← 앞뒤, 뒤앞  (경우의 수 2가지)
P(Y = 2 | θ, N=2) = θ²                ← 앞앞
                    ──────────
합 = 1
```

합이 1인 이유: 1² = (θ + (1−θ))² = θ² + 2θ(1−θ) + (1−θ)² — 이항정리 전개항이 그대로 각 확률이다. 그래서 이름이 **이항(Binomial)** 분포이다.

**N = 3 일 때** (Y ∈ {0, 1, 2, 3})
```
P(Y=0) = (1−θ)³
P(Y=1) = 3θ(1−θ)²
P(Y=2) = 3θ²(1−θ)
P(Y=3) = θ³
```

**일반식**
```
P(Y = k | θ, N) = C(N, k) · θᵏ · (1 − θ)ᴺ⁻ᵏ          C(N, k) = N! / (k!(N−k)!)
```
- C(N, k): N번 중 어느 k번이 앞면인지 고르는 경우의 수 ("N choose k")
- 기댓값: E[Y] = Nθ

### 8-4. Multinomial distribution — 면이 3개 이상일 때
동전(2면) → 주사위(K면)로 일반화한 것이다. 예: 3면체 주사위

```
θ₁ = 1번 면이 나올 확률
θ₂ = 2번 면이 나올 확률
θ₃ = 3번 면이 나올 확률
θ₁ + θ₂ + θ₃ = 1

N번 굴려서 1번 면 k₁번, 2번 면 k₂번, 3번 면 k₃번 나올 확률:
P(k₁, k₂, k₃) = N! / (k₁! k₂! k₃!) · θ₁^k₁ · θ₂^k₂ · θ₃^k₃
```

Binomial은 Multinomial에서 K = 2 (θ₁ = θ, θ₂ = 1 − θ)인 경우이다.

### 8-5. Bernoulli 여러 번 = Binomial 한 번 (Sequential = Batch의 또 다른 모습)
데이터 {1,1,1,0}을
- Bernoulli로 하나씩 업데이트 → Likelihood 곱 = θ³(1−θ)
- Binomial로 "4번 중 3번 앞면" 한 번에 업데이트 → Likelihood = C(4,3)θ³(1−θ) = 4θ³(1−θ)

앞의 상수 4는 θ와 무관해서 정규화하면 사라진다 → **Posterior 동일**. Think Bayes Ch.4의 `update_binomial`이 바로 이 원리로 250번 업데이트를 한 번에 처리한다.

## 9. Euro 문제 (Think Bayes Ch.4)

### 9-1. 문제
벨기에 1유로 동전을 세워서 250번 돌렸더니 앞면 140번, 뒷면 110번. 한 통계학 강사가 "공정한 동전이면 이만큼 극단적인 결과가 나올 확률은 7% 미만이라 의심스럽다"고 했다. **이 데이터가 동전이 치우쳤다는 증거가 되는가?**

### 9-2. 7%는 어디서 나왔나 — Binomial로 확인
θ = 0.5 (공정한 동전), N = 250 이라고 가정하면 Y ~ Bin(0.5, 250)

```
기댓값           : 125
P(Y = 125)       ≈ 5.0%   (가장 가능성 높은 값인데도 정확히 이것일 확률은 낮음)
P(Y = 140)       ≈ 0.8%
P(Y ≥ 140)       ≈ 3.3%   (오른쪽 꼬리)
P(Y ≤ 110)       ≈ 3.3%   (왼쪽 꼬리, 기댓값에서 15만큼 반대로 떨어진 쪽)
양쪽 합          ≈ 6.6%   → "7% 미만"의 출처
```

이건 "동전이 공정하다면 이런 데이터가 나오기 어렵다"는 말일 뿐, **"동전의 앞면 확률 θ가 얼마인가"에는 답하지 않는다.**

### 9-3. Bayesian estimation
- X = θ (이 동전의 앞면 확률), 0~1을 101개로 이산화 → **101 Bowls 문제와 수학적으로 완전히 동일**
- Prior: Uniform
- Likelihood: 앞면이면 θ, 뒷면이면 1−θ
- 140번 × θ, 110번 × (1−θ) 곱하고 정규화 → Posterior ∝ θ¹⁴⁰(1−θ)¹¹⁰
- **MAP = 0.56 = 140/250**
- Posterior를 보면 0.4 미만, 0.7 초과는 거의 불가능하고 0.5~0.6 사이가 가장 유력하다.

### 9-4. Triangle prior와 Swamping the priors
"동전이 아무리 찌그러져도 θ = 0.1이나 0.9까지는 안 갈 것 같다" → 0.5 근처에 확률을 더 주는 **삼각형 모양 Prior**를 쓸 수도 있다.

Uniform prior와 Triangle prior로 각각 같은 데이터(250번)를 업데이트하면 **두 Posterior가 거의 똑같아진다.**

→ **Swamping the priors**: 데이터가 충분히 많으면 Prior가 달라도 Posterior는 같은 곳으로 수렴한다. Prior가 주관적이라는 비판에 대한 좋은 답이다. (반대로 데이터가 적을 때는 Prior 선택이 결과에 크게 영향을 준다.)

### 9-5. Binomial likelihood로 한 번에
250번을 하나씩 곱하는 대신 "250번 중 140번 앞면"의 Binomial 확률을 Likelihood로 한 번에 곱해도 결과가 같다 (8-5와 같은 원리). 훨씬 효율적이다.

```
Likelihood(θ) = C(250, 140) · θ¹⁴⁰ · (1−θ)¹¹⁰
```

### 9-6. Bayes's Theorem vs Bayesian Statistics
101 Bowls와 Euro 문제는 계산이 똑같지만 철학적으로 두 가지가 다르다.

| | 101 Bowls | Euro 문제 |
|---|---|---|
| Prior | 문제에서 "랜덤으로 고른다"고 정해줌 → 논란 없음 | 사람이 선택해야 함 → **주관적** |
| 추정 대상 | 랜덤으로 뽑은 bowl → 확률 붙이는 게 자연스러움 | 동전의 물리적 성질 θ → 원래 랜덤한 게 아님 |
| 분류 | Bayes's Theorem 적용 | **Bayesian Statistics** |

- **Bayes's Theorem**: 확률의 수학 법칙. 누구도 반대하지 않는다.
- **Bayesian Statistics**: 랜덤하지 않은 대상(동전의 θ, 우주의 나이 등)도 "모르니까" 확률로 표현하고, 주관적 Prior를 허용한다. 그래서 역사적으로 논쟁이 있었다.
- Bayesian 관점에서 확률 = **불확실성에 대한 믿음의 정도**. Prior는 "동전 일반에 대한 믿음", Posterior는 "데이터를 본 뒤 이 동전에 대한 믿음"이다.

## 10. 공식 요약

```
[Bayes]
P(X | D) = P(D | X) P(X) / P(D)
Posterior ∝ Prior × Likelihood
Z = P(D) = Σₓ P(D | X) P(X)                         (정규화 상수)

[합 = 1]
Σₐ P(a | c) = 1           (같은 조건 c에서 사건 a를 다 더함)
Σₓ P(D | X) ≠ 1 (일반적)   (Likelihood는 X에 대한 분포 아님)

[이산 / 연속]
Σᵢ P(X = xᵢ) = 1   ⟺   ∫ f(x) dx = 1
P(X = 특정 한 점) = 0  (연속)
f(x) = lim Δ→0  P(x < X ≤ x+Δ) / Δ                 (PDF)
F(x) = P(X ≤ x) = ∫₋∞ˣ f(t) dt,   f(x) = F'(x)     (CDF)

[독립]
P(A, B) = P(A) P(B)
P(D₁, D₂ | X) = P(D₁ | X) P(D₂ | X)                (조건부 독립)

[Sequential = Batch]
Prior × L₁ × L₂ × ... × Lₙ  → 정규화 (한 번이든 매번이든 결과 동일)

[Bernoulli]   P(Y=1|θ) = θ,  P(Y=0|θ) = 1−θ
[Binomial]    P(Y=k | θ, N) = C(N,k) θᵏ (1−θ)ᴺ⁻ᵏ,   E[Y] = Nθ
[Multinomial] P(k₁,...,k_K) = N!/(k₁!···k_K!) · Π θᵢ^kᵢ,   Σ θᵢ = 1

[MAP]  X_MAP = argmaxₓ P(X | D)
```
