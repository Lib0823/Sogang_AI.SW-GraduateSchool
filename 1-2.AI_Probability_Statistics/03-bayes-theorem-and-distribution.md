## 0. 핵심 용어

| 용어 | 한국어 | 의미 |
|---|---|---|
| Hypothesis / Parameter | 가설 / 파라미터 | 알고 싶은 대상. 베이즈 식에서 X 자리 |
| Observation / Data | 관측값 / 데이터 | 실제 측정 결과. 값을 이미 알고 있음. 베이즈 식에서 조건(Y) 자리 |
| Prior | 사전확률 | 데이터를 보기 전 가설의 확률 P(X) |
| Likelihood | 우도 / 가능도 | 가설이 사실일 때 이 관측값이 나올 확률 P(Y\|X) |
| Evidence | 증거 / 주변 가능도 | 가설과 무관하게 관측값이 나올 전체 확률 P(Y) |
| Posterior | 사후확률 | 데이터를 본 뒤 업데이트된 가설의 확률 P(X\|Y) |
| Joint Probability | 결합확률 | 여러 확률변수가 동시에 특정 값을 가질 확률. 테이블의 **칸 하나 그대로**의 값 |
| Marginal Probability | 주변확률 | 다른 변수를 모두 더해서(없애서) 얻은 한 변수의 확률 |
| Marginalization | 주변화 | 한 변수 축을 따라 전부 더해 그 변수를 없애는 과정 |
| Normalization Constant | 정규화 상수 | 확률의 합이 1이 되도록 나눠주는 값. 보통 Z로 표기 |
| Latent (Hidden) Variable | 잠재 변수 | 직접 관측할 수 없는 변수 (예: 어떤 주사위를 던졌는지) |
| PMF (Probability Mass Function) | 확률질량함수 | 이산 확률변수의 각 값 → 확률로 매핑하는 함수 |
| MAP (Maximum A Posteriori) | 최대 사후확률 추정 | 사후확률이 가장 큰 가설을 고르는 것 |

## 1. 복습 — 세 가지 규칙

지난 시간에 다룬 세 규칙이다.

| 규칙 | 다른 이름 | 역할 |
|---|---|---|
| Sum Rule (더하기 규칙) | Marginalization | 조인트 → 마지널 |
| Product Rule (곱하기 규칙) | Chain Rule | 조인트 = 마지널 × 컨디셔널 |
| Bayes' Rule (베이즈 규칙) | Bayes' Theorem | P(Y\|X) → P(X\|Y) 뒤집기 |

### 1.1 Joint Probability 테이블

- 확률변수가 2개 이상일 때 그 확률분포를 **Joint(조인트)** 라고 함
- 현재 다루는 것은 **이산(Discrete)** 확률변수 → 확률값이 정확한 숫자로 나오는 **PMF**
- 예시: X는 x₁~x₅ (5개 값), Y는 y₁~y₃ (3개 값) → 5×3 테이블

```
          y₁     y₂     y₃
  x₁      ·      ·      ·
  x₂      ·      ·      ·
  x₃      ·     0.05    ·     ← x₃ 행 합 = 0.11
  x₄      ·      ·      ·
  x₅      ·      ·      ·
```

- 테이블의 **칸 하나**가 곧 조인트 확률 P(X=xᵢ, Y=yⱼ)임

### 1.2 Sum Rule (Marginalization)

**X=x₃일 확률** → x₃ 행에서 가능한 Y 값 3개를 모두 더함

```
P(X=x₃) = P(x₃, y₁) + P(x₃, y₂) + P(x₃, y₃)

일반화:  P(X) = Σ_Y P(X, Y)
```

**Y=y₂일 확률** → y₂ 열에서 X 값 5개를 모두 더함

```
P(Y=y₂) = Σ_{k=1}^{5} P(X=x_k, Y=y₂)
```

- 한 변수 축을 따라 전부 더하면 그 변수가 **사라짐** → 결과를 **Marginal Probability**, 이 과정을 **Marginalization**이라 부름
- 직관적으로는 뻔하지만 수식 한 줄로 쓰면 헷갈리기 쉬움 → 항상 테이블의 행/열 합으로 떠올리면 됨

**연속(Continuous) 확률변수로 확장**

| | 이산 (Discrete) | 연속 (Continuous) |
|---|---|---|
| 분포 | Probability Mass | Probability Density |
| 주변화 | Σ (덧셈) | ∫ (적분) |

```
P(Y) = ∫ P(X, Y) dX
```

→ 컨셉은 동일하고 **덧셈이 적분으로 바뀔 뿐**임

### 1.3 Conditional Probability

**P(Y=y₂ | X=x₃)**: X=x₃인 경우로 **세상을 한정**했을 때 Y=y₂일 확률

- x₃ 행만 보면 합이 0.11밖에 안 됨
- 그 안에서 0.05가 차지하는 비율이 조건부 확률임

```
P(Y=y₂ | X=x₃) = P(X=x₃, Y=y₂) / P(X=x₃)
               = 0.05 / 0.11
               ≈ 0.455
```

### 1.4 Product Rule (Chain Rule)

위 식을 정리하면 조인트 = 마지널 × 컨디셔널

```
P(X=x₃, Y=y₂) = P(X=x₃) · P(Y=y₂ | X=x₃)

일반화:
P(X, Y) = P(X) · P(Y | X)
        = P(Y) · P(X | Y)      ← 순서를 바꿔도 성립
```

- 조인트 확률이 두 확률의 **곱**으로 표현되므로 Product Rule이라 부름

## 2. Graphical Model과 Chain Rule

### 2.1 두 변수

```
 ( X ) ──→ ((Y))
```

- 화살표: **Y는 X에 의존**함 (X가 Y를 확률적으로 결정)
- 노드에 **색칠(음영)** 이 되어 있으면 → 그 변수를 **측정(관측)했다**는 뜻
- 이 그림이 의미하는 조인트 분해:

```
P(X, Y) = P(X) · P(Y | X)
```

- 수학적으로는 P(Y)·P(X|Y)도 맞지만, **이 그림과는 대응되지 않으므로** 그렇게 쓰지 않음
- 논문에서 수식을 일일이 쓰는 대신 변수 간 의존 구조를 그림으로 표현할 때 사용함

### 2.2 세 변수

**(a) X → Y, X → Z, Y → Z (모든 방향 연결)**

X에서 시작 → 나머지 (Y, Z)를 한 묶음으로 보고 분해 → 다시 Y, Z를 분해

```
P(X, Y, Z) = P(X) · P(Y, Z | X)
           = P(X) · P(Y | X) · P(Z | X, Y)
```

**(b) X → Z ← Y (Z가 X, Y 둘 다에 의존)**

```
P(X, Y, Z) = P(X) · P(Y) · P(Z | X, Y)
```

- 변수는 3개지만 **화살표 구조에 맞는 3개 항의 곱**으로 표현됨
- "결정"이 아니라 확률이므로 정확히는 **의존성(Dependency)** 이 있다고 표현함

### 2.3 변수 m+1개로 일반화

```
X₀ → X₁ → X₂ → ... → X_m
```

일반적인 Chain Rule:

```
P(X_{0:m}) = P(X₀) · P(X₁|X₀) · P(X₂|X₀,X₁) · ... · P(X_m | X₀, ..., X_{m-1})
```

- `X_{0:m}` 은 X₀부터 X_m까지 전체의 조인트를 나타내는 표기임

**Markov 가정**을 적용하면: Xₙ은 **바로 이전 Xₙ₋₁에만** 의존함

```
P(X_{0:m}) = P(X₀) · P(X₁|X₀) · P(X₂|X₁) · ... · P(X_m|X_{m-1})
```

- X₀는 **Initial Condition**이 됨
- X₁이 정해지면 X₂가, X₂가 정해지면 X₃가 결정되는 구조 → **Markov Chain**
- 더 앞의 상태는 현재 상태에 직접 영향을 주지 않음

## 3. Bayes' Theorem

### 3.1 유도

Product Rule을 양방향으로 쓰면

```
P(X=x₃, Y=y₂) = P(X=x₃) · P(Y=y₂ | X=x₃)
P(X=x₃, Y=y₂) = P(Y=y₂) · P(X=x₃ | Y=y₂)
```

두 식을 같다고 놓고 정리하면

```
                    P(X=x₃) · P(Y=y₂ | X=x₃)
P(X=x₃ | Y=y₂) = ─────────────────────────────
                          P(Y=y₂)

  Posterior       =   Prior × Likelihood
                     ─────────────────────
                          Evidence
```

### 3.2 각 항의 의미

| 항 | 이름 | 의미 |
|---|---|---|
| P(X=x₃ \| Y=y₂) | Posterior | 데이터 y₂를 본 뒤 X=x₃일 확률 |
| P(X=x₃) | Prior | 데이터 보기 전 X=x₃일 확률 |
| P(Y=y₂ \| X=x₃) | Likelihood | X=x₃라는 값이 정해졌을 때 y₂가 나올 확률 |
| P(Y=y₂) | Evidence | 어떤 X든 상관없이 y₂가 나올 전체 확률 |

- 조건 자리의 **Y는 데이터**임 → 값을 **이미 알고 있다**는 뜻
- X는 **알고 싶은 메인 확률변수** (가설, 파라미터)

### 3.3 조인트 vs 사후확률 구분

- 카드 3장(y₁, y₂, y₃) 중 한 장을 뽑았더니 **y₂**가 나온 상황
- y₂를 나오게 할 수 있는 X는 5가지(x₁~x₅)임
- **P(X=x₃, Y=y₂) = 0.05** → 테이블 전체에서 그 칸의 확률
- **P(X=x₃ | Y=y₂)** → y₂가 **데이터로 주어졌을 때**, y₂ 열의 5개 칸 중에서 x₃가 차지하는 비율
- 두 값은 **서로 다른 문제**의 답임

### 3.4 Evidence 전개 (Sum Rule + Product Rule)

변수 하나(Y)만 있는 Evidence를 두 변수짜리로 바꿈

```
P(Y=y₂) = Σ_{k=1}^{5} P(X=x_k, Y=y₂)                  ← Sum Rule
        = Σ_{k=1}^{5} P(X=x_k) · P(Y=y₂ | X=x_k)       ← Product Rule
```

- 실제 연구에서 다루는 문제는 대부분 **조인트 테이블이 아니라 조건부 확률(Likelihood)** 로 주어짐
- 따라서 Evidence는 거의 항상 위 두 번째 형태로만 계산 가능함

**일반화 시 주의점**

```
               P(X) · P(Y=y₂ | X)
P(X | Y=y₂) = ─────────────────────────────────────
               Σ_k P(X=x_k) · P(Y=y₂ | X=x_k)
```

- 분자의 x₃를 X로 일반화해도 **분모는 바뀌지 않음** (분모는 이미 모든 x_k에 대해 더한 값)

### 3.5 실제 계산 순서

1. 분자(Prior × Likelihood)를 **모든 x_k에 대해** 계산
2. 그것들을 **전부 더하면** 분모(Evidence)
3. 각 분자를 분모로 나누면 → x₁~x₅ 각각의 **Posterior** 5개가 모두 나옴

### 3.6 확률 업데이트 관점 (Diachronic Bayes)

```
P(X | Y) = P(X) · [ P(Y | X) / P(Y) ]
            ↑              ↑
          Prior      업데이트 비율
```

- 처음 생각한 확률(또는 주어진 자료의 확률) = **Prior** → 조건 없음
- **데이터를 측정**함 → 뒤쪽 비율만큼 Prior가 바뀜 → **Posterior** → 조건(데이터)이 붙음
- 예: 처음 보는 과자가 맛있을 확률은 반반. 먹어보니(측정) 맛있음 → 맛있을 확률이 올라감
- **데이터에 의해 확률이 업데이트된다**는 것이 베이즈의 핵심임
- "Diachronic"은 "시간에 따른 변화"라는 뜻 → 새 데이터를 볼수록 가설의 확률이 변함

**Evidence를 계산할 수 있는 조건** — 가설 집합이 다음을 만족해야 함

- **Mutually Exclusive**: 가설 중 하나만 참일 수 있음
- **Collectively Exhaustive**: 가설 중 하나는 반드시 참임

### 3.7 Normalization Constant와 ∝ 표기

```
P(X | Y=data) = P(X) · P(Y=data | X) / Z

Z = Σ_x P(x) · P(Y=data | x)      ← Normalization Constant
```

- Z로 나누면 Posterior의 합이 1이 됨 → 이 과정이 **Normalization**
- 매번 Z를 쓰기 번거로우므로 논문에서는 다음과 같이 씀

```
P(X | Y=data) ∝ P(X) · P(Y=data | X)
```

- `∝` : "비례한다"
- **주의**: ∝ 표기가 Z 계산을 생략해도 된다는 뜻은 아님
  - 숨은 의미: 모든 x에 대해 분자를 계산 → 더해서 Z를 구함 → 나눠줌
  - **확률분포 자체**를 구하려면 Z가 반드시 필요함
  - 단, Posterior를 최대화하는 **MAP Estimation**에서는 argmax만 찾으면 되므로 Z가 필요 없음 (이후 수업에서 다룸)
- 이런 축약 표기 때문에 논문/전공서 읽기가 어려워짐 → 기호의 의미가 헷갈리면 LLM에 자기 해석이 맞는지 확인하며 익히면 됨

## 4. Random Variable이란

- MML Ch.6: Random Variable은 **Sample Space → Target Space** 로의 **매핑(함수)** 임
- 이름은 "변수"지만 실제로는 **함수**임
- 예: 동전
  - Sample Space = {앞면, 뒷면}
  - X(앞면) = 1, X(뒷면) = 0
- 범주형(Categorical) 값도 숫자로 할당(assign)하면 됨
  - 예: 월·화·수·목·금 → 0, 1, 2, 3, 4 (또는 1~5)
  - 컴퓨터로 계산하기 위해 숫자로 바꿔둔 것
- 범주형은 모두 이산이므로 **배열 연산(Array Operation)** 으로 계산 가능함

## 5. Bayes Table — 문제 풀이 틀

베이즈 문제는 다음 **분할 정복(Divide-and-Conquer)** 순서로 풀면 됨

1. **가설(X)과 데이터(D)를 정의**함 ← 가장 중요. 여기서 막히면 문제를 못 품
2. 각 가설의 **Prior** P(X)를 구함
3. 각 가설 하에서 데이터의 **Likelihood** P(D|X)를 구함
4. 나머지는 테이블이 계산함

| X | Prior P(X) | Likelihood P(D\|X) | Unnorm P(X)·P(D\|X) | Posterior P(X\|D) |
|---|---|---|---|---|
| x₁ | | | ① | ① / Z |
| x₂ | | | ② | ② / Z |
| ... | | | ... | ... |
| | | | **Z = Σ Unnorm** | 합 = 1 |

- **Likelihood 열의 합은 1이 아니어도 됨** → 각각 서로 다른 가설에 조건부인 확률이기 때문
- **Unnorm** = Unnormalized Posterior (정규화 전 사후확률)
- Unnorm 열의 합 = Evidence = Z

Python(pandas)으로 옮기면 다음 흐름임

```python
table['unnorm']    = table['prior'] * table['likelihood']
Z                  = table['unnorm'].sum()
table['posterior'] = table['unnorm'] / Z
```

> ⚠️ **시험 포인트**: 시험 문제도 이 Bayes Table 형태로 출제됨. 답안은 알아볼 수 있게 깔끔하게 정리해야 함 (알아볼 수 없으면 점수 없음)

## 6. 수업 예제

### 6.1 Cookie Problem

**상황**

- 가게에서 쿠키를 주문함. 점원이 안 보이는 뒤쪽 박스 2개 중 **무작위로 하나**를 골라 쿠키를 꺼내 줌
- Bowl 1: 바닐라 30 + 초코 10
- Bowl 2: 바닐라 20 + 초코 20
- 꺼낸 만큼 자동으로 다시 채워진다고 가정 (복원 추출)
- 먹어보니 **바닐라** → 데이터 발생
- 질문: 이 바닐라 쿠키가 **Bowl 1에서 왔을 확률**은?

**핵심**: 점원이 무작위로 박스를 고른다는 **프로세스 모델**을 알고 있으므로 Prior를 정할 수 있음 (만약 점원이 항상 가까운 박스만 고른다면 Prior가 달라짐)

| X | Prior | Likelihood P(V\|X) | Unnorm | Posterior |
|---|---|---|---|---|
| B₁ | 1/2 | 30/40 = 3/4 | 3/8 | **3/5 = 0.6** |
| B₂ | 1/2 | 20/40 = 1/2 | 1/4 | **2/5 = 0.4** |
| | | | Z = 5/8 | 1 |

```
P(V) = (1/2)(3/4) + (1/2)(1/2) = 5/8

P(B₁|V) = (3/8) / (5/8) = 3/5 = 0.6
P(B₂|V) = (1/4) / (5/8) = 2/5 = 0.4
```

- 검산: 같은 조건에서 모든 x의 Posterior 합 = 1 → 0.6 + 0.4 = 1
- 직접 계산도 가능: 두 박스 쿠키 수가 같고 박스 선택 확률도 같으므로 모든 쿠키가 동일 확률 → 바닐라 50개 / 전체 80개 = 5/8

### 6.2 Dice Problem

**상황**

- 상자에 6면체, 8면체, 12면체 주사위가 1개씩 있음
- 무작위로 하나를 골라 던졌더니 **1**이 나옴
- 어느 주사위를 던졌는지는 보이지 않음 → **Latent(Hidden) Variable**
- 질문: 6면체였을 확률은?

**직관적 접근**

- ① 셋 중 하나니까 1/3 → 데이터를 무시한 것 (Prior 그대로)
- ② 6면체면 1/6, 8면체면 1/8, 12면체면 1/12 확률로 1이 나옴 → 이 비율대로 나누면? → Prior가 균등하므로 실제로 이 비율이 답이 됨

**셜록 홈즈식 추론** = 베이즈 추론

- 용의자(가설) 각각에 대해 "이 사람이 범인이라면 이런 증거가 나올 확률"을 따져보는 방식이 반복됨

**풀이**

| X | Prior | Likelihood P(1\|X) | Unnorm | Posterior |
|---|---|---|---|---|
| d6 | 1/3 | 1/6 | 1/18 | **4/9** |
| d8 | 1/3 | 1/8 | 1/24 | **3/9 = 1/3** |
| d12 | 1/3 | 1/12 | 1/36 | **2/9** |
| | | | Z = 1/8 | 1 |

```
Z = (1/3)(1/6 + 1/8 + 1/12) = (1/3)(9/24) = 1/8

P(d6 | 1) = (1/3)(1/6) / [(1/3)(1/6 + 1/8 + 1/12)]
          = (1/6) / (1/6 + 1/8 + 1/12)       ← 공통인 1/3이 약분됨
          = 4/9
```

- Prior 1/3이 분자·분모 모두에 공통으로 곱해져 있으므로 밖으로 빼면 약분됨
- 6면체가 가장 가능성이 높은 이유: 관측된 결과(1)를 만들어낼 **Likelihood가 가장 크기** 때문

### 6.3 Monty Hall Problem ⭐

**상황**

- 문 3개 중 하나 뒤에 자동차, 나머지 2개는 꽝(염소)
- 참가자가 **1번 문**을 선택함
- 진행자 Monty는 모든 문 뒤를 알고 있음 → **3번 문**을 열어 꽝을 보여줌
- 질문: 2번 문으로 **바꿀 것인가?**

**진행자 행동 가정**

1. Monty는 항상 문 하나를 열고 바꿀 기회를 줌
2. 참가자가 고른 문과 자동차가 있는 문은 **절대 열지 않음**
3. 참가자가 자동차 문을 골랐다면 나머지 두 문 중 **무작위**로 엶

**흔한 오답**: 남은 문이 2개니까 50:50 → 틀림

**가설과 데이터 정의**

- X = xᵢ : **자동차가 i번 문 뒤에 있다** (단순히 "문"이 아니라 "그 문 뒤에 차가 있다"는 가설)
- D : **Monty가 3번 문을 열었다** (그리고 꽝이었다)

**Likelihood 계산**

- **차가 1번 뒤**: 참가자가 1번을 골랐으니 1번은 못 엶 → 2, 3번 중 하나를 무작위로 엶 → P(D|x₁) = **1/2**
- **차가 2번 뒤**: 1번(참가자 선택)도 2번(차)도 못 엶 → 3번을 열 수밖에 없음 → P(D|x₂) = **1**
- **차가 3번 뒤**: 차가 있는 문은 못 엶 → P(D|x₃) = **0**

| X | Prior | Likelihood P(D\|X) | Unnorm | Posterior |
|---|---|---|---|---|
| x₁ (차가 1번) | 1/3 | 1/2 | 1/6 | **1/3** |
| x₂ (차가 2번) | 1/3 | 1 | 1/3 | **2/3** |
| x₃ (차가 3번) | 1/3 | 0 | 0 | **0** |
| | | | Z = 1/2 | 1 |

**결론**: 바꾸면 이길 확률 **2/3**, 안 바꾸면 **1/3** → **바꾸는 것이 유리**함

- 바꾼다고 반드시 당첨되는 것은 아니지만 **확률이 높아짐**
- 감성(찍은 문에 대한 미련)을 내려놓고 냉철하게 계산하면 바꿔야 함 → 경제학에서 합리적 의사결정을 설명할 때 자주 쓰는 문제임

**왜 2/3인가**

- Monty가 문을 여는 행동 자체가 **정보**임
- 3번이 꽝이라는 명백한 정보 외에, **"차가 2번 뒤에 있을 때 3번을 열 가능성이 더 높다"** 는 미묘한 정보가 있음
- 따라서 데이터(3번을 엶)는 **2번 가설을 지지하는 증거**가 됨

## 7. Think Bayes Ch.2 연습문제 (2.7)

### 7.1 Coin (Trick Coin)

- 상자에 일반 동전(앞/뒤) 1개, 트릭 동전(양면 모두 앞면) 1개
- 무작위로 하나를 골랐더니 한쪽 면이 **앞면(Head)**
- 질문: 트릭 동전일 확률은?

| X | Prior | Likelihood P(Head\|X) | Unnorm | Posterior |
|---|---|---|---|---|
| x₁ 일반 동전 | 1/2 | 1/2 | 1/4 | **1/3 ≈ 33.3%** |
| x₂ 트릭 동전 | 1/2 | 1 | 1/2 | **2/3 ≈ 66.7%** |
| | | | Z = 3/4 | 1 |

```
P(Y=Head) = P(x₁)P(Head|x₁) + P(x₂)P(Head|x₂)
          = (1/2)(1/2) + (1/2)(1) = 3/4          ← 전체 확률

P(x₂ | Head) = (1/2)(1) / (3/4) = 2/3
```

### 7.2 Children (두 아이 문제)

- 아이가 둘인 사람에게 "둘 중 딸이 있나요?" → **Yes**
- 질문: 둘 다 딸일 확률은?
- 힌트: 동일한 확률의 가설 4개로 시작

| X | Prior | Likelihood P(Yes\|X) | Unnorm | Posterior |
|---|---|---|---|---|
| GG | 1/4 | 1 | 1/4 | **1/3** |
| GB | 1/4 | 1 | 1/4 | 1/3 |
| BG | 1/4 | 1 | 1/4 | 1/3 |
| BB | 1/4 | 0 | 0 | 0 |
| | | | Z = 3/4 | 1 |

→ 답: **1/3 ≈ 33.3%** (1/2가 아님)

### 7.3 Monty Hall 변형

**조건 변경**: Monty는 **가능하면 항상 2번**을 열고, 어쩔 수 없을 때(차가 2번 뒤)만 3번을 엶. 참가자는 1번 선택.

**① Monty가 2번을 열었을 때 → 차가 3번 뒤일 확률은?**

- 차가 1번 뒤: 2번을 열 수 있으니 항상 2번을 엶 → 1
- 차가 2번 뒤: 2번은 못 열고 3번을 열었을 것 → 0
- 차가 3번 뒤: 2번을 열 수 있으니 항상 2번을 엶 → 1

| X | Prior | P(2번 open \| X) | Unnorm | Posterior |
|---|---|---|---|---|
| 차가 1번 | 1/3 | 1 | 1/3 | **1/2** |
| 차가 2번 | 1/3 | 0 | 0 | **0** |
| 차가 3번 | 1/3 | 1 | 1/3 | **1/2** |
| | | | Z = 2/3 | 1 |

→ **1/2** (바꿔도 안 바꿔도 같음)

**② Monty가 3번을 열었을 때 → 차가 2번 뒤일 확률은?**

- 차가 1번 뒤: 2번을 열었을 것 → 0
- 차가 2번 뒤: 3번을 열 수밖에 없음 → 1
- 차가 3번 뒤: 2번을 열었을 것 → 0

| X | Prior | P(3번 open \| X) | Unnorm | Posterior |
|---|---|---|---|---|
| 차가 1번 | 1/3 | 0 | 0 | **0** |
| 차가 2번 | 1/3 | 1 | 1/3 | **1** |
| 차가 3번 | 1/3 | 0 | 0 | **0** |
| | | | Z = 1/3 | 1 |

→ **1** (차는 확실히 2번 뒤)

- 진행자의 행동 규칙(가정)이 바뀌면 Likelihood가 바뀌고, 결론도 완전히 달라짐

### 7.4 M&M's

- 1994년 봉지 색 비율: Brown 30%, **Yellow 20%**, Red 20%, **Green 10%**, Orange 10%, Tan 10%
- 1996년 봉지 색 비율: Blue 24%, **Green 20%**, Orange 16%, **Yellow 14%**, Red 13%, Brown 13%
- 1994년 봉지 1개, 1996년 봉지 1개. 어느 게 어느 해인지 모름
- 각 봉지에서 하나씩 꺼냈더니 **노랑 1개, 초록 1개**
- 질문: 노란 것이 1994년 봉지에서 나왔을 확률은?

**가설 정의가 핵심**

- A: 노랑은 1994년, 초록은 1996년 봉지에서 나옴
- B: 노랑은 1996년, 초록은 1994년 봉지에서 나옴

| X | Prior | Likelihood P(Y,G\|X) | Unnorm | Posterior |
|---|---|---|---|---|
| A (Y=1994, G=1996) | 1/2 | 0.2 × 0.2 = 0.04 | 0.020 | **≈ 0.74** |
| B (Y=1996, G=1994) | 1/2 | 0.14 × 0.1 = 0.014 | 0.007 | **≈ 0.26** |
| | | | Z = 0.027 | 1 |

```
P(A | Y,G) = 0.020 / 0.027 ≈ 0.741
P(B | Y,G) = 0.007 / 0.027 ≈ 0.259
```

**Odds 표현**

```
Odds(A : B) = P(A|D) / P(B|D) = 0.04 / 0.014 = 20/7 ≈ 2.86 : 1
```

- 두 Posterior의 비율에서는 Z가 약분되고, Prior가 같으면 **Likelihood 비율**만 남음

## 8. Think Bayes Ch.3 — Distributions

### 8.1 Distribution과 PMF

- **Distribution(분포)**: 가능한 결과들과 각 결과의 확률의 집합
  - 동전: {앞, 뒤} 각각 약 1/2
  - 6면체 주사위: {1, ..., 6} 각각 1/6
- **PMF (Probability Mass Function)**: 결과가 이산일 때, 각 결과 → 확률로 매핑하는 함수
- 책에서는 `empiricaldist` 라이브러리의 `Pmf` 클래스를 사용함
  - pandas `Series`를 상속함 → `qs`(값들), `ps`(확률들)
  - `pmf[x]`: 없는 값이면 KeyError / `pmf(x)`: 없는 값이면 0 반환
  - `normalize()`: 정규화 후 **정규화 전 합(= 데이터의 전체 확률)** 을 반환함
- 가설의 Prior를 담은 Pmf → **Prior Distribution**, 업데이트 후 → **Posterior Distribution**

### 8.2 Cookie Problem 재풀이 — 순차 업데이트

Pmf를 쓰면 데이터가 여러 개일 때 **연속 업데이트**가 쉬움 (복원 추출, 같은 박스에서 계속 꺼냄)

| 관측 | Likelihood (B₁, B₂) | Posterior B₁ | Posterior B₂ |
|---|---|---|---|
| (시작) | — | 0.5 | 0.5 |
| 바닐라 | 3/4, 1/2 | 0.6 | 0.4 |
| 바닐라 | 3/4, 1/2 | ≈ 0.692 | ≈ 0.308 |
| 초코 | 1/4, 1/2 | ≈ 0.529 | ≈ 0.471 |

- **이전 Posterior가 다음 업데이트의 Prior**가 됨
- 바닐라 2개 + 초코 1개 후에는 거의 50:50에 가까워짐

### 8.3 101 Bowls ⭐

**상황**

- Bowl 0 ~ Bowl 100, 총 **101개** 박스
- Bowl x에는 바닐라가 **x%** 들어 있음 (나머지는 초코)
  - Bowl 0: 전부 초코 / Bowl 100: 전부 바닐라
- 박스를 무작위로 골라 쿠키 1개를 꺼냈더니 **바닐라**
- 질문: 각 Bowl x에서 나왔을 확률은?

**Prior**: 모든 박스가 동일 확률 → **Uniform Distribution**

```
P(X = B_x) = 1/101
```

**Likelihood**: 박스의 바닐라 비율

```
P(V | X = B_x) = x / 100    →  0, 0.01, 0.02, ..., 0.99, 1
```

| X | Prior | Likelihood P(V\|X) | Unnorm | Posterior |
|---|---|---|---|---|
| B₀ | 1/101 | 0 | (1/101)·0 | 0 |
| B₁ | 1/101 | 0.01 | (1/101)·0.01 | (1/101)·0.01 ÷ (1/2) |
| ⋮ | ⋮ | ⋮ | ⋮ | ⋮ |
| B₅₀ | 1/101 | 0.5 | (1/101)·0.5 | (1/101)·0.5 ÷ (1/2) |
| ⋮ | ⋮ | ⋮ | ⋮ | ⋮ |
| B₁₀₀ | 1/101 | 1 | (1/101)·1 | (1/101)·1 ÷ (1/2) |

**Likelihood 합 계산 (가우스 방식)**

```
S  = 0    + 0.01 + ... + 0.99 + 1       (101개 항)
S  = 1    + 0.99 + ... + 0.01 + 0       (역순)
────────────────────────────────────
2S = 1    + 1    + ... + 1    + 1  = 101 × 1 = 101

→ S = 50.5
```

**Evidence (정규화 상수)**

```
Z = P(V) = Σ (1/101) · (x/100) = (1/101) × 50.5 = 1/2
```

- Prior를 정규화하지 않고 1로 두고 계산하면 Unnorm 합이 50.5가 됨 → 이 경우 50.5로 나누면 됨 (결과는 동일)

**Posterior**

```
P(B_x | V) = (1/101)(x/100) / (1/2) = x / 5050     ∝ x
```

- Bowl 0은 바닐라가 없으므로 **0**
- Bowl 100이 **가장 높음**
- Likelihood가 박스 번호에 비례하므로 Posterior 모양은 **직선**

**데이터 추가에 따른 Posterior 모양 변화** (복원 추출, 같은 박스에서 계속)

| 관측 데이터 | Posterior ∝ | 모양 | 특징 |
|---|---|---|---|
| 바닐라 1개 | x | **직선** | Bowl 100이 최대 |
| 바닐라 2개 | x² | **곡선** (위로 휘는) | 번호 큰 박스일수록 급격히 높음 |
| 바닐라 2개 + 초코 1개 | x²(1 − x) | **봉우리** | Bowl 100 제외(초코 없음), 최대값 Bowl 67 |

- 초코 Likelihood = 1 − x/100
- 바닐라 2 + 초코 1 이후 최대값이 **Bowl 67** → 관측된 바닐라 비율 **2/3**과 일치
- 사후확률이 가장 높은 가설 = **MAP (Maximum A Posteriori)** → 여기서는 67

**Batch Update = Sequential Update**

- 데이터를 하나씩 순차 업데이트하든, 한 번에 모아서(바닐라 2 + 초코 1의 Likelihood를 곱해서) 업데이트하든 결과는 같음

```
순차:  Prior → ×P(V|x) → 정규화 → ×P(V|x) → 정규화 → ×P(C|x) → 정규화
일괄:  Prior × P(V|x) · P(V|x) · P(C|x) → 정규화 한 번
```

**본질적 의미**: 이 문제는 사실 박스 문제가 아니라 **비율(Proportion) 추정** 문제임

- 박스 하나의 바닐라 비율을 모르는데 0~1 사이 어떤 값이든 동일하게 가능하다고 생각할 때
- 3개를 뽑아 2개가 바닐라였다면 → 바닐라 비율에 대한 추정 = 위의 Posterior Distribution
- 다음 장(Ch.4 Estimating Proportions)에서 **Binomial Distribution**과 함께 이어짐

### 8.4 Dice Problem 재풀이 — 순차 업데이트

- 1차: 1이 나옴 → Posterior (d6, d8, d12) = (4/9, 1/3, 2/9)
- 2차: 같은 주사위로 **7**이 나옴
  - Likelihood = (0, 1/8, 1/12) → 6면체로는 7이 나올 수 없으므로 **0**

| X | 1차 후 | Likelihood (7) | 2차 후 |
|---|---|---|---|
| d6 | 4/9 | 0 | **0** |
| d8 | 1/3 | 1/8 | **≈ 0.692** |
| d12 | 2/9 | 1/12 | **≈ 0.308** |

**일반화된 업데이트 규칙** (n면체 주사위, 관측값 data)

```
Likelihood = 1/n     (data ≤ n 인 경우)
           = 0       (data > n 인 경우 → 불가능한 결과)

Posterior ∝ Prior × Likelihood → 정규화
```

- 불가능한 결과(관측값이 면의 개수보다 큼)에 대한 체크가 반드시 필요함

## 9. 과제

### 9.1 Monty Hall — 문 4개

> 수업 중 지명되면 앞에 나와서 풀이해야 함 (제출 필수는 아님)

**문제**: 문이 4개. 참가자가 **1번**을 선택, 진행자가 **4번**을 열었더니 꽝. 자동차가 각 문 뒤에 있을 확률은?

**Prior**

```
P(x₁) = P(x₂) = P(x₃) = P(x₄) = 1/4
```

**Likelihood** (진행자가 4번을 열 확률)

- 차가 1번 뒤: 2, 3, 4번 중 무작위 → **1/3**
- 차가 2번 뒤: 1번(선택), 2번(차) 제외 → 3, 4번 중 무작위 → **1/2**
- 차가 3번 뒤: 1번, 3번 제외 → 2, 4번 중 무작위 → **1/2**
- 차가 4번 뒤: 차 있는 문은 못 엶 → **0**

| X | Prior | Likelihood P(D\|X) | Unnorm | Posterior |
|---|---|---|---|---|
| x₁ | 1/4 | 1/3 | 1/12 | **1/4 (25%)** |
| x₂ | 1/4 | 1/2 | 1/8 | **3/8 (37.5%)** |
| x₃ | 1/4 | 1/2 | 1/8 | **3/8 (37.5%)** |
| x₄ | 1/4 | 0 | 0 | **0** |
| | | | Z = 1/3 | 1 |

```
P(D) = (1/4)(1/3) + (1/4)(1/2) + (1/4)(1/2) + (1/4)(0)
     = 2/24 + 3/24 + 3/24 = 8/24 = 1/3

P(x₁|D) = (1/12) / (1/3) = 1/4
P(x₂|D) = (1/8)  / (1/3) = 3/8
P(x₃|D) = (1/8)  / (1/3) = 3/8
P(x₄|D) = 0
```

→ 1번을 유지하면 25%, 2번 또는 3번으로 바꾸면 **37.5%** → **바꾸는 것이 유리**함

### 9.2 예습 — Binomial / Beta Distribution

**Binomial Distribution (이항분포)**

- 성공 확률이 p인 시행을 **n번** 독립 반복할 때 성공 횟수 k의 분포

```
P(k | n, p) = C(n, k) · p^k · (1 − p)^(n−k)
```

- 101 Bowls에서 "바닐라 비율 p인 박스에서 n개 뽑아 k개가 바닐라"일 Likelihood가 바로 이 형태임

**Beta Distribution (베타분포)**

- **0~1 사이 값(비율, 확률)** 에 대한 연속 분포

```
Beta(p | α, β) ∝ p^(α−1) · (1 − p)^(β−1)
```

- Beta(1, 1) = 0~1 균등분포 → 101 Bowls의 Uniform Prior에 해당
- 101 Bowls의 바닐라 2 + 초코 1 Posterior ∝ p²(1 − p)¹ → **Beta(3, 2)** 모양
  - 최빈값(Mode) = (α − 1)/(α + β − 2) = 2/3 → MAP 67과 일치
- Beta Prior × Binomial Likelihood → Posterior도 Beta가 됨 (**Conjugate Prior**, Think Bayes Ch.18)

## 10. 공식 요약

```
[Sum Rule]
P(X) = Σ_Y P(X, Y)                (연속: ∫ P(X, Y) dY)

[Product Rule]
P(X, Y) = P(X) P(Y|X) = P(Y) P(X|Y)

[Chain Rule]
P(X₀, ..., X_m) = P(X₀) Π_{n=1}^{m} P(Xₙ | X₀, ..., Xₙ₋₁)

[Markov]
P(X₀, ..., X_m) = P(X₀) Π_{n=1}^{m} P(Xₙ | Xₙ₋₁)

[Conditional]
P(Y|X) = P(X, Y) / P(X)

[Bayes]
P(X|D) = P(X) P(D|X) / P(D)

[Evidence]
P(D) = Σ_k P(x_k) P(D|x_k) = Z

[비례 표기]
P(X|D) ∝ P(X) P(D|X)

[Odds]
P(A|D) / P(B|D) = [P(A) P(D|A)] / [P(B) P(D|B)]
```
