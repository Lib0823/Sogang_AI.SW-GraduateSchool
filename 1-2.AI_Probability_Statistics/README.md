# AI Probability and Statistics

<br/>

서강대학교 AI·SW 대학원 **인공지능확률통계** 강의 내용을 정리한 저장소입니다.
담당 교수는 서용덕(`yndk@sogang.ac.kr`)이며, 머신러닝과 데이터 분석에서 쓰이는
확률통계 이론을 확률공간·확률분포 모델에서 시작해 베이즈 추론과 파라미터 추정,
확률과정(Random/Markov Process)까지 다룹니다. 각 주차 노트는 `NN-주제.md` 형태의
단일 마크다운 파일로 정리합니다.

<br/>

> *이 저장소의 자료는 학습 및 개인 복습 목적으로 정리한 것이며, 실제 강의
> 내용과 표현상 차이가 있을 수 있습니다.*
