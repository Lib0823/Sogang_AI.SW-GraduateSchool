# 블록 0 — 준비 ⏱ 15분

## 0-1. 기호 읽는 법

| 기호 | 읽는 법 | 뜻 |
|---|---|---|
| `P(A)` | A의 확률 | — |
| `P(A, B)` | A와 B의 **결합**확률 | **동시에** 일어날 확률 (콤마 = 그리고) |
| `P(A \| B)` | B일 때 A의 확률 | **세로줄 오른쪽은 이미 확정된 조건** |
| `θ` | 세타 | 모르는 값 (보통 "성공 확률") |
| `θ̂` | 세타 햇 | θ의 **추정치** |
| `Σ` | 시그마 | 다 더하기 |
| `∫ … dθ` | 적분 | 다 더하기의 연속 버전 (그래프 아래 넓이) |
| `C(N,k)` | N 콤비네이션 k | N개 중 k개 고르는 경우의 수 = `N!/(k!(N−k)!)` |
| `n!` | n 팩토리얼 | 1×2×…×n (단 **0! = 1**) |
| `∝` | 비례한다 | 상수배 차이 무시, **모양만 같다** |
| `argmax_θ f(θ)` | 아그맥스 | f를 가장 크게 만드는 **θ 값** |

> ⚠️ **`P(A|B)`와 `P(B|A)`는 완전히 다른 값입니다.** 이 과목 최대 함정입니다.

## 0-2. 영어 해독 사전 — 시험지가 영어입니다

### 지시어

| 영어 | 뜻 | 보이면 할 일 |
|---|---|---|
| **Compute / Find** | 구하라 | 숫자를 내라 |
| **Prove / Show** | 증명하라 | 식 변형 (버려도 되는 문제일 가능성 높음) |
| **Give your answer probabilistically** | 확률로 답하라 | **베이즈 표를 그려라** |

### 용어

| 영어 | 한국어 | 표의 어디 |
|---|---|---|
| **marginal distribution** | 주변분포 | **한 줄을 다 더해라** |
| **conditional distribution** | 조건부분포 | **칸 ÷ 그 줄의 합** |
| **prior** | 사전확률 | 첫째 열 |
| **likelihood** | 우도 | 둘째 열 |
| **posterior** | 사후확률 | 마지막 열 (**구하려는 답**) |
| **density function** | 밀도함수 | **상수까지** 계산하라 |
| **log-likelihood ℓ(θ)** | 로그우도 | log 씌우고 **미분 = 0** |
| **θ_MLE** | 최대우도추정 | `d/dθ[log L] = 0` |
| **θ_MAP** | 최대사후확률추정 | `d/dθ[log L + log prior] = 0` |
| **i.i.d.** | 독립동일분포 | **그냥 곱해도 된다**는 허가 |
| **prevalence** | 유병률 | **Prior** |
| **sensitivity** | 민감도 | `P(양성\|감염)` |
| **specificity** | 특이도 | `P(음성\|정상)` |
| **PMF** | 확률질량함수 | 각 값의 확률을 **전부 나열** |
| **proportion** | 비율 | θ |

### 문장 패턴

| 영어 | 대응 |
|---|---|
| "Suppose I have a box that contains…" | **Prior = 개수 비율** |
| "I choose a die, roll it, and get a 7" | **데이터 D = 7** |
| "What is the probability that I chose…" | **Posterior를 묻는 것** |
| "Monty opens Door 4 and reveals a goat" | **데이터 D = 4번을 열었다** |
| "the result is Y = {1, 1, 0, 1, 1}" | 앞면 4, 뒷면 1 |
| "What happens as you vary the value of y?" | **말로 설명하는 문제** (부분점수 쉬움) |

> 💡 **a, b, c로 쪼개진 문제는 선물입니다.** a만 맞춰도 점수가 들어옵니다.

## 0-3. 쓰는 수학은 이게 전부

```
지수 더하기   x^m · x^n = x^(m+n)        ← 블록 4의 전부
0제곱         x^0 = 1
팩토리얼      5! = 120,  0! = 1
분수 나눗셈   (3/8) ÷ (5/8) = 3/5        ← 분모가 같으면 분자만 본다
log 미분      (log θ)' = 1/θ,  (log(1−θ))' = −1/(1−θ)   ← 블록 7~9에서만
```

# 블록 1 — 표에서 읽기 ⏱ 35분 · 기출 1번 (10점)

> 수업 노트 [1주차 §2·3](./01-fundamentals-of-probability-and-bayes.md) / [2주차 §1](./02-sum-product-bayes.md) — **기출과 숫자까지 같은 표**

## 배우기 — 하는 일은 두 가지

```
marginal(주변)      →  한 줄을 전부 더한다
conditional(조건부) →  칸 ÷ 그 줄의 합
```

**조건부의 직관**: `p(x|Y=y₂)`는 **"y₂ 행만 남기고 그걸 새로운 100%로 삼는 것"**. 그래서 분모가 y₂ 행의 합입니다.

> ⚠️ **분모는 항상 "조건으로 준 쪽"의 합**입니다. 조건이 `Y=y₂`면 **y₂ 행**의 합.

<br/>

### 📝 기출 1번

> Consider the following bivariate distribution p(x,y). Compute:
> (a) The marginal distributions p(x) and p(y)
> (b) The conditional distributions p(x|Y=y₂) and p(y|X=x₁)

| | x₁ | x₂ | x₃ | x₄ | x₅ |
|---|---|---|---|---|---|
| **y₁** | 0.01 | 0.02 | 0.03 | 0.10 | 0.10 |
| **y₂** | 0.05 | 0.10 | 0.05 | 0.07 | 0.20 |
| **y₃** | 0.10 | 0.05 | 0.03 | 0.05 | 0.04 |

<details>
<summary><b>▶ 해설 보기</b></summary>

**(a) p(x)** — 세로로 더한다

| | x₁ | x₂ | x₃ | x₄ | x₅ | 합 |
|---|---|---|---|---|---|---|
| p(x) | **0.16** | **0.17** | **0.11** | **0.22** | **0.34** | 1.00 ✓ |

**p(y)** — 가로로 더한다

| | y₁ | y₂ | y₃ | 합 |
|---|---|---|---|---|
| p(y) | **0.26** | **0.47** | **0.27** | 1.00 ✓ |

**(b) p(x | Y=y₂)** — y₂ 행(합 **0.47**)이 분모

| | x₁ | x₂ | x₃ | x₄ | x₅ |
|---|---|---|---|---|---|
| | 0.05/0.47 | 0.10/0.47 | 0.05/0.47 | 0.07/0.47 | 0.20/0.47 |
| **답** | **0.106** | **0.213** | **0.106** | **0.149** | **0.426** |

**p(y | X=x₁)** — x₁ 열(합 **0.16**)이 분모

| | y₁ | y₂ | y₃ |
|---|---|---|---|
| | 0.01/0.16 | 0.05/0.16 | 0.10/0.16 |
| **답** | **0.0625** | **0.3125** | **0.625** |

> 둘 다 합 = 1 ✓

</details>

## ⚠️ 틀리는 지점

1. **분포는 전부 써야 합니다.** `p(x|Y=y₂)`는 **5개 값**을 다 써야 10점입니다.
2. **분모 혼동.** 조건이 `Y=y₂`면 분모는 y₂ **행**의 합이지, 어떤 열의 합이 아닙니다.

<br/>

# 블록 2 — 베이즈 표 ⏱ 45분 · 기출 3번 (10점)

> 수업 노트 [4주차 §6-3](./04-bayes-update.md) — **기출과 완전히 같은 문제**
> ⭐ **이 블록이 전체의 핵심입니다.** 블록 3·6이 전부 같은 표를 씁니다.

## 배우기 — 네 칸짜리 표

```
     Prior      ×   Likelihood   =  Unnorm   →   ÷ Z    =  Posterior
 (데이터 보기 전)   (이 가설이면      (곱하기)    (다 더함)  (최종 답)
                   이 데이터가 나올 확률)
```

**가장 쉬운 예로 감을 잡습니다.**

> 상자 A에 빨간공 3개·흰공 1개, 상자 B에 빨간공 1개·흰공 3개.
> 하나를 골라 공을 꺼냈더니 **빨강**. A에서 나왔을 확률은?

| 상자 | ① 고를 확률 | ② 빨강이 나올 확률 | ③ ①×② | ④ ③ ÷ 합계 |
|---|---|---|---|---|
| A | 1/2 | **3/4** | 3/8 | **3/8 ÷ 4/8 = 3/4** |
| B | 1/2 | **1/4** | 1/8 | 1/8 ÷ 4/8 = 1/4 |
| | | | 합계 **4/8** | 합 = 1 ✓ |

**①이 Prior, ②가 Likelihood, ④가 Posterior입니다.** 이게 베이즈 정리의 전부입니다.

> 💡 **요령**: Prior가 둘 다 1/2로 **같으면 약분됩니다.** Likelihood 비율 `3/4 : 1/4 = 3:1` → 바로 **3/4, 1/4**.

<br/>

### 📝 기출 3번

> Suppose I have a box that contains **1 die that is 4-sided, 2 dice that are 6-sided, 3 dice that are 8-sided, 4 dice that are 12-sided, and 5 dice that are 20-sided**. I choose a die, roll it, and get a **7**. What is the probability that I chose an **8-sided** die?

<details>
<summary><b>▶ 해설 보기</b></summary>

**Prior** = 개수 / 전체(1+2+3+4+5 = **15**)
**Likelihood** = 그 주사위로 7이 나올 확률 → ⚠️ **4면체·6면체는 7이 안 나오므로 0**

| X | Prior | Likelihood | Unnorm | **Posterior** |
|---|---|---|---|---|
| D4 | 1/15 | **0** | 0 | **0** |
| D6 | 2/15 | **0** | 0 | **0** |
| D8 | 3/15 | 1/8 | 1/40 | **9/23 ≈ 0.391** |
| D12 | 4/15 | 1/12 | 1/45 | 8/23 ≈ 0.348 |
| D20 | 5/15 | 1/20 | 1/60 | 6/23 ≈ 0.261 |
| | | | **Z = 23/360** | 합 = 1 ✓ |

```
(3/15)(1/8)  = 1/40  = 9/360
(4/15)(1/12) = 1/45  = 8/360      ← 분모를 360으로 통일하면 분자 비율만 남는다
(5/15)(1/20) = 1/60  = 6/360

Z = (9+8+6)/360 = 23/360
P(D8 | 7) = 9/360 ÷ 23/360 = 9/23
```

### 답: **9/23 ≈ 39.1%**

</details>

## ⚠️ 틀리는 지점

1. **"이 결과가 나올 수 있나?"를 먼저 묻습니다.** 못 나오면 Likelihood = 0, 그 가설은 영구 탈락.
2. **D20이 Prior 1등인데 답이 아닙니다.** Likelihood(1/20)가 작아 밀립니다 — Prior와 Likelihood의 줄다리기.

<br/>

### ✏️ 연습 2-A

> 상자 A에 빨간공 **2**개·흰공 **3**개, 상자 B에 빨간공 **4**개·흰공 **1**개.
> 하나를 골라 꺼냈더니 **빨강**. **A**에서 나왔을 확률은?

<details>
<summary><b>▶ 해설 보기</b></summary>

| 상자 | Prior | Likelihood | Unnorm | Posterior |
|---|---|---|---|---|
| A | 1/2 | 2/5 | 2/10 | **1/3 ≈ 0.333** |
| B | 1/2 | 4/5 | 4/10 | 2/3 ≈ 0.667 |
| | | | Z = 6/10 | 합 = 1 ✓ |

> Prior가 같으므로 Likelihood 비율 `2/5 : 4/5 = 1 : 2` → 바로 **1/3, 2/3**.

</details>

<br/>

### ✏️ 연습 2-B

> 상자에 **6면체 2개, 8면체 1개, 10면체 3개, 20면체 4개**. 하나 굴려 **9**가 나왔다.
> **10면체**일 확률은?

<details>
<summary><b>▶ 해설 보기</b></summary>

전체 **10개**. ⚠️ **9는 6면체·8면체로 못 나온다 → 둘 다 0**

| X | Prior | Likelihood | Unnorm | Posterior |
|---|---|---|---|---|
| D6 | 2/10 | 0 | 0 | **0** |
| D8 | 1/10 | 0 | 0 | **0** |
| D10 | 3/10 | 1/10 | 3/100 | **3/5 = 0.6** |
| D20 | 4/10 | 1/20 | 2/100 | **2/5 = 0.4** |
| | | | Z = 5/100 | 합 = 1 ✓ |

### 답: **3/5 = 60%**

> 기출(7)에서는 8면체가 **살아있었는데**, 여기서는 9 > 8이라 **탈락**합니다. 숫자가 바뀌면 탈락자도 바뀝니다.

</details>

<br/>

### ✏️ 연습 2-C

> 그릇 1에 바닐라 30·초코 10, 그릇 2에 바닐라 20·초코 20.
> 하나를 골라 꺼냈더니 **초코**. **그릇 1**이었을 확률은?

<details>
<summary><b>▶ 해설 보기</b></summary>

| 그릇 | Prior | Likelihood P(초코) | Unnorm | Posterior |
|---|---|---|---|---|
| B₁ | 1/2 | 10/40 = 1/4 | 1/8 | **1/3 ≈ 0.333** |
| B₂ | 1/2 | 20/40 = 1/2 | 1/4 | 2/3 ≈ 0.667 |
| | | | Z = 3/8 | 합 = 1 ✓ |

> 바닐라였다면 0.6이었는데, 초코를 보니 **반대로 기울었습니다.**

</details>

# 블록 3 — 베이즈 표 응용 ⏱ 25분 · 기출 11번 (10점)

> **블록 2와 완전히 같은 표입니다.** 영어 용어 3개만 추가로 외우면 됩니다.

## 배우기 — 용어 3개

| 영어 | 한국어 | 식 | 표의 어느 열 |
|---|---|---|---|
| **prevalence** | 유병률 | `P(H=1)` | **Prior** |
| **sensitivity** | 민감도 | `P(Y=1\|H=1)` | Likelihood |
| **specificity** | 특이도 | `P(Y=0\|H=0)` | Likelihood |

**외우는 법**: Likelihood 표는 **각 행(같은 H 조건)의 합이 1**입니다.

| 진실 \ 검사 | Y=0 (음성) | Y=1 (양성) | 행 합 |
|---|---|---|---|
| **H=0 (정상)** | 특이도 | 1 − 특이도 | 1 |
| **H=1 (감염)** | 1 − 민감도 | 민감도 | 1 |

<br/>

> 구하라: (a) `P(H=1|Y=1)`  (b) `P(H=1|Y=0)`

<details>
<summary><b>▶ 해설 보기</b></summary>

| H=0 | 0.9 | **0.025** (=1−0.975) | 0.0225 | ≈ 0.205 |
| | | | **Z = 0.11** | 합 = 1 ✓ |

**(b) 음성일 때** — ⚠️ **Likelihood 열을 바꿔 써야 합니다**

| H | Prior | Likelihood | Unnorm | **Posterior** |
|---|---|---|---|---|
| H=1 | 0.1 | **0.125** (=1−0.875) | 0.0125 | **≈ 0.014** |
| H=0 | 0.9 | **0.975** | 0.8775 | ≈ 0.986 |
| | | | **Z = 0.89** | 합 = 1 ✓ |

### 답: (a) **약 79.5%**  (b) **약 1.4%**

# 블록 4 — Beta 더하기 ⏱ 40분 · 기출 6번 (10점)

> 수업 노트 [5주차 §8](./05-binomial-mle-beta.md) — **절차 동일**

## 배우기 — 규칙 하나

$$
\text{Beta}(a,\ b) \;\xrightarrow{\ \text{성공 } k\text{번},\ \text{실패 } m\text{번}\ }\; \text{Beta}(a+k,\ b+m)
$$

**그냥 더하기입니다.** 왜 그런지는 지수 법칙 한 줄이면 됩니다.

```
Beta(a,b)의 모양  =  θ^(a−1) (1−θ)^(b−1)
데이터의 모양     =  θ^k (1−θ)^m

곱하면            =  θ^(a−1+k) (1−θ)^(b−1+m)
                  =  θ^((a+k)−1) (1−θ)^((b+m)−1)      →  Beta(a+k, b+m)
```

> ⚠️ **지수에 1을 더해야 a, b가 됩니다.** `θ⁵(1−θ)²` → `Beta(6,3)`이지 `Beta(5,2)`가 아닙니다.

**상수 공식** (density function을 물으면 필요)

$$
B(a,b) = \frac{(a-1)!\,(b-1)!}{(a+b-1)!}
\qquad
p(\theta\mid Y) = \frac{\theta^{a-1}(1-\theta)^{b-1}}{B(a,b)}
$$

<br/>

### 📝 기출 6번

> A coin is tossed 5 times and the result is **Y = {1, 1, 0, 1, 1}**. The data are i.i.d.
> (a) What is the likelihood function?
> (b) When the prior is `p(θ) = Beta(θ|a=2, b=2)`, find the posterior density function `p(θ|Y)`.

<details>
<summary><b>▶ 해설 보기</b></summary>

**데이터**: 앞면(1) **4번**, 뒷면(0) **1번**

**(a) Likelihood** — i.i.d.니까 그냥 곱합니다
```
L(θ) = θ · θ · (1−θ) · θ · θ = θ⁴(1−θ)
```

**(b) Posterior**
```
p(θ|Y) ∝ θ⁴(1−θ) × θ^(2−1)(1−θ)^(2−1)
       = θ⁴(1−θ) × θ(1−θ)
       = θ⁵(1−θ)²  =  θ^(6−1)(1−θ)^(3−1)       →  Beta(6, 3)

B(6,3) = 5!·2!/8! = (120×2)/40320 = 1/168
```

### 답: **p(θ|Y) = Beta(θ|6, 3) = 168·θ⁵(1−θ)²**

**1초 검산**: Beta(2,2) + 앞면 4, 뒷면 1 → Beta(2+4, 2+1) = **Beta(6,3)** ✓

</details>

## ⚠️ 틀리는 지점

1. **지수 +1을 빠뜨리기.** `θ⁵(1−θ)²` → a = 5+1 = 6, b = 2+1 = 3.
2. **"density function"인데 `∝`로 끝내기.** `B(a,b)`까지 계산해야 완답입니다.

<br/>

### ✏️ 연습 4-A

> 동전을 **8번** 던져 `Y = {1,0,1,1,0,1,1,1}`. prior가 `Beta(θ|3, 1)`.
> (a) likelihood function  (b) posterior density function (상수까지)

<details>
<summary><b>▶ 해설 보기</b></summary>

앞면 **6번**, 뒷면 **2번**

**(a)** `L(θ) = θ⁶(1−θ)²`

**(b)**
```
p(θ|Y) ∝ θ⁶(1−θ)² × θ^(3−1)(1−θ)^(1−1)
       = θ⁶(1−θ)² × θ²(1−θ)⁰
       = θ⁸(1−θ)² = θ^(9−1)(1−θ)^(3−1)      →  Beta(9, 3)

B(9,3) = 8!·2!/11! = (40320×2)/39916800 = 1/495
```
### **p(θ|Y) = Beta(θ|9,3) = 495·θ⁸(1−θ)²**

> 검산: Beta(3,1) + 성공 6, 실패 2 → Beta(9,3) ✓

</details>

<br/>

### ✏️ 연습 4-B

> 동전을 **10번** 던져 앞면 **3번**. prior가 `Beta(θ|1, 1)`.
> (a) posterior  (b) posterior의 mode `(a−1)/(a+b−2)` 를 구하고 MLE(`k/N`)와 비교

<details>
<summary><b>▶ 해설 보기</b></summary>

**(a)** Beta(1,1) + 성공 3, 실패 7 → **Beta(4, 8)**
```
B(4,8) = 3!·7!/11! = (6×5040)/39916800 = 1/1320
p(θ|Y) = 1320·θ³(1−θ)⁷
```

**(b)** mode = `(4−1)/(4+8−2)` = **3/10 = 0.3**, MLE = `3/10` = **0.3** → **같습니다.**

> **이유**: `Beta(1,1)`은 **Uniform(평평한 분포)** 이라 prior가 아무 영향을 주지 않습니다.
> 반면 4-A는 prior `Beta(3,1)`이 1쪽으로 치우쳐서 mode가 `8/10 = 0.8`로, MLE(6/8 = 0.75)보다 **올라갔습니다.**

</details>

> ✅ **이 블록을 끝내면**: Beta 문제를 1분 안에 푼다. **누적 40점.**

# 블록 5 — 이항분포 ⏱ 25분 · 기출 9번 (10점)

> 수업 노트 [4주차 §8-3](./04-bayes-update.md) — 공식은 배웠고, 기출의 "convolution"은 **같은 계산의 다른 이름**입니다.

## 배우기

기출의 `X + X`는 **독립인 동전 2개를 던져 나온 숫자의 합** = **앞면이 몇 번 나왔나** = **이항분포**입니다.

$$
P(Y = k \mid N, \theta) = \binom{N}{k}\,\theta^{k}(1-\theta)^{N-k}
$$

**θ = 1/2이면 특히 쉽습니다.** `θᵏ(1−θ)^(N−k)`가 전부 `1/2ᴺ`으로 같아지므로 **`C(N,k)`만 구하면 됩니다.**

```
C(N,k) = N! / (k!(N−k)!)

C(2,k) = 1, 2, 1                  → 분모 2² = 4
C(3,k) = 1, 3, 3, 1               → 분모 2³ = 8
C(4,k) = 1, 4, 6, 4, 1            → 분모 2⁴ = 16
C(5,k) = 1, 5, 10, 10, 5, 1       → 분모 2⁵ = 32
```

> 💡 **암산 요령** (수업 용어는 아니지만 계산이 빠릅니다): 위 두 수를 더하면 아래 줄이 됩니다.
> ```
>       1
>     1   1
>   1   2   1
> 1   3   3   1
> ```
> **답안에는 배운 표기인 `C(N,k)`로 쓰세요.**

<br/>

### 📝 기출 9번

> `X ∈ {0,1}`, `P(1) = 1/2`. Convolution theorem으로 PMF를 구하라.
> (a) `A = X + X`  (b) `B = A + X`  (c) `C = X + X + X + X`

<details>
<summary><b>▶ 해설 보기</b></summary>

**(a) A = X+X** → 동전 **2개** → `C(2,k)/2² = 1,2,1 / 4`

| A | 0 | 1 | 2 |
|---|---|---|---|
| p(A) | **1/4** | **1/2** | **1/4** |

**(b) B = A+X** → 동전 **3개** → `C(3,k)/2³ = 1,3,3,1 / 8`

| B | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| p(B) | **1/8** | **3/8** | **3/8** | **1/8** |

**(c) C = X+X+X+X** → 동전 **4개** → `C(4,k)/2⁴ = 1,4,6,4,1 / 16`

| C | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| p(C) | **1/16** | **4/16** | **6/16** | **4/16** | **1/16** |

> 모두 합 = 1 ✓
>
> **답안에 한 줄 추가**: "Bernoulli(1/2)를 N번 더하면 Binomial(N, 1/2)이 된다.
> convolution 공식 `p_A(a) = Σ_k p_X(k)·p_X(a−k)` 가 이를 보여준다."

</details>

## ⚠️ 틀리는 지점

- **θ ≠ 1/2이면 `C(N,k)/2ᴺ`으로 풀면 틀립니다.** 반드시 `C(N,k)θᵏ(1−θ)^(N−k)`를 쓰세요.

<br/>

### ✏️ 연습 5-A

> `P(1) = 1/2`일 때 (a) `A = X+X+X`  (b) `B = A+X+X` 의 PMF

<details>
<summary><b>▶ 해설 보기</b></summary>

**(a)** 동전 **3개** → `C(3,k)/8`

| A | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| p(A) | **1/8** | **3/8** | **3/8** | **1/8** |

**(b)** 동전 **5개** → `C(5,k)/32`, `C(5,k) = 1, 5, 10, 10, 5, 1`

| B | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| p(B) | **1/32** | **5/32** | **10/32** | **10/32** | **5/32** | **1/32** |

> 합 = 32/32 = 1 ✓

</details>

<br/>

### ✏️ 연습 5-B

> `P(1) = 1/3`일 때 `A = X+X` 의 PMF

<details>
<summary><b>▶ 해설 보기</b></summary>

θ = 1/3이므로 **공식을 그대로 써야 합니다**

```
P(A=0) = C(2,0)(1/3)⁰(2/3)² = 1 × 1 × 4/9 = 4/9
P(A=1) = C(2,1)(1/3)¹(2/3)¹ = 2 × 2/9     = 4/9
P(A=2) = C(2,2)(1/3)²(2/3)⁰ = 1 × 1/9     = 1/9
```

| A | 0 | 1 | 2 |
|---|---|---|---|
| p(A) | **4/9** | **4/9** | **1/9** |

> 합 = 1 ✓ — `1,2,1 / 4`로 쓰면 **틀립니다.**

</details>

> ✅ **이 블록을 끝내면**: 10분 안에 10점. **누적 50점 — 이미 반에 근접했습니다.**

# 블록 6 — 몬티 홀 ⏱ 50분 · 기출 2번 (10점)

> 수업 노트 [3주차 §9.1](./03-bayes-theorem-and-distribution.md) — **기출과 같은 문제** (수업 중 지명 과제)
> ⚠️ **유일하게 암기가 안 통합니다.** Likelihood를 직접 세워야 해서 마지막에 배치했습니다.

## 배우기 — 질문 하나로 환원하기

표 자체는 블록 2와 같습니다. 다른 점은 **Likelihood가 문제에 안 적혀 있다**는 것뿐입니다.

> ### **"차가 거기 있다고 치면, 진행자는 몇 개 문 중에서 고르나?"**

진행자는 ① **내가 고른 문** ② **차가 있는 문** — 이 둘을 절대 열지 않습니다.

| 차의 위치 | 진행자가 못 여는 문 | 고를 수 있는 문 개수 | P(그 문을 연다) |
|---|---|---|---|
| **내가 고른 문** | 내 문 하나뿐 | 전체 − 1 | **1/(전체−1)** |
| **다른 문** | 내 문 + 차 문 = 2개 | 전체 − 2 | **1/(전체−2)** |
| **열린 문** | 차가 있으면 못 엶 | — | **0** |

**문 개수별로 계산하면**

| 문 개수 | 내 문에 차 | 다른 문에 차 | 열린 문에 차 |
|---|---|---|---|
| 3개 | 1/2 | **1** | 0 |
| **4개** | **1/3** | **1/2** | **0** |
| 5개 | 1/4 | 1/3 | 0 |

> ⚠️ **3문 버전의 `2/3`을 외워서 쓰면 틀립니다.** 문 개수가 바뀌면 전부 다시 계산해야 합니다.

<br/>

### 📝 기출 2번

> 문이 **4개**, 차 1대 + 염소 3마리. **1번 문**을 골랐다. Monty가 **4번 문**을 열어 염소를 보여줬다.
> 바꿀 것인가? **posterior를 계산해서** 답하라.

<details>
<summary><b>▶ 해설 보기</b></summary>

**Step 1. 가설과 데이터**
```
X = xᵢ : 차가 i번 문 뒤에 있다
D      : Monty가 4번 문을 열었다
```

**Step 2. Likelihood** — "차가 거기 있다면 Monty는 몇 개 중에서 고르나?"

| 차의 위치 | 열 수 있는 문 | 개수 | **P(4번을 연다)** |
|---|---|---|---|
| **1번** (내 선택) | 2, 3, 4 | 3개 | **1/3** |
| **2번** | 3, 4 | 2개 | **1/2** |
| **3번** | 2, 4 | 2개 | **1/2** |
| **4번** | 차가 있어 못 엶 | — | **0** |

**Step 3. 베이즈 표**

| X | Prior | Likelihood | Unnorm | **Posterior** |
|---|---|---|---|---|
| 차 1번 | 1/4 | 1/3 | 1/12 | **1/4 = 25%** |
| 차 2번 | 1/4 | 1/2 | 1/8 | **3/8 = 37.5%** |
| 차 3번 | 1/4 | 1/2 | 1/8 | **3/8 = 37.5%** |
| 차 4번 | 1/4 | 0 | 0 | **0** |
| | | | **Z = 1/3** | 합 = 1 ✓ |

```
Z = 1/12 + 1/8 + 1/8 = 2/24 + 3/24 + 3/24 = 8/24 = 1/3
P(차 1번|D) = (1/12)/(1/3) = 1/4
P(차 2번|D) = (1/8) /(1/3) = 3/8
```

### 답: 유지 **25%**, 2번 또는 3번으로 바꾸면 **37.5%** → **바꾸는 것이 유리**

> **반드시 문장으로 결론을 쓰세요.** "바꾸는 것이 유리하다"가 문제가 요구한 답입니다.

</details>

## ⚠️ 틀리는 지점

1. **"문이 3개 남았으니 1/3씩"은 오답.** Monty는 아무 문이나 연 게 아니라 **정답을 알고 염소 문만** 열었습니다.
2. **내가 고른 문의 확률은 끝까지 변하지 않습니다** (4문이면 1/4). Monty가 내 문에 대해 아무 정보도 주지 않았기 때문입니다.

<br/>

### 유지 **1/3**, 바꾸면 **2/3** → 바꾼다

</details>

### ✏️ 연습 6-B

> 문 **5개**. **1번**을 골랐고 Monty가 **5번**을 열었다. 각 문의 posterior는? 바꿔야 하는가?

<details>

# 블록 7 — 비전 시스템 ⏱ 40분 · 기출 7번 (10점)

> 수업 노트 [6주차 §1~3](./06-mle-map-estimating-counts.md) — **6주차 메인 예제. 기출과 숫자까지 동일합니다.**
> ⭐ **작년엔 어려운 문제였지만 올해는 수업에서 통째로 다뤘습니다. 출제 확률 최상위.**

## ⏱ 시간이 부족하면 — 25분 단축 경로

미분을 건너뛰고 아래 **세 가지만** 하세요. 점수의 대부분이 여기 있습니다.

```
① P(H 보고|θ) = 0.2 + 0.6θ  를 세운다            ← 10분. 이 한 줄이 절반
② 방정식으로 θ를 구한다                          ← 5분. 미분 불필요
      140/250 = 0.56 = 0.2 + 0.6θ  →  θ = 0.6
③ "y를 바꾸면?" 을 말로 쓴다                     ← 10분. 계산 없음
      y가 0.5에 가까워질수록 데이터가 정보를 잃고
      posterior가 평평해져 prior로 되돌아간다
```

> **미분 유도(Step 3)는 선택입니다.** 답은 ②와 똑같이 0.6이 나옵니다.
> 답안에는 ②로 답을 내고 "log-likelihood를 미분해도 같은 결과"라고 한 줄 덧붙이면 됩니다.

## 배우기 — 핵심은 Likelihood 한 줄

기계가 **앞면이라고 보고할 확률**을 Sum rule로 만듭니다.

```
         ┌── 실제 앞면 (θ) ──┬── 제대로 읽음 (0.8) ──→ H 보고
동전 ────┤                   └── 잘못 읽음 (0.2) ──→ T 보고
         └── 실제 뒷면 (1−θ) ┬── 제대로 읽음 (0.8) ──→ T 보고
                             └── 잘못 읽음 (0.2) ──→ H 보고
```

$$
P(\text{H 보고}\mid\theta) = 0.8\theta + 0.2(1-\theta) = \boxed{0.2 + 0.6\theta}
\qquad
P(\text{T 보고}\mid\theta) = \boxed{0.8 - 0.6\theta}
$$

**숫자로 감 잡기** (6주차 §1.2)

| θ | H 보고 확률 | 의미 |
|---|---|---|
| 0.5 | 0.5 | 오류가 대칭이라 그대로 |
| 1 | 0.8 | 앞면만 나와도 20%는 뒷면으로 오독 |
| 0 | 0.2 | 뒷면만 나와도 20%는 앞면으로 오독 |

> **보고 확률이 0.2 ~ 0.8로 눌려 있습니다.** 비전 오류가 실제 확률을 **0.5 쪽으로 끌어당기는** 효과입니다. 이게 이 문제의 전부입니다.

<br/>

### 📝 기출 7번

> 기계가 확률 **y = 0.2**로 앞면을 뒷면으로, 뒷면을 앞면으로 잘못 보고한다.
> **250번** 돌려 기계가 **앞면 140번**을 보고했다. **x의 posterior는?** **y를 바꾸면 어떻게 되는가?**

<details>
<summary><b>▶ 해설 보기</b></summary>

**Step 1. Likelihood** — "H 보고 수"는 250번 중 성공 횟수이므로 **Binomial**

$$
L(\theta)=\binom{250}{140}(0.2+0.6\theta)^{140}(0.8-0.6\theta)^{110}
$$

**Step 2. Posterior**

$$
p(\theta\mid Y)\;\propto\;(0.2+0.6\theta)^{140}(0.8-0.6\theta)^{110}\times p(\theta)
$$

- Beta 꼴이 **아니라서 닫힌 형태가 없습니다** → θ를 `0, 0.01, …, 1`로 **이산화해서 수치로 계산**한다고 쓰면 됩니다 (101 Bowls 방식)
- prior를 Uniform(= Beta(1,1))으로 두면 posterior 모양 = likelihood 모양

**Step 3. 꼭대기(MLE)는 손으로 구할 수 있습니다**

```
d/dθ [140·log(0.2+0.6θ) + 110·log(0.8−0.6θ)] = 0

140×0.6/(0.2+0.6θ) − 110×0.6/(0.8−0.6θ) = 0       ← 안쪽 0.6이 곱해짐
140(0.8−0.6θ) = 110(0.2+0.6θ)
112 − 84θ = 22 + 66θ
90 = 150θ
```

$$
\boxed{\hat\theta_{\text{MLE}} = 0.600}
$$

> **직관**: 기계가 극단값을 0.5 쪽으로 뭉개기 때문에, 보고값 `140/250 = 0.56`을 만들려면 **진짜 θ는 더 극단적인 0.6**이어야 합니다.

**6주차 노트의 전체 결과** (적어두면 좋습니다)

| 추정 | 값 |
|---|---|
| MLE | **0.600** |
| MAP (Beta(2,2) prior) | ≈ 0.598 |
| Posterior mean | ≈ 0.597 |
| 90% credible interval | ≈ (0.51, 0.68) |

**Step 4. "y를 바꾸면?" — 말로 쓰는 문제 (쉬운 점수)**

일반화하면 `P(H 보고) = y + (1−2y)θ` 이고, 보고 비율 0.56을 맞추는 θ는 `θ̂ = (0.56 − y)/(1 − 2y)`

| y | 의미 | θ̂ |
|---|---|---|
| 0 | 기계가 완벽 | **0.56** (= 140/250) |
| **0.2** | 문제 조건 | **0.6** |
| 0.4 | 매우 부정확 | 0.8 (추정이 극단으로 밀림) |
| **→ 0.5** | **순수 노이즈** | **Likelihood가 평평 → posterior = prior, 아무것도 모름** |

> **한 줄 결론**: **y가 0.5에 가까워질수록 데이터가 정보를 잃고, posterior가 넓게 퍼져 prior로 되돌아간다.**

</details>

## ⚠️ 틀리는 지점

1. **140을 "실제 앞면 횟수"로 착각하기.** 140은 **기계가 앞면이라고 보고한 횟수**입니다.
2. **미분할 때 안쪽 0.6을 빠뜨리기.** `log(0.2+0.6θ)`의 미분은 `0.6/(0.2+0.6θ)` 입니다.

<br/>

### ✏️ 연습 7

> 오류율이 **y = 0.1**인 기계로 **100번** 돌려 **70번 앞면** 보고를 받았다.
> (a) `P(H 보고|θ)` 를 θ로 나타내시오  (b) `θ_MLE` 를 구하시오

<details>

# 블록 8 — MAP ⏱ 30분 · 기출 5번 (10점) · **여유 시**

> 수업 노트 [6주차 §3.3](./06-mle-map-estimating-counts.md) — log posterior로 MAP 구하기

## 배우기 — 공식 하나

$$
\hat\theta_{\text{MAP}} = \arg\max_\theta\Big[\underbrace{\log L(\theta)}_{\text{블록 7·9와 동일}} + \underbrace{\log p(\theta)}_{\text{prior 항만 추가}}\Big]
$$

> ⭐ **MAP = MLE 식 + log prior 항.** 그게 전부입니다.
> **Z는 계산할 필요가 없습니다** (상수라서 arg max에 영향 없음). Z가 필요한 건 평균·구간을 구할 때뿐입니다.

**Beta(a,b) prior의 log**
```
log Beta(θ|a,b) = (a−1)·log θ + (b−1)·log(1−θ) + 상수
```

<br/>

### 📝 기출 5번

> 기출 4번(탈세 설문, 100명 중 YES 60)에서 prior가 `p(θ) = Beta(θ|a=30, b=20)` 일 때
> (a) log-posterior  (b) `θ_MAP`

<details>
<summary><b>▶ 해설 보기</b></summary>

`P(YES|θ) = (1+θ)/2`, `P(NO|θ) = (1−θ)/2` 이므로

**(a) log-posterior**

$$
\log p(\theta\mid Y)=\text{상수}+\underbrace{60\log(1+\theta)+40\log(1-\theta)}_{\log L}+\underbrace{29\log\theta+19\log(1-\theta)}_{\log\text{prior}}
$$

$$
=\text{상수}+60\log(1+\theta)+29\log\theta+59\log(1-\theta)
$$

> `(1−θ)` 항이 **40 + 19 = 59**로 합쳐지는 게 포인트입니다.

**(b) θ_MAP** — 미분하면 2차방정식

```
60/(1+θ) + 29/θ − 59/(1−θ) = 0

양변에 θ(1+θ)(1−θ)를 곱하면
60θ(1−θ) + 29(1+θ)(1−θ) − 59θ(1+θ) = 0
60θ − 60θ² + 29 − 29θ² − 59θ − 59θ² = 0
−148θ² + θ + 29 = 0
```

$$
148\theta^2-\theta-29=0
\;\Rightarrow\;
\theta=\frac{1+\sqrt{1+4(148)(29)}}{296}=\frac{1+\sqrt{17169}}{296}\approx\frac{132.03}{296}
$$

$$
\boxed{\hat\theta_{\text{MAP}}\approx 0.446}
$$

> **해석**: MLE는 0.2인데 prior `Beta(30,20)`(mode ≈ 0.6)이 강해서 **0.446으로 끌어올려졌습니다.**

</details>

> ⏰ **시간이 없으면**: (a) log-posterior 식 + (b) `148θ² − θ − 29 = 0` **까지만 써도** 대부분의 점수가 들어옵니다. 근의 공식은 마지막에.

# 블록 10 — 최종 점검 ⏱ 30분

## 10-1. 외울 것 — 전부 일곱 줄

```
① 조건부확률 = 칸 ÷ 그 줄의 합            (분모는 조건으로 준 쪽)
② 베이즈 표  = Prior × Likelihood → 다 더해서 Z → 각각 ÷ Z
③ Likelihood 0 = 그 가설 영구 탈락
④ Beta(a,b) + 성공 k, 실패 m → Beta(a+k, b+m)      (지수 +1 주의)
⑤ B(a,b) = (a−1)!(b−1)! / (a+b−1)!
⑥ 이항분포 P(Y=k) = C(N,k)·θᵏ(1−θ)^(N−k),  C(N,k) = N!/(k!(N−k)!)
⑦ MAP = MLE 식 + log prior 항             (Z는 계산 불필요)
```

## 10-2. 답안 작성 템플릿

> 교수 코멘트: **"답안은 알아볼 수 있게 깔끔하게. 알아볼 수 없으면 점수 없음."**

```
[문제 N]

1) 가설 정의   X = x₁ : (내용)   X = x₂ : (내용)
2) 데이터      D = (관측한 것)
3) Bayes Table

   ┌──────┬───────┬────────────┬──────────┬───────────┐
   │  X   │ Prior │ Likelihood │  Unnorm  │ Posterior │
   ├──────┼───────┼────────────┼──────────┼───────────┤
   │  x₁  │       │            │          │           │
   └──────┴───────┴────────────┴──────────┴───────────┘
                               Z = ____    합 = 1 ✓

4) 계산:  Z = ___ ,  P(x₁|D) = ___ / Z = ___
5) 답:  ___        (+ 한 문장 해석)
```

> **Likelihood를 그 값으로 잡은 근거를 한 줄 쓰세요.** 계산이 틀려도 **부분점수가 나옵니다.**

① 내가 모르는 것(X, θ)은 무엇인가?
② 내가 관측한 것(D)은 무엇인가?
③ "X가 이 값이라면 D가 나올 확률"은 얼마인가?   ← Likelihood. 여기가 전부.
```

# 부록 A — 버린 문제 (8·10번, Gaussian)

> 6주차는 Gaussian이 아니라 MLE/MAP였습니다. **아직 미수강**이라 버립니다.
> 7주차에 Gaussian을 배우면 **8번은 가장 쉬운 문제가 됩니다** (아래 참고).

<details>
<summary><b>▶ 기출 8번 — Gaussian MLE/MAP (수강 후 확인용)</b></summary>

> 측정값 `Y = {−1, 1.1, 0, 1.9, 2}`, 모델 `y ~ Normal(m, 1)`.
> (a) `L(m)` (b) `ℓ(m)` (c) `m_MLE` (d) prior가 `Normal(0, 0.1)`일 때 `m_MAP`

**(a)(b)**
$$
L(m)=\prod_{i=1}^{5}\frac{1}{\sqrt{2\pi}}\exp\!\left(-\frac{(y_i-m)^2}{2}\right)
\qquad
\ell(m)=\text{상수}-\frac12\sum_{i=1}^{5}(y_i-m)^2
$$

**(c)** `dℓ/dm = Σ(yᵢ − m) = 0` → **m_MLE = 표본평균**
```
(−1 + 1.1 + 0 + 1.9 + 2)/5 = 4.0/5 = 0.8
```
### **m_MLE = 0.8**

> 💡 **"Gaussian 평균의 MLE = 표본평균"** 이 한 줄만 알아도 (c)는 공짜입니다.

**(d)** prior `Normal(0, σ₀²)`를 넣으면
$$
\hat m_{\text{MAP}}=\frac{\sum y_i}{N+1/\sigma_0^{2}}
$$
- 0.1을 **분산**으로 보면: `4/(5+10) = 4/15 ≈ 0.267`
- 0.1을 **표준편차**로 보면: `4/(5+100) ≈ 0.038`

> ⚠️ 표기 관례가 갈립니다. **"0.1을 분산으로 보았다"고 답안에 명시**하고 푸세요.
> 공통 메시지: prior가 0을 가리키므로 MLE 0.8이 **0 쪽으로 끌려 내려간다.**

</details>

① 결론: 두 가우시안의 convolution은 다시 가우시안이며,
