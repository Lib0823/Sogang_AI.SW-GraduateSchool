# §1. 베이즈 표 하나로 7문제 ⏱ 40분

> 수업 노트: [3주차](./03-bayes-theorem-and-distribution.md), [4주차](./04-bayes-update.md)

## 배우기 — 4칸이 전부

```
 가설 │ Prior │ Likelihood          │ Prior×Lik │ Posterior
──────┼───────┼─────────────────────┼───────────┼──────────────
  A   │ 고를  │ "A가 맞다면 이       │   곱한다   │ 곱한 값 ÷ Z
  B   │ 확률  │  데이터가 나올 확률"  │           │
──────┴───────┴─────────────────────┴───────────┴──────────────
                                   Z = 곱한 값 합계   합 = 1 ✓
```

### 계산을 3배 빠르게 하는 요령 두 개

**요령 ① Prior가 개수나 %로 주어지면 분수로 바꾸지 말고 그 숫자를 그대로 곱한다.** 어차피 마지막에 Z로 나누면 상쇄됩니다.

**요령 ② 곱한 값들을 정수 비율로 만든다.** 최소공배수를 곱하면 `9 : 8 : 6` 같은 정수가 되고, 답은 `9/23`처럼 바로 나옵니다.

> ⚠️ **Likelihood = 0이면 그 가설은 탈락.** 예: 6면체 주사위로는 7이 안 나옵니다.

<br/>

## 📝 기출로 바로 연습 (쉬운 순서)

### 1-1. 쿠키 문제 (2023-1)

> 그릇 1: 바닐라 40·초코 10. 그릇 2: 바닐라 30·초코 20. 그릇을 무작위로 골라 쿠키 하나를 꺼냈더니 **바닐라**였다. **그릇 1**에서 나왔을 확률은?

<details>
<summary><b>▶ 해설</b></summary>

| 그릇 | Prior | Lik = P(바닐라) | 곱 |  Posterior |
|---|---|---|---|---|
| 1 | 1/2 | 40/50 = 0.8 | 0.4 | **0.4/0.7 = 4/7 ≈ 0.571** |
| 2 | 1/2 | 30/50 = 0.6 | 0.3 | 3/7 ≈ 0.429 |
| | | | Z = 0.7 | 합 = 1 ✓ |

Prior가 같으므로 Likelihood 비율 `0.8 : 0.6 = 4 : 3`만 봐도 바로 **4/7**입니다.

</details>

### 1-2. 트릭 동전 (2023-2)

> 정상 동전(앞/뒤) 1개와 **양면 앞면** 동전 1개. 무작위로 하나를 골랐더니 보이는 면이 **앞면**이다. 트릭 동전일 확률은?

<details>
<summary><b>▶ 해설</b></summary>

| 동전 | Prior | Lik = P(앞면) | 곱 | Posterior |
|---|---|---|---|---|
| 정상 | 1/2 | 1/2 | 1/4 | 1/3 |
| 트릭 | 1/2 | **1** | 1/2 | **2/3** |
| | | | Z = 3/4 | 합 = 1 ✓ |

### 답: **2/3**

</details>

### 1-3. 주사위 1회 (2023-4)

> 6면체, 8면체, 10면체 주사위가 하나씩 있다. 하나를 골라 굴렸더니 **1**이 나왔다. 6면체일 확률은?

<details>
<summary><b>▶ 해설</b></summary>

Prior는 모두 1/3로 같으니 Likelihood만 비교합니다.

```
1/6 : 1/8 : 1/10        ← 최소공배수 120을 곱한다
 20 :  15 :  12         합 47
```

| 주사위 | Lik | 정수 비율 | Posterior |
|---|---|---|---|
| D6 | 1/6 | 20 | **20/47 ≈ 0.426** |
| D8 | 1/8 | 15 | 15/47 ≈ 0.319 |
| D10 | 1/10 | 12 | 12/47 ≈ 0.255 |

### 답: **20/47 ≈ 42.6%**

</details>

### 1-4. 주사위 상자 (2025-3) ⭐

| D4 | 1 | **0** | 0 | 0 | 0 |
| D6 | 2 | **0** | 0 | 0 | 0 |
| D8 | 3 | 1/8 | 3/8 | 9 | **9/23 ≈ 0.391** |

</details>

### 1-5. 주사위 2회 (2023-5)

> 상자에 6면체 **1개**, 8면체 **2개**, 10면체 **3개**. 하나를 골라 **두 번** 굴려 **3, 7**이 나왔다. 8면체일 확률은?

<details>
<summary><b>▶ 해설</b></summary>

두 번 굴렸으므로 **Likelihood를 두 번 곱합니다** (독립). 6면체는 7이 나올 수 없어 탈락합니다.

| 주사위 | 개수 | Lik | 곱 | ×800 | Posterior |
|---|---|---|---|---|---|
| D6 | 1 | 0 (7 불가) | 0 | 0 | 0 |
| D8 | 2 | (1/8)² = 1/64 | 1/32 | 25 | **25/49 ≈ 0.510** |
| D10 | 3 | (1/10)² = 1/100 | 3/100 | 24 | 24/49 ≈ 0.490 |
| | | | | 합 49 | 합 = 1 ✓ |

### 1-6. 동전 공장 (2023-7)

> 공장 1은 동전의 30%를 생산하고 앞면 확률은 0.3이다. 공장 2는 20%, 앞면 확률 0.5. 공장 3은 나머지 50%, 앞면 확률 0.6. 어떤 동전을 던져 **D = {앞, 앞, 뒤}**가 나왔다. 각 공장의 `P(Factory = k | D)`는?

<details>
<summary><b>▶ 해설</b></summary>

Likelihood = `θ · θ · (1−θ) = θ²(1−θ)`. Prior는 % 숫자를 그대로 씁니다.

| 공장 | Prior(%) | θ²(1−θ) | 곱 | Posterior |
|---|---|---|---|---|
| 1 | 30 | 0.09 × 0.7 = 0.063 | 1.89 | **0.163** |
| 2 | 20 | 0.25 × 0.5 = 0.125 | 2.50 | **0.216** |
| 3 | 50 | 0.36 × 0.4 = 0.144 | 7.20 | **0.621** |
| | | | Z = 11.59 | 합 = 1 ✓ |

### 답: **0.163 / 0.216 / 0.621** (정확히는 189/1159, 250/1159, 720/1159)

</details>

### 1-7. COVID 검사 (2023-10, 2025-11) ⭐⭐ 두 해 모두 출제

> 유병률 `P(H=1) = 0.1`, 민감도 `P(Y=1|H=1) = 0.875`, 특이도 `P(Y=0|H=0) = 0.975`.
> (a) `P(H=1|Y=1)` (b) `P(H=1|Y=0)`

**용어 3개만 외우면 됩니다.**

| 영어 | 뜻 | 표의 어디 |
|---|---|---|
| prevalence | 유병률 | **Prior** |
| sensitivity | 감염자가 양성 나올 확률 | Likelihood (H=1 행) |
| specificity | 정상인이 음성 나올 확률 | Likelihood (H=0 행) |

<details>
<summary><b>▶ 해설</b></summary>

Prior를 %로 써서 10 : 90으로 둡니다.

**(a) 양성일 때**: Likelihood는 `P(Y=1|H)`

| H | Prior | Lik | 곱 | Posterior |
|---|---|---|---|---|
| 1 (감염) | 10 | 0.875 | 8.75 | **8.75/11 ≈ 0.795** |
| 0 (정상) | 90 | 1−0.975 = 0.025 | 2.25 | 0.205 |
| | | | Z = 11 | 합 = 1 ✓ |

**(b) 음성일 때**: ⚠️ Likelihood 열이 `P(Y=0|H)`로 **바뀝니다**

| H | Prior | Lik | 곱 | Posterior |
|---|---|---|---|---|
| 1 (감염) | 10 | 1−0.875 = 0.125 | 1.25 | **1.25/89 ≈ 0.014** |
| 0 (정상) | 90 | 0.975 | 87.75 | 0.986 |
| | | | Z = 89 | 합 = 1 ✓ |

### 답: (a) **≈ 79.5%** (b) **≈ 1.4%**

해석 한 줄: 양성이어도 감염 확률은 약 80%다. 유병률이 10%로 낮기 때문이다.

</details>

### 1-8. 몬티 홀, 문 4개 (2023-3, 2025-2) ⭐⭐ 두 해 모두 출제

> 문 4개, 차 1대 + 염소 3마리. **1번**을 골랐다. Monty가 **4번**을 열어 염소를 보여줬다. 각 문 뒤에 차가 있을 확률은? 바꿔야 하는가?

**Likelihood를 정하는 질문은 하나입니다: "차가 거기 있다면 Monty는 몇 개 문 중에서 하나를 여는가?"**
Monty는 **내가 고른 문**과 **차가 있는 문**은 절대 열지 않습니다.

<details>
<summary><b>▶ 해설</b></summary>

| 차의 위치 | Monty가 열 수 있는 문 | P(4번을 연다) |
|---|---|---|
| 1번 (내 선택) | 2, 3, 4 → 3개 | **1/3** |
| 2번 | 3, 4 → 2개 | **1/2** |
| 3번 | 2, 4 → 2개 | **1/2** |
| 4번 | 차가 있으니 못 연다 | **0** |

Prior는 모두 1/4로 같으므로 Likelihood 비율만 봅니다.

```
1/3 : 1/2 : 1/2 : 0      ← 6을 곱한다
 2  :  3  :  3  : 0      합 8
```

| 문 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| Posterior | **1/4 = 25%** | **3/8 = 37.5%** | **3/8 = 37.5%** | **0** |

### 답: 그대로 두면 25%, 2번이나 3번으로 바꾸면 37.5%이므로 **바꾸는 것이 유리하다.**

⚠️ 3문짜리 정답 `2/3`을 외워서 쓰면 틀립니다.

</details>

> ✅ **§1 체크**: 1-4, 1-7, 1-8은 **보지 않고 3분 안에** 풀 수 있어야 합니다. 시험에 그대로 나옵니다.

# §2. 동전 θ 추정 — 지수 더하기 ⏱ 25분

> 수업 노트: [5주차](./05-binomial-mle-beta.md), [6주차](./06-mle-map-estimating-counts.md)

## 배우기 — 공식 세 줄

앞면 `k`번, 뒷면 `m`번이 나왔을 때 (`N = k + m`):

```
① MLE          θ̂ = k / N                           (그냥 앞면 비율)
② 사후분포     Beta(a, b) prior  →  Beta(a + k, b + m)   (그냥 더하기)
③ Beta 최빈값  Mode = (a − 1) / (a + b − 2)        (= MAP)
```

**정답을 받으려면 유도 한 줄을 반드시 씁니다.** 아래 틀을 외우세요.

```
L(θ)   = θ^k (1−θ)^m
ℓ(θ)   = k·log θ + m·log(1−θ)            ← log-likelihood
NLL(θ) = −k·log θ − m·log(1−θ)           ← negative log-likelihood (부호만 반대)
dℓ/dθ  = k/θ − m/(1−θ) = 0  →  k(1−θ) = mθ  →  θ = k/(k+m)
```

> ⚠️ `log(1−θ)`를 미분하면 **`−1/(1−θ)`** 입니다. 마이너스를 빠뜨리지 마세요.

<br/>

### 2-1. NLL과 MLE (2023-6)

> 동전을 100번 던져 앞면 60, 뒷면 40. (a) θ의 NLL은? (b) θ_MLE는?

<details>
<summary><b>▶ 해설</b></summary>

```
(a) NLL(θ) = −60·log θ − 40·log(1−θ)        (+ 상수 −log C(100,60))

(b) d/dθ NLL = −60/θ + 40/(1−θ) = 0
    60(1−θ) = 40θ  →  60 = 100θ
```
### 답: **θ_MLE = 0.6**

</details>

### 2-2. Beta 사후분포 (2025-6) ⭐

> `Y = {1, 1, 0, 1, 1}` (i.i.d.). (a) likelihood function은? (b) prior가 `Beta(2,2) = θ(1−θ)/B(2,2)`일 때 posterior `p(θ|Y)`는?

<details>
<summary><b>▶ 해설</b></summary>

앞면 4번, 뒷면 1번입니다.

```
(a) L(θ) = θ·θ·(1−θ)·θ·θ = θ⁴(1−θ)

(b) p(θ|Y) ∝ θ⁴(1−θ) × θ(1−θ) = θ⁵(1−θ)²  =  θ^(6−1)(1−θ)^(3−1)
    → Beta(6, 3)

    B(6,3) = 5!·2!/8! = 240/40320 = 1/168
```
### 답: **p(θ|Y) = Beta(θ|6, 3) = 168·θ⁵(1−θ)²**

검산: Beta(2,2)에 앞면 4·뒷면 1을 더하면 Beta(6,3) ✓

⚠️ 지수에 **+1을 해야** a, b가 됩니다. θ⁵ → a = 6.
상수 공식: `B(a,b) = (a−1)!(b−1)!/(a+b−1)!`

</details>

### 2-3. Beta 최빈값 증명 (2023-8)

> θ ~ Beta(a,b), a>1, b>1. 최빈값(peak)이 `(a−1)/(a+b−2)`임을 보여라.

<details>
<summary><b>▶ 해설</b></summary>

§2 MLE 유도와 **완전히 같은 계산**입니다 (k → a−1, m → b−1).

```
p(θ) ∝ θ^(a−1) (1−θ)^(b−1)

log p(θ) = (a−1)·log θ + (b−1)·log(1−θ) + 상수

d/dθ = (a−1)/θ − (b−1)/(1−θ) = 0
(a−1)(1−θ) = (b−1)θ
a − 1 = (a + b − 2)θ
θ = (a−1)/(a+b−2)                                     ∎

최대인 이유: 2차 미분 = −(a−1)/θ² − (b−1)/(1−θ)² < 0   (a>1, b>1이므로)
```

**활용**: 사후분포 Beta(6,3)의 MAP는 `(6−1)/(6+3−2) = 5/7`입니다.

</details>

> ✅ **§2 체크**: `θ⁵(1−θ)²`를 보면 곧바로 `Beta(6,3)`을 떠올릴 수 있으면 됩니다.

# §3. "YES 비율" 문제 — 비율 맞추기 ⏱ 15분

> 탈세 설문은 두 해 모두 나왔고(2023-9, 2025-4·5), 비전 기계(2025-7)도 **구조가 같습니다.**

## 배우기 — 두 단계

**1단계. 관측이 나올 확률을 θ로 쓴다** (가지 그림)

```
탈세 설문 (동전 앞면 확률 h):
   P(YES|θ) = h  +  (1−h)·θ
              ↑        ↑
       앞면이라 무조건 YES   뒷면이고 실제 탈세자

비전 기계 (오독률 y):
   P(H 보고|θ) = (1−y)·θ  +  y·(1−θ)  =  y + (1−2y)·θ
                   ↑            ↑
            진짜 앞면을 맞게 읽음   진짜 뒷면을 잘못 읽음
```

**2단계. "관측 비율 = 그 식"으로 놓고 θ를 푼다.** 이게 MLE입니다.

> 💡 **답안에는 반드시** log-likelihood와 미분 = 0 한 줄을 쓰고, 비율 맞추기는 **검산용**으로 쓰세요. 결과는 같습니다.

<br/>

### 3-1. 탈세 설문 MLE (2025-4) ⭐

> 앞면이면 YES, 뒷면이면 솔직하게 답한다. 100명 중 YES 60, NO 40. (a) log-likelihood (b) θ_MLE

<details>
<summary><b>▶ 해설</b></summary>

```
P(YES|θ) = 1/2 + θ/2 = (1+θ)/2,     P(NO|θ) = (1−θ)/2

(a) ℓ(θ) = 60·log((1+θ)/2) + 40·log((1−θ)/2)
         = 상수 + 60·log(1+θ) + 40·log(1−θ)

(b) 60/(1+θ) − 40/(1−θ) = 0
    60(1−θ) = 40(1+θ)  →  20 = 100θ
```
### 답: **θ_MLE = 0.2**

검산: (1+θ)/2 = 0.6 → θ = 0.2 ✓
⚠️ `60/100 = 0.6`이라고 쓰면 0점입니다. 동전 효과를 빼야 합니다.

</details>

### 3-2. 탈세 설문 사후분포 (2023-9)

> 100명 중 YES 80, NO 20. (1) 앞면 확률 0.5일 때 posterior와 최빈값은? (2) 앞면 확률 0.2일 때 최빈값은?

<details>
<summary><b>▶ 해설</b></summary>

Prior를 Uniform으로 두면 **posterior ∝ likelihood**이므로 최빈값 = MLE입니다.

**(1) h = 0.5**
```
p(θ|D) ∝ ((1+θ)/2)^80 · ((1−θ)/2)^20  ∝  (1+θ)^80 (1−θ)^20,   0 ≤ θ ≤ 1

80/(1+θ) − 20/(1−θ) = 0  →  80 − 80θ = 20 + 20θ  →  θ = 0.6
```
검산: (1+0.6)/2 = 0.8 ✓

**(2) h = 0.2**
```
P(YES|θ) = 0.2 + 0.8θ,     P(NO|θ) = 0.8(1−θ)

80·0.8/(0.2+0.8θ) − 20/(1−θ) = 0
64(1−θ) = 20(0.2+0.8θ)  →  64 − 64θ = 4 + 16θ  →  θ = 0.75
```
검산: 0.2 + 0.8×0.75 = 0.8 ✓

### 답: (1) **0.6** (2) **0.75**

</details>

### 3-3. 비전 기계 (2025-7)

> 오독률 y = 0.2. 250번 중 기계가 앞면 140번을 보고했다. x(=θ)의 posterior는? y를 바꾸면 어떻게 되는가?

<details>
<summary><b>▶ 해설</b></summary>

```
P(H 보고|θ) = 0.2 + 0.6θ,     P(T 보고|θ) = 0.8 − 0.6θ

posterior:  p(θ|D) ∝ (0.2 + 0.6θ)^140 · (0.8 − 0.6θ)^110 · p(θ)
            (Beta 꼴이 아니므로 θ를 0~1 격자로 나눠 수치 계산한다)

최빈값(Uniform prior):
  140·0.6/(0.2+0.6θ) = 110·0.6/(0.8−0.6θ)
  140(0.8−0.6θ) = 110(0.2+0.6θ)  →  90 = 150θ  →  θ = 0.6
```
검산: 140/250 = 0.56 = 0.2 + 0.6θ → θ = 0.6 ✓

**y를 바꾸면** (서술형이라 부분점수를 받기 쉽습니다)
- y = 0: 기계가 완벽하므로 θ̂ = 0.56
- y가 커질수록 보정 폭이 커진다 (y = 0.2이면 0.6, y = 0.4이면 0.8)
- **y → 0.5: 보고값이 순수한 노이즈가 되어 likelihood가 평평해지고, posterior는 prior로 되돌아간다**

</details>

### 3-4. 탈세 MAP (2025-5) — 시간 남으면

> 3-1에 prior `Beta(θ|30, 20)`을 붙여라. (a) log-posterior (b) θ_MAP

<details>
<summary><b>▶ 해설</b></summary>

(a) log p(θ|D) = 상수 + 60·log(1+θ) + 40·log(1−θ)  +  29·log θ + 19·log(1−θ)

# §5. Convolution ⏱ 10분 · 2025-9

> 수업 노트: [4주차 §8](./04-bayes-update.md)

## 배우기

```
p(A = a) = Σ_k p_X(k) · p_X(a − k)      ← "합이 a가 되는 모든 조합"을 더한다
```

표를 그리면 **같은 대각선끼리 더하는 것**입니다. 그리고 **동전 n개의 합은 이항분포**이므로 결과는 `C(n,k)/2ⁿ`이 됩니다.

```
동전 2개  1 2 1      /4
동전 3개  1 3 3 1    /8
동전 4개  1 4 6 4 1  /16
```

> 문제: X ∈ {0,1}, P(1) = 1/2. (a) A = X+X (b) B = A+X (c) C = X+X+X+X 의 PMF

<details>
<summary><b>▶ 해설</b></summary>

**(a) A = X + X**
```
p(A=0) = p(0)p(0)             = 1/4
p(A=1) = p(0)p(1) + p(1)p(0)  = 1/2
p(A=2) = p(1)p(1)             = 1/4
```

**(b) B = A + X**: p_A와 p_X를 convolution
```
p(B=0) = pA(0)·½                 = 1/8
p(B=1) = pA(1)·½ + pA(0)·½       = 3/8
p(B=2) = pA(2)·½ + pA(1)·½       = 3/8
p(B=3) = pA(2)·½                 = 1/8
```

**(c) C = A + A** (X 4개 = A 2개)
```
p(C=0) = ¼·¼                         = 1/16
p(C=1) = ¼·½ + ½·¼                   = 4/16
p(C=2) = ¼·¼ + ½·½ + ¼·¼             = 6/16
p(C=3)                               = 4/16
p(C=4)                               = 1/16
```

결론 한 줄: Bernoulli(½)를 n번 더하면 Binomial(n, ½)이 된다. 모두 합 = 1 ✓

</details>

# §6. 부분점수 줍기 — Gaussian ⏱ 5분 · 2025-8, 10

7주차(Gaussian) 내용입니다. **두 문장만 외우세요.**

```
① Gaussian 평균의 MLE = 표본평균
   Y = {−1, 1.1, 0, 1.9, 2}  →  m_MLE = 4.0/5 = 0.8

② ℓ(m) = 상수 − ½·Σ(yᵢ − m)²     → 미분 = Σ(yᵢ − m) = 0  → 표본평균
```

- **2025-8 (d) MAP**: prior가 0을 가리키므로 **MLE 0.8이 0 쪽으로 끌려 내려간다**고 쓰고, 공식 `m_MAP = Σyᵢ / (N + 1/σ₀²)`을 적습니다. 0.1을 분산으로 보면 `4/15 ≈ 0.267`입니다. **어떤 해석을 택했는지 답안에 명시**하세요.
- **2025-10 증명**: 이렇게 세 줄만 쓰고 넘어갑니다.
  "합의 pdf는 convolution `p(y) = ∫N(x|μ₁,σ₁²)·N(y−x|μ₂,σ₂²)dx`이다. 이는 §5 이산 convolution의 연속판이다. 결과는 평균 μ₁+μ₂, 분산 σ₁²+σ₂²인 Gaussian이다."
