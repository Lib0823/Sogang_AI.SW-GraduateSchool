## 강의 내용 정리

### 1. Opinet API 가이드
한국석유공사가 제공하는 오피넷 유가 정보 API의 공식 가이드로, 22개 엔드포인트를 문서화하고 있다: 현재 평균가(전국/시도/시군구), 최근 7일 일별 평균가(전국/상표별/지역별), 주간 평균가, 최저가 TOP 20, 반경 검색, 주유소 ID/이름 조회, 면세유 가격, 요소수(경유차 첨가제) 가격, 지역 코드 조회 등.

모든 요청에는 회원가입 후 발급받는 API 키(`code` 파라미터)와 응답 형식을 지정하는 `out` 파라미터(`xml` 또는 `json` 중 선택 가능 — XML 전용이 아니다)가 필요하다. 무료 요금제는 일 1,500회 호출로 제한되며, 갱신 주기도 명시되어 있다(현재가는 1·2·9·12·16·19시, 일별 평균가는 24시, 주간 평균가는 매주 금요일 10시). 유종별 제품 코드는 B034(고급휘발유), B027(보통휘발유), D047(경유), C004(등유), K015/K105(자동차용 부탄/LPG)이다.

### 2. API 기반 업무 자동화 노트북
9장 슬라이드와 함께 진행되는 빈칸 채우기 실습 노트북으로(12개 코드 셀 모두 실행 결과 없이 미실행 상태), 다음 순서로 구성된다:
- `requests`로 오피넷 API를 호출하고 `BeautifulSoup(response.content, "xml")`로 XML을 파싱한다 (`xml.etree`가 아닌 BeautifulSoup 사용 — 이 경우 내부적으로 `lxml` 파서 설치가 필요하다는 점이 노트북에 명시되어 있지 않아 유의할 부분).
- Colab 한글 폰트 깨짐 문제 해결을 위해 `koreanize_matplotlib`을 설정한다.
- **API①** (`avgAllPrice.do`, 전국 평균가) 호출.
- **API②** (`avgSidoPrice.do`, 시도별 평균가) 결과를 pandas DataFrame으로 변환하고, 제품 코드를 유종명으로 매핑하는 파생변수를 만든 뒤 지역×유종 피벗 테이블을 생성한다.
- **API④** (`avgRecentPrice.do`, 최근 7일 전국 일별 평균가) 결과를 날짜×유종 피벗 테이블로 재구성한다. (영문 라벨링에서 K015를 폭넓게 "LPG"로 표기하는데, 엄밀히는 자동차용 부탄을 가리키는 코드라는 점은 참고할 필요가 있다.)
- 마지막 두 섹션은 **프롬프트만 있고 코드 셀은 비어 있는 실습 과제**로, (1) 5개 유종의 일별 변동률을 나타내는 5x1 서브플롯(whitegrid 스타일, 12x18 크기)과 (2) 유가 간 상관관계 히트맵(8x6 크기, 파스텔 발산 컬러맵, 값 표기, "Correlation Between Fuel Prices" 제목)을 ChatGPT로 생성해보도록 지시한다 — 실행되지 않았으므로 실제 차트나 상관계수 결과는 파일에 존재하지 않는다.
