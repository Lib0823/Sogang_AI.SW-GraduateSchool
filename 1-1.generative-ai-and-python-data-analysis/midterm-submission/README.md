## 시험 개요
강의계획서 기준, 이 과목은 **필기시험을 실시하지 않으며**, 중간고사는 기말 프로젝트 수행을 위한 **"과제 정의서" 제출**로 대체된다. 이 폴더의 PPTX는 학기 중반 시점에 제출한 프로젝트 정의서 초안이며, 이후 다듬어진 최종 버전은 [final-project/project-definition-final.docx](../final-project/project-definition-final.docx)에서 확인할 수 있다.

파일이 PPTX 형식이라 본문 텍스트를 직접 추출하지 못해 상세 내용은 요약하지 못했으나, 최종 프로젝트가 AI 기반 주식 자동매매 시스템(FinanceManageAgent)에 관한 것임을 고려하면, 이 초안 역시 해당 프로젝트의 초기 문제 정의·목표·범위를 담고 있을 것으로 추정된다.
